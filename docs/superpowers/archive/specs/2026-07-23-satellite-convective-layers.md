# Spec: 위성 대류 발달·구름 꼭대기 레이어

**Status:** Approved  
**Created:** 2026-07-23

## Problem / Goal

조종사는 비행 전 지도에서 위성 기반 대류 발생 가능성과 구름 꼭대기 높이를, 레이더·낙뢰와 별개의 위성 산출물로 확인할 수 있어야 한다.

GK2A CI와 CTPS를 기존 관측 타임라인과 지도에 추가한다. 이 자료는 현재 관측이며, 미래 경로 조우·위험등급·회피 권고로 해석하지 않는다.

## Requirements

- FR-001: 지도 기상 패널은 기존 `위성` 옆에 독립 토글 `대류 가능성`(CI)과 `구름 꼭대기`(CTPS)를 제공한다. 둘 다 기본값은 OFF다.
- FR-002: CI와 CTPS는 각각 독립적으로 켜고 끌 수 있고, 동시에 표시할 수 있다. 어느 레이어도 기존 위성 영상을 자동으로 켜거나 끄지 않는다.
- FR-003: CI·CTPS는 하단 타임라인의 실제 선택된 위성 프레임과 정확히 같은 GK2A 관측시각 자료만 표시한다. 해당 시각 자료가 없으면 해당 레이어를 숨긴다.
- FR-003a: 원래 위성 영상이 꺼져 있어도 CI 또는 CTPS는 독립적으로 기존 관측 타임라인을 사용하고 시간 이동할 수 있다. 미래 시각에는 관측 레이어를 표시하지 않는다.
- FR-004: CI는 `CI1_prob`의 중간 상승기류 신호(3)와 강한 상승기류 신호(4) 중 유효 DQF만 표시한다. fill 값과 품질 불량 DQF는 제외하고, 인접 격자는 단계별 영역으로 묶는다.
- FR-005: CI 영역은 중간 상승기류 신호를 황색, 강한 상승기류 신호를 주황색으로 약 55% 투명하게 표시한다.
- FR-005a: CI 영역 위에는 상시 글자·아이콘을 표시하지 않는다.
- FR-006: CTPS는 유효한 구름 꼭대기 높이(CTH)만 표시한다. 맑음, fill 값, 품질 불량 또는 산출 실패 픽셀은 완전히 투명하게 처리한다.
- FR-007: CTPS는 `FL100 / FL200 / FL300 / FL400` 구간을 기준으로 녹색→노랑→주황→빨강→보라 색상으로 약 55% 투명하게 표시한다.
- FR-008: CTPS가 켜진 동안 기존 연직 고도 조절 UI와 같은 오른쪽 고도 레일을 표시한다. 기본값은 `전체`이며, `FL050` 단위로 `FL550`까지 선택할 수 있다.
- FR-009: 사용자가 CTPS 고도 레일을 선택하면, 선택값보다 낮은 구름 꼭대기는 지도에서 숨긴다.
- FR-010: CI와 CTPS를 동시에 표시할 경우 CTPS는 아래, CI 영역은 위에 표시한다.
- FR-011: 지도에서 한 지점을 선택하면 현재 켜진 CI·CTPS 레이어의 그 지점 값을 하나의 상세 카드에 함께 보여 준다. 값이 없는 레이어는 카드에서 생략한다. CI는 대류 발생 가능성의 상승기류 신호 단계를, CTPS는 구름 꼭대기 FL·섭씨(°C) 온도·품질 상태를 보여 준다. 선택 고도보다 낮아 지도에서 숨긴 CTPS는 카드에도 표시하지 않는다.
- FR-011a: 선택 상세는 선택한 관측시각과 활성 레이어가 유지되는 동안만 유지한다. 시간 이동, 레이어 OFF, 같은 지점의 값 없음, 또는 새 지점 선택 시 현재 값으로 갱신하거나 숨긴다.
- FR-011b: 선택 상세의 관측시각은 앱의 기존 시간대 설정(KST 또는 UTC)으로 표시한다. 내부 프레임 비교와 API 조회는 UTC instant를 사용한다.
- FR-012: 범례는 CI의 상승기류 신호 단계와 CTPS 구름 꼭대기 색상 구간을 설명한다. CI에는 위성 기반 대류 발생 가능성 참고이며 레이더 실황·위험등급이 아니라는 점을, CTPS에는 높이 정보이며 위험등급이 아니라는 점을 명시한다.
- FR-013: 수집 실패 시 마지막 정상 자료를 보존한다. 불완전한 새 자료로 기존 정상 자료를 교체하지 않는다.
- FR-014: CI·CTPS는 브리핑의 경로 조우·Go/No-go·자동 회피 권고·위험등급·알림 생성에 사용하지 않는다.

## Non-Goals

- CI·CTPS를 이용한 미래 대류 예측
- 경로 회피 권고 또는 자동 경로 변경
- 레이더·낙뢰·위성 레이어의 자동 동시 토글
- ETOP 산출 또는 원시 레이더 수직 스캔 처리
- 브리핑 본문의 대류 위험 판정 연동

## Success Criteria

- SC-001: 사용자는 `대류 가능성`과 `구름 꼭대기`를 각각 켜고 끌 수 있으며, 기본 지도는 변하지 않는다.
- SC-002: CI·CTPS는 동일 위성 프레임 시각의 자료만 표시하며, 시간 어긋난 자료가 남지 않는다.
- SC-003: CI는 중간·강한 상승기류 영역만, CTPS는 선택 FL 이상의 유효 구름 꼭대기만 표시한다.
- SC-004: CI·CTPS를 동시에 켰을 때 CTPS 위에 CI 영역이 표시된다.
- SC-005: 지도 선택 카드와 범례가 현재 켜진 레이어의 의미·값·관측시각을 명확히 설명한다.
- SC-006: 데스크톱·iPad·모바일에서 독립 토글, CTPS 고도 레일, 타임라인 이동, 베이스맵 교체 뒤에도 정상 동작한다.

## Alternatives Considered

| Option | Trade-off | Why not chosen |
|---|---|---|
| CI·CTPS를 하나의 위험 점수로 병합 | 한눈에는 단순하지만 산출물 의미를 잃음 | 대류 발생 가능성과 구름 꼭대기는 별개의 정보다. |
| CTPS를 브리핑 경로 조우로 사용 | 비행계획과 연결 가능 | 현재 관측만으로 ETD~ETA 조우를 판정할 수 없다. |
| 브라우저로 원시 NetCDF 전송 | 서버 코드는 작아짐 | 대용량 관측값 전송과 지도 처리 부담이 커진다. |
