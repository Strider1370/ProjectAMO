# 공항 패널 개편 — 단일 스크롤 + TAC-히어로 (디자인 제안서)

> 상태: **제안·설계 확정, 미구현.** 구조(인터랙션 아키텍처) 변경이므로 디자인 헌법 §195 Proposal-First 대상 → 이 문서 = 제안서, 구현은 **사용자 승인 후**.
> 작성: 2026-07-13. 사용자 결정: 표시=①TAC-히어로, 정보구조=전면 단일스크롤.

## 1. 문제

현재 공항 패널은 탭 분리(현재날씨·METAR·TAF·AMOS·공항경보·NOTAM·기상정보). 번잡함의 원인:
1. **중복** — 현재날씨가 METAR를 요약 → METAR 탭이 재표시 → TAF도 양쪽에.
2. **디코드 카드 과잉** — 한 값 = 한 카드 × N × 여러 탭.
3. **탭 호핑** — 전체 상황 파악에 클릭 반복.

## 2. 결정 (사용자 승인)

- **표시: ① TAC-히어로** — 원문 TAC 대형 + 토큰별 임계값 색상이 주인공, 디코드는 접이식.
- **정보구조: 전면 단일 스크롤** — 데스크톱·iPad·폰 모두. 왼쪽 탭 레일은 유지하되 **스크롤-스파이 네비**로 전환.
- **임계값 색상 필수.**

## 3. 리서치 요약 (타 기관)

- **하이브리드가 보편** — 원문 TAC를 없애는 서비스 없음. 요약/색 먼저, 원문 항상 접근가능(AWC, ForeFlight, CFPS, MAVIS 등). → TAC-히어로가 관습과 부합.
- **비행규칙 색이 1차 코딩**(단 우리는 3단계 VFR/IFR/LIFR — §6), 개별 요소 색은 상용앱 일부만(SkyDemon 개인 minima). → 우리가 둘 다 하면 차별점.
- **탭 < 스택/스크롤**(ForeFlight 단일 스크롤+레이어 노출), 예보는 **그래픽 트렌드**가 텍스트 우위.
- **KMA 항공기상청**은 탭+테이블(동아시아 표준), 색 체계 미문서화 → 우리가 색 코딩으로 앞설 여지.
- 근거: aviationweather.gov, foreflight.com, skydemon.aero, avplan-efb.com, metoffice(MAVIS), amo.kma.go.kr, FAA AC 00-45E.

## 4. 정보구조 설계

### 단일 스크롤 + 스크롤-스파이 레일
- 왼쪽 레일(아이콘+라벨) = 섹션 네비. 클릭 → 해당 섹션 스무스 스크롤. 스크롤 시 현재 섹션 자동 하이라이트(IntersectionObserver).
- 섹션 세로 스택, **위험도·시급성 순**(헌법 §116):
  `공항경보 → 현재(METAR) → 예보(TAF) → AMOS → NOTAM → 기상정보`
- **중복 제거**: 기존 "현재날씨" 탭은 해체 → 상단 `공항경보` 섹션 + `현재(METAR)` 섹션으로 흡수. 요약 카드 더미는 색 입힌 TAC 한 줄로 대체.

### 모바일 (전면 단일 스크롤, 단 완화책 필수)
- 헌법 P3 "한 화면 한 작업" 긴장 → 완화: **섹션 헤더 sticky**, 텍스트 많은 섹션(NOTAM·기상정보)은 **기본 접힘(요약 줄만) + 펼치기**. 레일은 하단 탭 또는 좌측 슬림 레일 중 폰 관습 검토.
- 페이지 가로 스크롤 금지(헌법 §182). TAC 한 줄은 폰에서 자동 줄바꿈 또는 패널 내부 가로 스크롤 폴백(헌법 §183).

## 5. 표시 설계 — TAC-히어로

> ※ §9(탭 실사 후 조정)가 이 절을 보강·일부 대체함 — 평문 요약줄 제외, TAF는 기존 타임라인 유지 등. 최신은 §9 참조.

각 기상 섹션 구성(위→아래):
1. **섹션 헤더**: 배지(METAR/TAF/…) + 관측/유효 시각 + i(출처 팝오버, 기존 패턴 재사용). (평문 요약줄은 §9-2에서 **제외 확정** — 색상만으로.)
2. **TAC 히어로**: 원문 TAC를 대형 모노스페이스(≈20px)로, **토큰마다 임계값 색상**. 색이 곧 디코드.
3. **접이식 "디코드 상세"**: 기존 카드형 상세를 원하면 펼침(기본 접힘).
4. (예보) **그래픽 트렌드**: TAF 기존 색상 타임라인 유지(§9-3) — 시간축 색상 세그먼트로 비행조건 변화 한 눈에.

국내(KMA/IWXXM)는 원문 TAC가 없으므로 **재구성 필요** → [[metar-taf-raw-tac-plan]] 선행/병행. (외국은 이미 raw_text 보유.)

## 6. 임계값 색상 스펙 (필수)

### 비행규칙 (3단계 · **프로젝트 실제 로직** `shared/weather/helpers.js` 기준)
> **MVFR 미사용** — 프로젝트는 VFR/IFR/LIFR 3단계(US 4단계 아님). MVFR/LIFR은 어차피 규정 아닌 미 NWS 분류.
| 등급 | 기준 | 색(실제 앱) |
|---|---|---|
| VFR | 시정 ≥5000m **AND** 운고 ≥1500ft | 녹 `#15803d` |
| IFR | 시정 <5000m **OR** 운고 <1500ft | **앰버** `#f59e0b` |
| LIFR | 시정/운고 < **공항별 최저치**(`DEFAULT_AIRPORT_MINIMA_RULES`, 예 RKJB 시정<550m·운고<200ft) = 실제 못 내림 | **적** `#dc2626` |

> ✅ **드리프트 해결(2026-07-13)**: 디자인 헌법 §4·§5·CSS토큰을 코드에 맞춰 정정 완료(MVFR 제거, 카테고리=심각도 레벨 VFR/MVFR=녹·IFR=앰버·LIFR=적, `--cat-*`→`--level-*` 별칭). 잔여: 코드 `theme/tokens.*`의 `--cat-mvfr`·`--cat-ifr:#c0291f`·`--cat-lifr:#9d2c9d` 레거시 hex + `AirportPanel.css .ap-taf-summary-cat--MVFR` → 개편 구현 때 레벨색으로 수렴. 데이터의 "MVFR" 문자열 fold 로직은 유지.

### 개별 토큰 (리서치 임계값 · 헌법 시맨틱색)
| 요소 | 앰버(주의) `--level-amber` | 적(경고) `--level-red` |
|---|---|---|
| 바람 지속 | ≥20 kt | ≥30 kt |
| 돌풍(gust−lull) | ≥10 kt | — |
| 측풍 | ≥15 kt | ≥20 kt |
| 기온−노점 스프레드 | ≤2°C (안개) | — |
| (선택) METAR 나이 | 오래됨 | 매우 오래됨 |

- 시정·운고 토큰 = 비행규칙색. 정상 = 무채(text-1). 색은 위험만(헌법 §28).
- **색만으로 구분 금지**(헌법 §38): 색 + 값 + 필요시 아이콘 병기.
- (향후) **개인 minima 동적 색상**(SkyDemon 방식) — [[briefing-go-nogo-design]]의 minima와 연계 옵션.

## 9. 조정 — 탭 실사 후 (2026-07-13, RKSI 7탭 캡처 반영)

전 탭을 실제 캡처해 데이터 성격을 확인한 결과, **"전면 TAC-히어로"는 문자 그대로가 아님**을 확정:
**코드 전문(METAR·TAF)만 TAC-히어로, 나머지는 성격에 맞는 전용/구조화 뷰 유지 + 색상·접이.**

### 데이터 성격 (실사)
- METAR = 코드전문(TAC 재현 가능). 단 **측풍·일강수량은 원문에 없음**(파생/센서값).
- TAF = **이미** 타임라인/테이블/그리드 토글 + 임계값 색상 보유(IFR 주황, 저시정 적) → 없애지 말 것.
- AMOS = 실시간 센서 대시보드(윈드로즈 다이얼, 활주로별 RVR, H/T·측풍성분) → 코드 아님, TAC 부적합.
- 기상정보 = 항공기상청 장문 서술 공보(일기개황·기온/강수 표·위험기상).
- NOTAM = 구조화 리스트. 공항경보 = 단순 상태/리스트.
- **현재날씨 탭 = METAR·TAF와 완전 중복** → 해체.

### 확정 결정
1. **측풍·일강수량 → AMOS로 이관.** METAR 원문에 없고, AMOS가 이미 활주로별 측풍(CROSS-WS)을 더 정확히 표시(중복). METAR 섹션은 원문 TAC 집중(+선택 체감온도 정도).
2. **평문 요약 줄 생략 — 색상만으로.** 규칙기반 요약 생성 = 유일한 신규 로직이었으나, 색이 곧 판독이므로 불필요. §5의 "한 줄 평문 요약"은 **제외**(신규 로직 0).
3. **TAF 섹션 = 기존 색상 타임라인 유지(주) + 원문 TAF TAC 보조(재구성 후) + 테이블/그리드 토글 유지.** TAC가 타임라인을 대체하지 않음.
4. **AMOS·기상정보·NOTAM·공항경보는 TAC-히어로 미적용** — 전용/구조화 뷰 유지, 우리 토큰 재스타일 + 임계 색상 + (장문은) 접이.

### 조정된 섹션별 설계 (최종)
| 섹션(순서) | 표시 |
|---|---|
| 공항경보 | 상태 배지(없음/발효중) + 경보 리스트. 발효 시 최상단 적색 강조 |
| 현재(METAR) | 비행규칙 배지 + **원문 TAC 대형·토큰 색상** + 접이 디코드. (요약줄·측풍·일강수량 없음) |
| 예보(TAF) | **색상 타임라인(유지)** + 원문 TAF TAC(재구성 후) + 테이블/그리드 토글 |
| AMOS | 윈드로즈 다이얼 + 활주로별 RVR·측풍·H/T + **일강수량**. 임계 색상 |
| NOTAM | 구조화 리스트(현행) + 접이 + 상단 개수 요약 |
| 기상정보 | 한 줄 요약(위험기상·경보 유무) + 접이식 장문 공보 |

→ TAC 재구성([[metar-taf-raw-tac-plan]])은 METAR·TAF 섹션에만 필요. 신규 로직은 사실상 없음(요약 생성 제외).

## 10. 레일 심각도 배지 (사이드 레일 = 트리아지 보드)

단일 스크롤에서 왼쪽 레일이 "문제 목차"가 되도록, 각 섹션 항목에 **주의 필요 개수 배지 + 최악 심각도 색**을 얹는다.

### 공통 규칙
- **숫자** = 그 섹션에서 주의 필요한 항목 수. **색** = 그중 최악 심각도. **0이면 배지 없음**(부재=정상).
- 심각도(코드 3단계 기준): **적(LIFR=최저치 미만·경보·폐쇄) > 앰버(IFR·바람/돌풍/유의기상 주의·위험기상) > 중립(항목 수)**. VFR=정상=배지 없음.
- 접근성: 색+숫자 → aria-label 병기("주의 2건, 최악 LIFR"). 큰 수 `9+` 캡.
- **임계 판별 로직은 기존 뷰모델 재사용**(`visCat`·`ceilCat`·`flightCat`·`highWind`·측풍 계산). 배지는 "세는 계층"만.

### 섹션별 카운트 단위·기준 (실제 데이터 필드 기준)
| 섹션 | 카운트 단위 | 판별 요소·기준 | 색 |
|---|---|---|---|
| 공항경보 | 유효 경보 건수 | `warnings[]` 현재 유효 | 적(경보=무조건 적) |
| 현재(METAR) | **요소 수**(스냅샷) | 시정<5000m 또는 운고<1500ft(=IFR·앰버, 공항최저치 미만이면 LIFR·적)·바람≥20kt·돌풍(gust−spd)≥10kt·유의기상(TS 적/그 외 앰버)·windshear 적 | 최악(적>앰버) |
| 예보(TAF) | **위험 시간창 수**(change group) | 한 BECMG/TEMPO/FM 구간 안에 임계 초과 요소가 하나라도 있으면 그 구간=1. 요소 수 아님 | 모든 위험 구간 중 최악 |
| AMOS | 활주로 임계 초과 수 | 측풍≥15/20kt·배풍·RVR<800/550m·돌풍(max−spd)≥10kt. 풍속 단위 **m/s**(×1.94=kt) | 최악 |
| NOTAM | 활성 NOTAM 수 | location=icao·현재유효 | 중립(항목수), 단 폐쇄류(qcode `QMR..LC` 등)=적 |
| 기상정보 | 위험기상 항목 수 | `forecast` ○불릿, `warn`≠"없음" | 위험수준(주의 앰버 / 경고·위험 적) |

- **METAR vs TAF 단위 차이 = 의도된 설계.** METAR=스냅샷이라 "지금 몇 개가 한계 밖"(요소 수), TAF=시간축이라 "몇 구간에서 못 뜸"(시간창 수). 조종사 관점에 각각 부합.
- **TAF 예시**: `BECMG 0600 FG BKN002` → 시정·FG·운고 모두 위험이나 **1구간**, 색 적(공항최저치 미만=LIFR). 카운트 범위는 표시 중 예보창(예 6h) 내로 한정.

### 확정 기본값 (필요시 변경)
- **비행규칙 3단계**(VFR/IFR/LIFR, MVFR 미사용) — 코드 `helpers.js` 기준. IFR=앰버, LIFR(공항최저치 미만)=적.
- NOTAM = **폐쇄류만 적, 나머지 중립**.
- TAF = **위험 시간창 수**(요소 수 아님), 색=최악.

### 실측 검증 (RKSI, 2026-07-13)
- METAR: 시정 9999·NSC·바람 9kt → **배지 없음(정상)** ✓
- 기상정보: 폭염(주의)·활주로온도 → **2 앰버** ✓
- 공항경보: RKSI 0 / RKPC 1(WIND_SHEAR 적) ✓
