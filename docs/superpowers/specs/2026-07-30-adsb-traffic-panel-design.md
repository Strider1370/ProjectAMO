# ADS-B 항적 패널 분리 및 필터 — 설계

- 작성일: 2026-07-30
- 상태: 사용자 승인 대기
- 범위: 프런트엔드 전용. 백엔드·파서·데이터 스키마 변경 없음.

## 1. 배경과 목적

ADS-B(실시간 항공기 위치)는 지금 **기상 레이어 패널**의 `항적` 그룹 안에 켜기/끄기 타일 하나로 들어 있다.
ADS-B는 기상정보가 아니라 교통 상황이고, 실제 코드에서도 예외 취급이 드러난다 —
`WeatherOverlayPanel.jsx`의 그룹 정의가 `{ id: 'traffic', title: '항적', ids: ['adsb'] }` 하나짜리이고
주석도 "마지막이 참고용 항적"이라고 스스로 구분해 두었다.

목적은 두 가지다.

1. ADS-B를 기상 패널에서 떼어내 **독립 패널**로 옮긴다 (켜기/끄기 자체를 포함해 전부).
2. 그 패널에서 **보고 싶은 항공기만 남기는 필터**를 제공한다.

주 사용 상황(사용자 확인):

- **임무기 추적** — 소방청·산림청 등 특정 기관 항공기만 남겨 계속 지켜본다.
- **고도대별 교통 파악** — 접근·출발 트래픽(저고도)과 순항 트래픽(고고도)을 나눠 본다.

조건에 맞지 않는 항공기는 **숨긴다**(흐리게 남기지 않는다).

## 2. 이미 있는 것 (새로 만들지 않는 것)

지도에 올라가는 항공기 하나하나(`createAdsbGeoJSON`, `addAdsbLayer.js`)가 이미 다음 속성을 달고 있다.

| 속성 | 내용 | 필터 용도 |
|---|---|---|
| `callsign` | 편명 (KAL123) | 검색, 항공사 판정 |
| `registration` | 등록기호 (HL1234) | 검색, 기관 판정 |
| `operator` | 항공사/기관 코드 | 소속 필터 |
| `airline_name` | 한글 이름 | 소속 목록 표시 |
| `aircraft_class` | `heavy`/`jet`/`regional`/`turboprop`/`piston`/`helicopter`/`unknown` | 기종 필터 |
| `baro_altitude` | 기압고도 **(미터)** | 고도 필터 |
| `type_code`, `velocity`, `true_track`, `vertical_rate`, `squawk` | — | 이번 범위 아님 |

소속 이름표도 이미 있다 — `airlines.js`(항공사 14개, ICAO 코드 → 한글 이름),
`operators.js`(등록기호 → 기관: 산림청, 소방청(119), 항공대·한서대·초당대·교통대·청주대).

따라서 이번 작업은 **UI + 순수 판정 로직**이고, 데이터 파이프라인 작업은 없다.

## 3. 확정된 결정

| 항목 | 결정 |
|---|---|
| 패널 위치 | 왼쪽 사이드바에 `항적` 항목 신설 → 독립 패널 (`activePanel === 'traffic'`) |
| 켜기/끄기 | 기상 패널에서 제거하고 새 패널 맨 위로 이동 |
| 필터 불일치 기체 | 숨김 |
| 소속 목록 | `항공사` / `기관·훈련기` / `미분류` 3그룹, 펼치면 개별 소속. 지금 떠 있는 소속만 대수와 함께 |
| 고도 | 이중 슬라이더 (0 ~ 45,000ft, 500ft 단위) |
| 1단계 필터 | 소속, 고도, 기종 등급, 편명·등록기호 검색 (상승/하강 상태는 제외) |
| 필터 기억 | 브라우저에 저장 → 다음 접속에도 유지 (검색어는 저장 안 함) |
| 켜기/끄기 기억 | 저장하지 않는다. 다른 지도 레이어와 같이 새로고침하면 꺼진 상태로 시작 |
| 적용 방식 | 지도에 다 올려두고 표시 규칙만 바꿈 (`map.setFilter`) |

## 4. 화면

사이드바 `항적`(전파 아이콘, ADS-B 타일이 쓰던 것 재사용)을 누르면 기존 `기상 레이어`·`항공 레이어`와
같은 자리·같은 껍데기(`layer-drawer`)로 패널이 열린다. 모바일은 지도 위 `항공`/`기상` 버튼 옆에
`항적`이 추가되고, 좁은 화면에서는 기존 패널과 같은 방식으로 아래에서 올라오는 시트가 된다.

패널 구성(위→아래):

1. **ADS-B 표시** 켜기/끄기 스위치
2. **소속** — 3그룹 트리. 그룹 체크 = 그룹 전체. 각 항목 옆에 현재 대수
3. **고도** — 이중 슬라이더 + 양끝 숫자(ft) 표시
4. **기종** — 대형기 · 제트 · 리저널 · 터보프롭 · 피스톤 · 헬기 · 미분류 칩
5. **검색** — 편명 또는 등록기호 부분일치 입력 한 칸
6. **하단** — `필터 초기화`, 그리고 `보이는 항공기 12 / 전체 131`

ADS-B가 꺼져 있으면 2~5는 비활성이고 "ADS-B를 켜면 지금 떠 있는 소속이 표시됩니다" 한 줄을 보여준다.

필터가 하나라도 걸려 있으면 사이드바 `항적` 버튼에 표식을 띄운다(사이드바에 이미 있는 배지 구조 재사용).
"왜 몇 대밖에 없지?"를 막기 위한 장치다.

## 5. 필터 규칙

- **서로 다른 필터는 AND** (소속 ∧ 고도 ∧ 기종), **같은 필터 안에서는 OR** (산림청 ∨ 소방청).
- **아무것도 선택하지 않은 필터는 "조건 없음"** — 전체를 통과시킨다. 빈 화면으로 시작하지 않게.
- **검색은 다른 필터를 무시한다.** 검색어가 비어 있지 않으면 편명·등록기호 부분일치(대소문자 무시)만
  적용한다. 근거: "FL180 이상"을 걸어둔 채 착륙 중인 기체를 검색하면 안 나와서, 찾는 도구가 못 찾는
  상황이 된다.
- **소속 판정** — `operator`가 항공사 명단에 있으면 `항공사`, 기관 명단에 있으면 `기관·훈련기`,
  둘 다 아니거나 비어 있으면 `미분류`.
- **고도** — 지도 속성은 미터, 화면 표시는 ft. 변환은 `trafficFilter.js` 한 곳에서만 한다.
  **고도를 보고하지 않는 기체(`baro_altitude`가 없음)는 슬라이더가 전 구간이 아닐 때 숨긴다** —
  값을 모르면 구간 안인지 판정할 수 없다. 이 사실을 슬라이더 아래에 작게 적는다.
- **기종** — `aircraft_class` 값과 그대로 대응. `unknown`은 `미분류` 칩.

## 6. 켜기 전에는 목록이 비어 있다

ADS-B는 **`/api/adsb` 요청이 올 때만** adsb.lol을 갱신한다(의도된 설계, `server.js`의
"collected on demand"). 즉 켜지 않으면 데이터가 없고, "지금 떠 있는 소속" 목록도 만들 수 없다.

- 꺼져 있을 때: 필터 비활성 + 안내 한 줄 (4절).
- 켠 직후: 첫 응답까지 "수신 중" 표시.
- 저장된 소속 선택이 지금 하늘에 없으면 목록에는 안 뜨지만 조건으로는 유효하다. 이때
  **"선택했지만 지금 안 떠 있음: 산림청"** 을 목록 아래에 남겨 조건이 살아 있음을 보이게 한다.

## 7. 코드 구조

새 폴더 `frontend/src/features/traffic/` 하나로 모은다.

| 파일 | 책임 | 의존 |
|---|---|---|
| `trafficFilter.js` | 순수 계산. ① 필터 설정 → MapLibre 표시 규칙, ② 항공기 목록 → 소속별/전체 대수, ③ ft↔m 변환 | `airlines.js`, `operators.js` |
| `useTrafficFilters.js` | 필터 상태 + 브라우저 저장/복원 | `trafficFilter.js` |
| `TrafficPanel.jsx` / `.css` | 화면만. 상태를 갖지 않고 props로 받는다 | 기존 `layer-drawer` 클래스 |

수정하는 기존 파일:

- `app/layout/Sidebar.jsx` — `항적` 항목과 `PANEL_MAP` 항목 추가
- `app/layout/MobileMapOverlay.jsx` — 모바일 버튼 추가
- `app/App.jsx` — 패널 연결, 필터 상태 보유
- `features/map/MapView.jsx` — `activePanel === 'traffic'` 분기, 표시 규칙 적용
- `features/weather-overlays/WeatherOverlayPanel.jsx` — `traffic` 그룹 제거

**`addAdsbLayer.js`는 수정하지 않는다.** 레이어 이름(`ADSB_LAYER_ID`, `ADSB_LOGO_LAYER_ID`,
`ADSB_TRAIL_LAYER_ID`)이 이미 밖으로 노출되어 있어 규칙만 밖에서 걸면 된다.

## 8. 세 겹 모두에 걸어야 한다

항공기는 세 겹으로 그려진다.

| 레이어 | 처리 |
|---|---|
| `adsb-layer` (아이콘) | 필터 규칙 적용 |
| `adsb-logo-layer` (항공사 로고) | 자체 조건 `['!=', ['get','operator'], '']`이 이미 있으므로 **AND로 묶어** 적용 |
| `adsb-trail-source`/`adsb-trail-layer` (지나온 궤적) | 궤적 데이터에는 `icao24`만 있다 → **보이는 기체의 `icao24` 목록**으로 걸러 적용 |
| `adsb-range-layer` (수신 범위 원) | 항공기가 아니므로 그대로 둔다 |

아이콘만 숨기면 숨긴 기체의 로고나 궤적이 지도에 남는다.

## 9. 잘못될 수 있는 것

| 상황 | 처리 |
|---|---|
| 저장값이 옛 버전/깨진 형식 | 조용히 무시하고 기본값(전체 표시). 저장 키에 버전을 붙인다 |
| 저장된 소속 코드가 명단에서 사라짐 | 무시. 단 6절의 "안 떠 있음" 줄로 사용자에게 보인다 |
| 필터 결과가 0대 | "조건에 맞는 항공기 없음"과 `필터 초기화` 버튼을 함께 보여준다. 수신 실패와 구분한다 |
| `/api/adsb` 응답 실패 | 기존 처리 유지. 패널은 "수신 없음"으로 표시 |
| 군용·익명 송출 기체 | 애초에 데이터에 없다. 스펙 범위 밖이며 "미분류"와 다른 문제임을 문서에 남긴다 |

## 10. 검증

**단위 테스트** — `trafficFilter.test.js`

- 소속 그룹 판정 (항공사 / 기관·훈련기 / 미분류)
- 그룹 체크 = 개별 전체 체크와 같은 결과
- 아무것도 선택하지 않으면 전체 통과
- 고도 경계값 (구간 양끝 포함), ft↔m 변환
- 고도 미보고 기체: 전 구간이면 표시, 구간을 좁히면 숨김
- 검색어가 있으면 다른 필터를 무시
- 대수 계산 (보이는 수 / 전체 수, 소속별 수)

**브라우저 검증(Playwright)** — ADS-B를 켜서 실제 데이터가 들어온 상태로

- 사이드바 `항적` → 패널 열림, 기상 패널에는 `항적` 그룹이 없음
- 소속 하나만 체크 → 지도 위 항공기 수가 줄어들고 하단 카운트와 일치
- 고도 구간을 좁힘 → 남은 기체가 모두 구간 안
- 검색어 입력 → 해당 기체만 남음
- 새로고침 → 필터 유지, ADS-B 표시는 꺼진 상태
