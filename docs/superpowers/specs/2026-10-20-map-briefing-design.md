# 지도형 비행 전 브리핑 설계

- 작성: 2026-10-20 (같은 날 시안 8까지 반영해 갱신)
- 상태: 화면 설계 확정, 구현 계획 미작성
- 최종 시안: [docs/design/mockups/2026-10-20-map-briefing-v8.html](../../design/mockups/2026-10-20-map-briefing-v8.html) — 상단 버튼으로 상태 전환. v1~v7은 검토 이력.
- 배경: [운영 사이트 신규 사용자 테스트](../../research/2026-10-20-live-site-new-user-test.md)
- 인계: [status](../status/2026-10-20-map-briefing.md)

## 1. 목적

지금 브리핑 결과는 "한쪽 지도 + 한쪽 문서"라 지도와 문서가 따로 놀고 가독성이 높지 않다. 브리핑 결과를 **지도 한 화면**으로 다시 짜서 위치(지도)·고도(연직단면·고도 슬라이더)·시간(시간 막대)·위험(위험 막대)을 한 번에 보게 한다.

함께 막을 테스트 결과:
- F1: "계획고도에서 조우하는 위험 없음" 바로 아래 SEVERE 난류 → 위험 판단을 위험 막대 한 곳으로 통일.
- F2: 비교하지 않은 고도를 "추가 위험기상 없음"으로 표시 → "없음"과 "확인 불가" 구분.
- F3: 총 거리에서 SID·STAR 누락 → 선행 수정.

## 2. 결정 사항

| 항목 | 결정 |
|---|---|
| 보기 | 지도형이 기본, "문서형 보기"로 기존 BriefingView 전환 |
| 기기 | 폭 1280 이상만 지도형. 그보다 좁으면 문서형 |
| 원칙 | **화면이 스스로 움직이지 않는다.** 시간·고도·과거 자료는 사용자가 조작할 때만. 따라가기 모드는 범위 밖 |
| 세로 배치 | 지도(위) → 독(위험 막대 + 연직단면도) → 시간 막대(맨 아래) |
| 위험 전달 | **위험 막대**가 맡는다(기존 enroute 리본 확장). 패널은 요약 한 줄 |
| 위험 막대 구성 | **현상별 줄**(난류·착빙·대류 + 해당 시 태풍·시정/운고). 한 줄 안에 **모델 막대 + 예보관 발표 틀** |
| 강도 기준 | 모델 막대는 MODERATE 이상만. LIGHT는 연직단면도에서 |
| 연직단면도 | **기존 UI 그대로**(레이어 토글·범례·확대 등). 새로 만들지 않음 |
| 공항 카드 | 시간 막대와 연동 안 함. 기본 접힘 3줄, 눌러서 펼침. METAR·TAF 각각 ◀▶ 과거 보기 |
| TAF 기본 범위 | ETD/ETA **±1시간** |
| 상단 버튼 | 브리핑 중에는 [항공정보 · 기상정보 · 브리핑]. 연직단면도 버튼 숨김 |

## 3. 화면 구성 (기준 1920×1080, 사이드바 56px은 기존 그대로)

### 3.1 상단 버튼과 브리핑 패널
- 지도 왼쪽 위(20/20): [항공정보 · 기상정보 · **브리핑**]. 브리핑 = 패널 켜기/끄기(켜짐 강조). 기존 연직단면도 버튼은 브리핑 화면에서 숨김.
- 패널(버튼 아래, 위 72, 폭 288): 머리("비행 전 브리핑" + ✕ = 브리핑 버튼과 같은 동작), 경로 24px + IFR/VFR 배지, 공항명(교체 있으면 "교체 김해")·날짜, 숫자 3칸(ETD·ETA·순항), 거리·소요·TAS·시간대 한 줄.
- 요약(callout): 내 고도에서 만나는 가장 센 위험 1건. 없으면 초록 "내 고도에서 MOD 이상 위험 없음", 모델 자료 없으면 회색 "난류·착빙 확인 불가". 누르면 해당 막대 선택.
- 버튼: 문서형 보기(주), 저장(비로그인이면 앱 안 로그인 창, F12), 수정. 그 아래 "브리핑 종료 · 경로 입력으로"(패널 닫기와 구분).
- 패널을 닫아도 브리핑 화면(막대·단면·카드)은 유지.
- "전 구간 VFR" 문구 폐지. 공항 등급은 공항 카드에만.

### 3.2 공항 카드
- 출발·도착(교체 지정 시 교체까지) 공항 옆 지시선. 경로·다른 카드를 가리지 않는 쪽, 넘치면 경로 반대편 → 최대 높이 안 스크롤.
- **접힘(기본)**: 머리(역할 배지·ICAO·공항명·비행등급·깃발) + `METAR 시각 | 값` + `TAF ETD/ETA±1h | 기준 시각 값`. ±1h 안에 다른 변화가 있으면 "앞뒤 변화 n건 · 펼쳐 보기". 깃발: 공항경보(빨강), 윈드시어(보라), NOTAM n(빨간 테두리).
- **펼침**:
  - 경보 띠(공항경보·윈드시어): 발효 중이거나 ETD/ETA ±1h와 겹칠 때. 종류·발효 시각(KST)·요지.
  - METAR: 관측 시각·"최신" + ◀▶, 값(시정·운고 굵게).
  - TAF: 발표 시각 + "전문" + ◀▶. ±1h 구간 표(BECMG·TEMPO·PROB 배지, 기준 시각 줄 파란 선). 전문 = 시간 열+값 열 표, 직전 발표 대비 변경 표시, 원문(TAC).
  - NOTAM: 공항 해당 수 + 가장 중요한 1건, 누르면 목록.
  - 상세(AMOS·이륙예보): 사용 활주로, 2분 평균 바람, 정풍·측풍, 운고, RVR·MOR / 이륙예보(ETD 앞뒤 시간별 바람·기온·QNH). METAR와 AMOS가 다르면 출처·시각 차이 한 줄(F22).
- **과거 보기**: 최신이 아니면 주황 띠 "과거 관측 보는 중 · n건 전" + "최신으로". 이전 자료 없으면 ◀ 비활성.

### 3.3 지도
- 기본: 경로선, 지점 이름, 경로 위 **내 고도 모델 위험 구간 색 띠**(SEV 빨강, MOD 노랑, 태풍 보라).
- 위험 막대를 가리키면 경로 해당 구간 하이라이트(미리보기). **누르면**:
  - 경로 구간 하이라이트 + 시작·끝 지점 이름표.
  - 해당 지도 레이어가 꺼져 있으면 켠다. 모델 막대 → 난류(KIM GKTG) / 구름·착빙 / 대류영역(실험), 예보관 틀 → SIGMET(국내) / AIRMET, 태풍 → 태풍.
  - 켰다는 안내를 잠깐 띄움("난류(KIM GKTG) 레이어를 켰습니다 · FL250 · 09:45 KST [끄기]"), 기상정보 버튼에 개수 배지.
  - 고도·시간은 바꾸지 않는다(고도 기본이 순항고도라 순항고도로 그려짐). 켠 레이어는 선택을 풀어도 유지.
  - 상승·강하 구간 위험(예: 접근 중 4,000–2,000ft)은 순항 레이어에 안 보일 수 있어 팝오버에 "이 위험은 4,000–2,000ft · 고도 슬라이더로 확인" 안내만. 고도는 그대로.
  - 영역 도형을 따로 그리지 않는다.
- 브리핑 화면에서 상단 SIGMET·AIRMET 칩 숨김. 오른쪽 위 자료 시각 카드는 유지.

### 3.4 고도 슬라이더 (지도 오른쪽, SFC~FL450)
- 고도축(레일 12px) 위에 위험 고도를 직접 표시: **모델 위험 = 칠함**(내 고도 꽉 찬 색, 다른 고도 빗금), **예보관 발표 = 테두리만**(내 고도 실선, 다른 고도 점선). 범위가 넓은 발표(예: TS SFC–FL320)가 축 전체를 덮지 않게 하기 위함.
- 비행 범위(SFC~순항)는 시간 막대의 ETD~ETA 창처럼 축을 감싸는 테두리 상자.
- 고도와 무관한 위험(태풍)은 축에 그리지 않고 슬라이더 위 "태풍 · 전 고도".
- 손잡이 기본 = 순항고도. 말풍선은 그 고도의 내 고도 위험 색 + 글자("FL250 · 난류 SEV").

### 3.5 독: 위험 막대 + 연직단면도
- 위쪽 손잡이로 독 높이 조절. **위험 막대와 연직단면도를 따로 접기**(각 머리의 접기 버튼). 접은 상태와 높이는 다음 브리핑에도 유지.

**위험 막대(새로 만듦)**
- 머리: "경로상 위험 · 막대 = 수치예보(내 비행 고도·MOD 이상) · 틀 = 예보관 발표 SIGMET/AIRMET · 경로 전체" + 접기.
- 줄: **난류 · 착빙 · 대류**(항상), **태풍**(경로에 걸릴 때), **시정·운고**(해당 AIRMET이 있을 때).
- 한 줄 안:
  - **꽉 찬 막대 = 수치예보**: 난류 KIM GKTG, 착빙 KIM, 대류 KIM 대류영역(실험). 비행 고도 단면을 따라 MOD 이상 구간.
  - **테두리 틀 = 예보관 발표**: 위에 이름표(출처·현상·고도·내 고도/다른 고도). 내 고도와 겹치면 진한 실선, 다른 고도면 점선. SIGMET 빨강, AIRMET 갈색.
  - 모델 결과가 없으면 "모델 MOD 이상 없음", 자료 실패면 회색 빗금 "단면 자료 없음 · 확인 불가".
- 현상 배정: SIGMET TURB·MTW → 난류 / ICE → 착빙 / TS(EMBD·OBSC·FRQ·SQL) → 대류 / TC → 태풍. AIRMET MOD TURB·ICE → 해당 줄, 지표 시정·운고·지상풍 → 시정·운고 줄. 낙뢰는 관측 자료라 넣지 않음. VA는 수집 자료 없음.
- 라벨 열(폭 176): 눈 아이콘(막대·지도 표시 켜기/끄기) · 색 · 이름 · 상태 칩 = 모델 결과(SEV/MOD/없음/확인 불가) + 발표 칩(SIG/AIR, 실선=내 고도, 점선=다른 고도).
- 줄 높이: 막대만 24, 틀 있는 줄 36(이름표 자리), 빈 줄 16. 가로축 = 경로 거리(SID·STAR 포함), **항상 경로 전체**.
- 연직단면도가 확대돼 일부만 보일 때 그 구간을 막대 위 테두리 창으로 표시(확대 연동은 하지 않음). `VerticalProfileViewer`의 보이는 범위(`range`)를 밖으로 넘겨받는다.

**막대·틀 상세 팝오버**
- 강도 칩·이름·출처, "내 비행 고도에서 만남/다른 고도", 구간(지점→지점, NM), 통과 시각·지속(바람 미반영 표기), 고도·단계, 자료 발표·유효 시각, (상승·강하 구간이면) 고도 안내.
- "지도·슬라이더를 이 구간으로" 버튼: 누를 때만 시간·고도 손잡이와 지도 이동. 닫기·Esc·바깥 클릭.

**연직단면도(기존 그대로)**
- 지금 앱의 `VerticalProfileViewer`/`VerticalProfileChart` UI와 기본값을 그대로: 레이어 줄(구름·착빙·난류 | 바람깃·등풍속선·권계면·제트 | 등온선·SIGMET/AIRMET), 세부 설정, ‹ 시각 › · 시간대, −·+·전체, 크게 보기, TOD 안내, 지점 축, 전체 경로 미니맵, 범례, 자료 정보, 커서 연동. 결빙고도(등온선)·구름은 기존 레이어로 충분.
- 시안의 단면 그림은 자리만 잡은 것이며 이 문서와 기존 UI가 우선.

### 3.6 시간 막대 (맨 아래, 높이 56)
- 라벨 열 "시간 · KST". 지난 시간 진한 선, ETD~ETA 테두리 창, 현재 시각 점선, 둥근 손잡이. 위험 표시 없음.
- 기본 범위 ETD−2h15 ~ ETA+3h. 손잡이 기본 = ETD(지났으면 현재). 끌 때만 지도 기상 레이어 시각이 바뀜. 공항 카드는 영향 없음.

### 3.7 폭 1280~1919
패널 264, 공항 카드 280, 막대 라벨 열 144. 나머지 동일.

## 5. 새로 만들거나 먼저 고칠 것

1. **총 거리(F3, 선행)**: `shared/route-planning/routePlanner.js:420`의 `totalDistanceNm`은 SID·STAR를 빼고 공항↔첫/끝 지점을 직선으로 잇는다. ETA 계산(`useRouteBriefing.js` `plannedEtaDistanceNm`, `computeEtaIso` 호출부들, `shared/route-planning/planRoute.js` `buildAppliedRouteInputs`)과 경로 비교 화면이 이 값을 쓴다. 이미 SID·STAR를 더하는 `buildIfrDistanceBreakdown`(`routeBriefingModel.js`)과 브리핑 생성용 `plannedDistanceNm`이 따로 있어 화면마다 값이 다르다. 한 계산으로 통일하고 기상이(AI)도 같은 값을 쓰게 한다.
2. **대류 모델 막대**: 대류영역(실험) 자료를 비행 고도 단면을 따라 구간으로 만드는 계산.
3. **공항 METAR·TAF 이력 API**: 현재 보관 수집본으로. 화면에는 있는 만큼만. TAF 보관 기간 확대·AMD 수집은 별도.
4. **지도형 브리핑 화면**: 기존 `MapView`의 브리핑 지도 모드(`routeBriefingMapMode`, "지도에 관련 레이어 보기")를 출발점으로.
5. **기존 요소 조정**: TimelineRail(ETD~ETA 창), NwpSliderBar(위험 표시·비행 범위 상자·말풍선), 상단 레이어 버튼(브리핑 버튼), VerticalProfileViewer(보이는 범위 밖으로 전달만).

## 6. 자료가 없거나 틀릴 때
- 모델 단면 실패: 모델 막대 "확인 불가", 패널 요약 회색. 예보관 틀은 그대로 표시.
- 과거 METAR·TAF 없음: ◀ 비활성 + "보관된 이전 자료 없음".
- 공항 좌표 없음(해외): 태풍 판정 "모름"(기존 규칙).
- 현재 시각 난류가 하루 전 예보를 고르는 문제(F4)는 원인 확인 후 별도 수정.

## 7. 확인 방법
- 단위: 막대 구간 → 통과 시각, 내 고도/다른 고도 분류, 현상→줄 배정, TAF ±1h와 "앞뒤 변화 n건", 과거 보기 이동, 막대 → 켤 레이어.
- 화면(Playwright): 남북형(RKSI→RKPC)·동서형 경로, 기본·막대 누름·카드 펼침·자료 없음.
- 회귀: 문서형 보기, 독 안 연직단면도가 기존과 같은 동작, 막대·단면 따로 접기.

## 8. 범위 밖
따라가기 모드, 휴대폰 지도형, 단면 회전 배치, 착빙 LIGHT 막대, 낙뢰, SIGWX, 화산재, 개황, TAF 보관 확대·AMD 수집, 막대-단면 확대 연동.

## 9. 열린 질문
- 기본 상태에서 연직단면도를 접어 둘지(시안 8 기본은 펼침 → 지도 약 49%). 접으면 지도 약 75%.
- 조종사가 모델 SEV를 SIGMET과 같은 무게로 읽는가.
- 공항 카드 깃발만으로 공항경보를 놓치지 않는가.
- 교체공항 TAF 기준 시각(ETA ±1h vs 교체공항 도착 예상 시각).
