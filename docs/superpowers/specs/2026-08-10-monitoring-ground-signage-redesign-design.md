# 모니터링 지상 화면 사이니지 재구성 설계

## 목적

1920×1080 고정 사이니지에서 `/monitoring` 지상 화면의 왼쪽 정보 영역을 멀리서도 빠르게 읽을 수 있도록 재구성한다. 상단 헤더와 오른쪽 지도는 그대로 유지하며, 왼쪽 영역만 경보·현재 관측·예보의 우선순위에 맞게 다시 배치한다.

예보 영역은 시간별 예보와 주간 예보가 같은 공간을 번갈아 사용한다. 두 화면 모두 개별 카드의 모음이 아니라, 공통 열과 행을 공유하는 하나의 정보 표로 보이게 한다.

## 범위

### 포함

- 지상 모드 왼쪽 정보 영역의 높이와 내부 레이아웃 조정
- 경보명과 발효시각의 사이니지용 타이포그래피 조정
- 현재 관측값과 날씨 아이콘 확대
- 현재 관측 6개 지표에 의미가 분명한 아이콘 병기
- 시간별 예보를 하나의 8열 그리드와 통합 SVG 그래프로 재구성
- 주간 예보를 하나의 6열 표로 재구성
- 예보 영역만 12초 간격으로 자동 전환
- 예보 제목에 현재·다음 상태와 전환까지 남은 시간을 나타내는 진행선 표시
- 1920×1080 Playwright 캡처와 레이아웃 계약 검증

### 제외

- 상단 헤더, 공항 선택 UI, 오른쪽 지도, 지도 오버레이의 시각 또는 동작 변경
- 운항 모드와 다른 모니터링 모드의 변경
- 백엔드 API, 응답 스키마, 데이터 수집 로직 변경
- 모바일·태블릿용 별도 반응형 설계
- 수동 탭, 이전·다음 버튼, 페이지 표시점 등 예보 전환 조작부
- 여러 종류의 경보 또는 예보를 추가로 순환하는 슬라이드쇼

## 고정 화면 구조

- 기준 화면은 1920×1080이다.
- 기존 상단 헤더 높이와 오른쪽 지도 위치·크기는 변경하지 않는다.
- 왼쪽 콘텐츠의 기존 가로 경계는 유지한다. 기준 좌표는 `x=20`, 폭 `1015px`이며, 지도는 기존 `x=1055`, 폭 `845px`을 유지한다.
- 헤더 아래 왼쪽 세 영역은 다음 높이로 고정한다.

| 영역 | 높이 | 정보 영역 내 비율 |
| --- | ---: | ---: |
| 경보 | 130px | 약 14% |
| 현재 관측 | 300px | 약 32% |
| 예보 | 507px | 약 54% |

- 영역 사이 간격은 기존 리듬과 같은 `12px`로 유지한다.
- 기준 세로 위치는 경보 `y=74`, 현재 관측 `y=216`, 예보 `y=528`이다.
- 영역 높이는 데이터 유무에 따라 줄어들거나 늘어나지 않는다. 빈 상태도 같은 프레임을 유지한다.

## 경보 영역

- 현재 경보 데이터와 경보의 의미 색상은 그대로 사용한다.
- 경보명은 약 `30px`, 발효시각은 약 `20px`로 표시한다.
- 출처, 단계, 부가 표기는 기존 의미를 유지하되 경보명과 발효시각보다 시각적 우선순위를 낮춘다.
- 경보가 없을 때도 130px 높이를 유지하고 기존의 무경보 안내를 중앙에 안정적으로 배치한다.

## 현재 관측 영역

### 현재 날씨 요약

- 현재 날씨 아이콘은 약 `104px`로 확대한다.
- 현재 기온은 `64px`, 체감온도는 `20px`, 상태 문구는 `24px`를 기준으로 한다.
- 관측시각과 출처는 상단 메타 정보로 유지하되 현재 기온보다 작게 표시한다.
- 현재 기온, 체감온도, 상태는 한 묶음으로 읽히며 6개 지표와 경쟁하지 않도록 충분한 간격을 둔다.

### 관측 지표 6개

- 습도, 풍속, 일강수량, 미세먼지, 초미세먼지, 자외선의 기존 6개 지표를 `3열 × 2행`으로 유지한다.
- 각 칸은 단순 텍스트 상자가 아니라 `아이콘 + 라벨 + 값` 구조로 표시한다.
- 프로젝트가 이미 사용하는 `react-icons/wi` 계열의 실제 아이콘을 재사용한다.

| 지표 | 아이콘 의미 |
| --- | --- |
| 습도 | 물방울/습도 |
| 풍속 | 바람 |
| 일강수량 | 빗방울 |
| 미세먼지 | 먼지 입자 |
| 초미세먼지 | 연무/미세 입자 |
| 자외선 | 햇빛 |

- 아이콘은 약 `36px`, 라벨은 `17px`, 관측값은 `26px`를 기준으로 한다.
- 아이콘은 보조 수단이며 라벨을 제거하지 않는다.
- 상태 색상은 기존 기준을 재사용하고, 색만으로 상태를 전달하지 않는다.

## 예보 공통 영역

- 시간별 예보와 주간 예보는 동일한 507px 높이의 예보 뷰포트를 사용한다.
- 예보 뷰포트가 두 상태와 자동 전환 타이머를 소유한다.
- 초기 상태는 시간별 예보다.
- 12초마다 시간별과 주간 상태를 번갈아 표시한다.
- 전환은 예보 뷰포트 내부에서만 `opacity`로 이루어지며 지속시간은 `350ms`를 기준으로 한다. 허용 범위는 300~400ms다.
- 경보, 현재 관측, 헤더, 지도는 전환 중에도 움직이거나 다시 배치되지 않는다.
- 전환 레이어는 같은 좌표를 차지해 레이아웃 이동이 없어야 한다.
- 화면에서 숨겨진 상태는 보조기술에서도 숨기고 포커스를 받지 않게 한다.
- `prefers-reduced-motion`에서는 페이드와 진행선 채움 애니메이션을 제거하며 12초 자동 교대는 유지한다.
- 사용자가 조작하는 전환 버튼은 추가하지 않는다.

### 현재·다음 제목과 진행선

- 예보 제목 행 안에 `시간별 예보 | 주간 예보`를 고정된 순서와 위치로 함께 표시한다.
- 두 제목의 위치는 화면이 바뀌어도 이동하거나 서로 뒤바뀌지 않는다. 강조 상태만 교대한다.
- 현재 화면 제목은 약 `24px`의 진한 글자와 굵은 두께로 강조하고, 제목 위에 작은 `현재` 라벨을 둔다.
- 비활성 화면 제목은 약 `22px`의 회색 글자로 낮추고, 제목 위에 작은 `다음` 라벨을 둔다. 예보 상태가 두 개뿐이므로 비활성 제목이 곧 다음 화면이다.
- 두 제목은 상태를 설명하는 표시이며 사용자가 조작하는 탭이나 버튼으로 동작하지 않는다.
- 갱신시각은 제목 행 오른쪽의 기존 위치를 유지한다.
- 제목 행 하단에는 터미널 화면과 같은 방식의 `4px` 진행 트랙을 전체 폭으로 둔다.
- 트랙 배경은 옅은 회색, 채움은 기존 강조색인 파란색을 사용한다.
- 파란 채움은 현재 예보 상태가 나타난 순간 0%에서 시작해 12초 동안 선형으로 100%까지 진행한다.
- 12초가 되면 350ms 페이드 전환과 함께 현재·다음 강조가 교대하고, 새 상태의 진행선은 0%에서 다시 시작한다.
- 진행선과 자동 전환은 동일한 12초 주기 상태에서 파생한다. 별도의 독립 타이머를 두어 서로 어긋나게 하지 않는다.
- 숫자 초 카운트다운은 표시하지 않는다. 매초 바뀌는 숫자가 핵심 기상 수치와 경쟁하지 않게 한다.
- 제목과 진행선은 기존 예보 제목 행 안에서 해결하며 예보 데이터 영역의 높이를 추가로 줄이지 않는다.
- `prefers-reduced-motion`에서는 터미널 화면과 같은 방식으로 진행선을 100% 폭의 낮은 투명도로 고정해 움직이는 채움을 보여주지 않는다.

## 시간별 예보

### 구조

- 앞으로의 예보 중 기존 기준에 맞춰 3시간 간격의 8개 시점을 표시한다.
- 8개의 카드를 만들지 않고, 전체 폭을 공유하는 하나의 8열 그리드로 표시한다.
- 각 열의 시간, 날씨 아이콘, 기온 점, 기온 숫자, 강수 막대, 강수확률 숫자는 같은 열 중심선을 공유한다.
- 시간은 `20px`, 날씨 아이콘은 약 `64px`, 기온은 `32px`, 강수확률은 `20px`를 기준으로 한다. 예보 제목은 `24px`, 갱신 메타 정보는 `17px`를 기준으로 한다.

### 좌표와 스케일

- 8개 열의 중심 좌표는 하나의 `xScale(index)` 또는 동등한 순수 계산 함수에서 만든다.
- 시간, 아이콘, 기온 점, 기온 숫자, 강수 막대, 강수확률 숫자는 모두 이 중심 좌표를 사용한다.
- 기온의 세로 좌표는 표시 데이터의 최저·최고 기온에 상하 1℃ 여유를 둔 하나의 `temperatureScale(value)`에서 계산한다.
- SVG 기온 점과 기온 숫자는 동일한 데이터 값과 동일한 `temperatureScale` 결과를 사용한다. 숫자에는 읽기 위한 고정 시각 오프셋만 적용할 수 있으며, 각 점이나 숫자를 개별 보정하지 않는다.
- 모든 기온이 같을 때도 유효한 중앙선이 나오도록 0 범위 입력을 안전하게 처리한다.

### 기온과 강수 통합 그래프

- 기온 선·점과 강수 막대를 같은 SVG 안에 그린다.
- SVG 위쪽은 기온 선 그래프, 아래쪽은 강수 막대 밴드로 분리한다. 두 영역은 겹치지 않는다.
- 강수 막대는 0~100% 고정 범위의 별도 `precipitationScale(value)`를 사용한다.
- 각 강수 막대에는 흐린 배경 트랙, 확률에 비례한 채움, 강수확률 숫자를 함께 표시한다.
- 기온과 강수는 서로 다른 세로 스케일을 사용하지만, 반드시 동일한 8개 `xScale` 중심을 공유한다.
- 강수확률이 0%여도 트랙과 `0%` 표시는 유지해 열 정렬이 흔들리지 않게 한다.

### 데이터 부족 상태

- 시간별 데이터가 전혀 없으면 기존 의미의 빈 상태를 예보 프레임 안에 표시한다.
- 일부 시점만 있으면 8열 구조를 유지하고 부족한 열은 `-`로 표시한다. 데이터 개수 때문에 열 폭이나 중심 좌표가 바뀌지 않는다.

## 주간 예보

### 구조와 여백

- 기존 기준대로 오늘을 제외한 다음 6일을 표시한다.
- 6개의 카드를 만들지 않고, 하나의 6열 표로 표시한다.
- 표의 왼쪽·오른쪽·아래 내부 여백은 각각 `28px`로 둔다.
- 제목/갱신 메타와 표 사이의 시각적 간격은 `26px`로 둔다.
- 여섯 열은 동일한 폭을 사용한다.

### 공통 행

- 모든 열은 다음 네 행의 경계를 공유한다.

1. 요일과 날짜
2. 오전 날씨 아이콘과 강수확률
3. 오후 날씨 아이콘과 강수확률
4. 최저·최고 기온

- 오전/오후 행 라벨은 6일 데이터 열과 분리된 공통 행 라벨로 표시하며 일별 카드 안에서 반복하지 않는다.
- 날씨 아이콘은 약 `68px`, 요일은 `24px`, 날짜는 `18px`, 강수확률은 `20px`, 최저·최고 기온은 `30px`를 기준으로 한다.
- 각 날짜의 오전·오후·최저·최고 값은 동일한 행 기준선에 맞춘다.
- 날짜별 세로 구분선과 공통 가로 구분선은 표 전체를 연결하되, 카드처럼 보이는 개별 외곽 박스는 사용하지 않는다.

### 데이터 부족 상태

- 주간 데이터가 전혀 없으면 기존 의미의 빈 상태를 예보 프레임 안에 표시한다.
- 6일보다 적으면 6열 구조를 유지하고 부족한 열은 `-`로 표시한다.

## 데이터와 컴포넌트 경계

- 기존 `data.groundForecast`, 현재 날씨, 환경 관측, AMOS 데이터 흐름을 그대로 사용한다.
- 백엔드 계약이나 데이터 정규화 계약을 바꾸지 않는다.
- `MonitoringPage.jsx`는 지상 화면의 세 영역 배치만 담당한다.
- 예보 자동 전환과 두 레이어의 접근성 상태는 전용 예보 뷰포트 컴포넌트가 소유한다.
- `GroundHourlyStrip.jsx`는 시간별 8열과 통합 SVG를 렌더링한다.
- `GroundForecastPanel.jsx`는 주간 6열 표를 렌더링한다.
- 열 중심, 기온 스케일, 강수 스케일 계산은 렌더링 코드와 분리한 순수 함수로 두어 단위 테스트할 수 있게 한다.
- `GroundCurrentWeatherCard.jsx`는 기존 관측 데이터에 아이콘 표현만 더하며 값의 의미와 포맷은 바꾸지 않는다.
- 스타일은 기존 지상 모드 범위 안에 한정해 운항 모드와 다른 페이지에 영향을 주지 않는다.

## 접근성과 사이니지 원칙

- 모든 핵심 정보는 아이콘만으로 전달하지 않고 텍스트 라벨이나 수치를 함께 제공한다.
- 장식용 아이콘은 보조기술에서 숨긴다.
- 그래프에는 시간별 기온과 강수확률을 설명하는 접근 가능한 이름 또는 텍스트 대체를 제공한다.
- 숨겨진 예보 상태가 중복 낭독되지 않도록 한다.
- 고정 거리에서 읽는 화면이므로 작은 보조 문구를 늘리지 않고, 합의된 큰 수치와 명확한 정렬을 우선한다.

## 검증

### 단위/컴포넌트 검증

- 시간별 슬롯이 항상 8개이며 각 행 요소가 동일한 8개 중심 좌표를 사용하는지 검증한다.
- 기온 점과 기온 숫자가 같은 `temperatureScale` 결과에서 파생되는지 검증한다.
- 같은 기온만 들어오는 경우와 최저·최고 범위가 있는 경우를 모두 검증한다.
- 강수 막대가 0%, 중간값, 100%에서 정해진 밴드를 벗어나지 않는지 검증한다.
- 주간 슬롯이 항상 6개이고 모든 열의 네 행 경계가 같은지 검증한다.
- 자동 전환이 시간별에서 시작해 12초마다 주간/시간별로 교대하며, 타이머가 정리되는지 검증한다.
- 시간별 상태에서는 시간별 제목이 `현재`, 주간 제목이 `다음`으로 표시되고, 주간 상태에서는 강조와 라벨만 반대로 바뀌는지 검증한다.
- 진행선이 상태 시작 시 0%, 6초 부근에서 약 50%, 12초 직전에 약 100%이며 상태가 바뀐 뒤 다시 0%로 시작하는지 검증한다.
- 진행선과 페이드가 같은 자동 전환 주기를 사용해 장시간 실행 후에도 서로 어긋나지 않는지 검증한다.

### Playwright 브라우저 검증

- 프로젝트의 실제 dev server와 모니터링 fixture를 사용한다.
- 뷰포트와 페이지 화면은 1920×1080으로 고정한다.
- 초기 시간별 상태를 캡처한다.
- Playwright 시계를 12초 진행시키고 페이드 종료 시점까지 진행한 뒤 주간 상태를 캡처한다.
- 두 캡처에서 상단 헤더와 오른쪽 지도의 위치·크기가 기존 계약과 같은지 확인한다.
- 전환 전후 경보와 현재 관측 영역의 bounding box가 동일한지 확인한다.
- 시간별의 시간, 아이콘, 기온 점/숫자, 강수 막대/숫자의 열 중심이 허용 오차 안에서 일치하는지 확인한다.
- 주간 표의 좌우·아래 28px 여백, 제목 아래 26px 간격, 공통 행 경계를 확인한다.
- 전체 문서와 각 패널에 가로·세로 overflow가 없는지 확인한다.
- 캡처 결과는 기존 브라우저 검증 정책이 지정한 Linux 아티팩트 위치에 저장한다.

## 완료 조건

- 1920×1080에서 헤더와 오른쪽 지도가 변경되지 않는다.
- 왼쪽 영역이 130px / 300px / 507px 높이로 안정적으로 구성된다.
- 경보명, 현재 기온, 관측값, 시간별 기온과 아이콘이 합의된 사이니지 크기로 표시된다.
- 현재 관측 6개 지표에 의미가 분명한 아이콘과 텍스트 라벨이 함께 보인다.
- 시간별 예보가 하나의 8열 그리드로 보이고 모든 요소가 같은 열 중심을 공유한다.
- 기온 점과 숫자가 동일한 데이터 스케일에서 계산된다.
- 강수 세로 막대가 기온 그래프와 같은 SVG 안의 하단 밴드에 표시된다.
- 주간 예보가 충분한 내부 여백을 가진 하나의 6열 표로 보이고 공통 행이 정렬된다.
- 예보 영역만 12초마다 350ms 페이드로 자동 교대한다.
- 두 예보 제목이 고정된 위치에 함께 보이고 현재 제목과 다음 제목의 강조 상태가 전환과 함께 교대한다.
- 제목 행 하단의 4px 파란 진행선이 다음 전환까지의 12초를 나타내며 전환 후 다시 시작한다.
- Playwright의 시간별·주간 1920×1080 캡처와 정렬·overflow 검증이 통과한다.

## 전제와 결정 사항

- 화면은 1920×1080 고정 사이니지로 운용한다.
- 예보 전환은 자동 전환만 제공한다.
- 자동 전환 표시는 `시간별 예보 | 주간 예보` 고정 제목, 현재·다음 강조, 4px 파란 진행선의 B안으로 확정한다.
- 시간별과 주간의 정보 구조, 글자·아이콘 크기, 강수 막대 통합 방식, 주간 패널 여백은 검토된 목업 기준으로 확정한다.
- 구현 단계에서 새로운 사용자 선택이 필요한 미결 사항은 없다.
