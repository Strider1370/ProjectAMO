# KIM 지상기압 일기도 레이어 설계

## 목적

기상청 KIM 수치모델 그래픽 API의 지상 해면기압 일기도를 메인 Mapbox 지도에 시험 레이어로 제공한다. 한 장의 그래픽에는 해면기압 등압선과 고기압/저기압(H/L) 중심·중심기압이 포함된다.

## 범위

- KMA `retModelImgUrl`을 사용한다. 요청은 `modl=GDAPS_KIM`, `varGrp=UNIS_SFC`, `var=PRMSL`, `lev=0`, `PROJ=LCC`, `mapRange=EASIA`로 고정한다.
- 호출 인증은 KIM 격자 수집 키가 아니라, 수치모델 그래픽 API 활용 권한이 활성화된 `KMA_AVIATION_AUTH_KEY`를 사용한다.
- UM 전용 `retComposite2ImgUrl`은 사용하지 않는다. 강수 음영은 이 작업 범위가 아니다.
- MET 패널에 `지상기압` 토글을 추가한다.
- 현재 KIM NWP와 동일한 3시간 예보 축과 연결한다.
- KMA가 그린 H/L·등압선 그래픽을 그대로 렌더한다. 별도 H/L·전선·기압골/능 자동 진단은 이 작업 범위가 아니다.

## 수집 및 보존

- 모델 런은 00, 06, 12, 18 UTC를 대상으로 한다.
- 각 런에서 `analTime`은 모델 발표 시각으로, `foreTime`은 `+0, +3, +6, +9, +12, +15, +18시간` 유효시각으로 호출한다.
- 따라서 정상 수집은 런당 7장, 하루 28회 호출이다. 각 호출은 최초 요청 뒤 한 번만 재시도한다.
- 각 프레임 메타에는 `analysisTimeMs`, `validTimeMs`, KMA 출처, 파일 경로와 지도 경계를 저장한다.
- 최신 정상 런 한 세트(7장)만 보관한다. 새 런이 완전히 수집된 뒤에만 이전 런 세트를 정리한다. 실패 시 마지막 정상 세트를 유지한다.
- PNG의 투명 알파는 서버에서 정규화하고, KMA LCC 원본은 Web Mercator용 이미지로 재투영한 뒤 저장한다.

## 지도 및 타임라인 동작

- 별도의 시간축은 만들지 않는다. 기존 타임라인의 미래 NWP 3시간 눈금을 사용한다.
- 선택한 유효시각과 일치하는 프레임을 표시한다. 눈금 사이의 선택은 기존 NWP 선택 규칙과 동일하게 가장 가까운 3시간 프레임으로 해석한다.
- 관측 과거 구간에는 프레임을 표시하지 않는다.
- 동일한 유효시각의 프레임이 둘 이상이면 가장 최신 `analysisTimeMs`를 선택한다.
- 토글을 끄면 이미지 레이어와 공통 기상자료 시각 항목을 즉시 숨긴다.
- 스타일/베이스맵 교체 후에도 해당 시점과 토글 상태로 레이어를 복구한다.

## 공통 시각 표시

토글이 켜져 있고 프레임이 선택된 경우 기존 `기상자료 시각` 패널에 다음 정보를 한 줄로 노출한다.

`지상기압  발표 <analysis time> · 유효 <valid time>`

표시 시간대는 기존 앱 시간대 설정(KST/UTC)을 따른다.

## 오류 및 검증

- API 오류, 빈 이미지, 잘못된 이미지 크기 또는 재투영 실패는 프레임으로 발행하지 않는다.
- 마지막 정상 프레임이 있으면 이를 유지하고, 없으면 레이어를 숨긴다.
- 수집기: 7개 시각 요청, 메타 작성, 새 런 원자적 교체, 실패 시 이전 런 보존을 테스트한다.
- 프런트엔드: 프레임 선택, 과거 구간 비표시, 최신 발표시각 우선, 토글과 공통 시각 패널 동기화를 테스트한다.
- 브라우저: 메인 지도에서 토글, 미래 시각 전환, 과거 시각 전환, 베이스맵 두 번 교체 후 복구를 검증한다.
