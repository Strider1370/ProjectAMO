# 모니터링 조건부 안전모드 슬라이드 설계

**상태:** 검토 요청  
**작성일:** 2026-07-30

## 1. 목표

`/monitoring`의 기존 화면 전환 기능에 기상청 영향예보 기반 `안전수칙` 장면을 추가한다.

폭염 또는 한파 영향예보가 사용자가 정한 최소 단계 이상이면 안전수칙 장면을 기존 슬라이드 순환에 포함하고, 조건이 해제되면 다시 제외한다. METAR 온도를 자체 임계값과 비교해 안전모드를 판정하지 않는다.

이 기능의 주 사용자는 공항 지상 근무자다. 영향예보 분야는 `산업`으로 고정한다.

## 2. 핵심 원칙

1. **기상청 영향예보가 판정의 정본이다.** METAR 온도는 기존 기상정보로 표시할 수 있지만 안전모드 활성화 조건으로 사용하지 않는다.
2. **조건 판정은 단순한 스위치다.** 조건 충족 시 안전수칙 장면을 켜고, 조건 해제 시 끈다.
3. **별도 긴급 전환을 만들지 않는다.** 최초 활성화, 단계 상승, 단계 하락 때 즉시 재생하거나 타이머를 초기화하는 전용 로직을 추가하지 않는다.
4. **기존 슬라이드 엔진을 확장한다.** 조건부 안전모드를 위한 별도 재생 시스템을 만들지 않는다.
5. **설정 조합을 과도하게 늘리지 않는다.** 폭염과 한파는 같은 모니터별 설정을 공유한다.
6. **안전수칙 이미지는 검수된 로컬 자산이다.** 외부 사이트의 이미지 URL을 런타임에 직접 불러오지 않는다.

## 3. 용어

| 용어 | 의미 |
| --- | --- |
| 조건부 안전모드 | 영향예보 조건에 따라 안전수칙 장면의 사용 가능 여부가 자동으로 바뀌는 상태 |
| 안전수칙 장면 | 폭염 또는 한파 행동수칙 이미지와 현재 영향예보 정보를 표시하는 슬라이드 장면 |
| 표시 범위 | `전체 화면` 또는 `지도 패널` 중 슬라이드가 전환되는 영역 |
| 최소 표시 단계 | 안전수칙 장면을 활성화할 가장 낮은 영향예보 단계 |
| 유효 예보 | 기상청이 제공한 유효기간이 아직 지나지 않은 마지막 정상 영향예보 |

## 4. 지원 범위

### 4.1 기상 위험

- 폭염
- 한파

두 위험은 동일한 설정과 동일한 재생 규칙을 사용한다. 현재 활성화된 위험에 따라 이미지 목록과 화면 상태 정보만 달라진다.

### 4.2 영향예보 대상

- 지역: 현재 모니터링 중인 공항에 대응하는 기상청 영향예보 지역
- 분야: `산업`
- 단계: 기상청 영향예보가 제공하는 단계

서버는 런타임 외부 지오코딩 대신 검증된 `공항 코드 → 기상청 영향예보 지역코드` 매핑을 사용한다.

## 5. 설정

조건부 안전모드 설정은 현재 모니터의 브라우저에 개별 저장한다. 한 모니터에서 고른 값이 다른 모니터나 브라우저에 전파되지 않는다.

폭염과 한파는 다음 설정을 공통으로 사용한다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 조건부 안전모드 사용 | 꺼짐 | 기상청 영향예보에 따른 안전수칙 장면 사용 여부 |
| 표시 범위 | 전체 화면 | `전체 화면` 또는 `지도 패널` |
| 모니터링 장면 표시 시간 | 180초 | 안전수칙 장면 사이에 기본 모니터링 화면이 유지되는 시간 |
| 안전수칙 장면 표시 시간 | 20초 | 안전수칙 이미지 한 장의 표시 시간 |
| 최소 표시 단계 | 주의 | 선택한 단계 이상일 때 안전수칙 장면 활성화 |
| 전환 효과 | 기존 화면 전환 기본값 | 페이드 또는 슬라이드 |
| 전환 속도 | 기존 화면 전환 기본값 | 기존 허용 범위 안에서 설정 |

설정 화면은 기존 화면 전환 설정의 패턴과 저장 경로를 재사용한다. 재해별 설정, 단계별 표시 범위, 콘텐츠별 표시 범위처럼 별도의 조합은 제공하지 않는다.

## 6. 활성화와 해제

### 6.1 활성화

다음 조건을 모두 만족하면 안전수칙 장면을 활성화한다.

1. 사용자가 조건부 안전모드를 켰다.
2. 현재 모니터링 공항에 유효한 폭염 또는 한파 영향예보가 있다.
3. 산업 분야의 현재 단계가 사용자가 고른 최소 표시 단계 이상이다.
4. 선택한 표시 범위에 사용할 검수된 이미지 자산이 있다.

활성화는 안전수칙 장면의 사용 가능 여부만 `ON`으로 바꾼다. 현재 장면을 중단하거나 안전수칙을 즉시 표시하지 않는다. 기존 슬라이드 순서와 현재 타이머가 계속 진행되고, 안전수칙은 다음 정상 순서에서 표시된다.

### 6.2 해제

정상 API 응답에서 영향예보가 최소 표시 단계 아래로 내려가거나 유효 예보가 종료되면 안전수칙 장면의 사용 가능 여부를 `OFF`로 바꾼다.

해제 시 즉시 복귀, 남은 시간 완주, 타이머 재시작을 위한 전용 분기를 추가하지 않는다. 기존 슬라이드 엔진이 사용할 수 없어진 장면을 처리하는 일반 규칙을 그대로 적용한다.

### 6.3 API 실패와 마지막 정상값

- 일시적인 API 실패만으로 안전모드를 즉시 끄지 않는다.
- 마지막 정상 영향예보가 유효기간 안에 있으면 그 상태를 유지한다.
- 마지막 정상 영향예보의 유효기간이 지난 뒤에도 새 정상 데이터를 받지 못하면 안전수칙 장면을 비활성화한다.
- 실패 응답이나 불완전한 응답이 마지막 정상 예보를 덮어쓰면 안 된다.

발표·유효 시각은 파서 경계에서 출처 시간대를 해석하고 내부에서는 UTC 또는 epoch로 저장·비교한다. 화면에는 프로젝트의 기존 사용자 시각 표시 규칙을 적용한다.

## 7. 슬라이드 순환

안전수칙 장면은 활성화된 동안 기존 슬라이드 목록에 조건부로 포함된다. 기존에 사용자가 꺼둔 장면을 다시 켜거나 기존 순서를 별도로 변경하지 않는다.

가장 단순한 구성의 기본 예시는 다음과 같다.

```text
모니터링 180초
→ 안전수칙 이미지 20초
→ 모니터링 180초
→ 다음 안전수칙 이미지 20초
→ 반복
```

기존 기상정보나 개인 이미지 장면이 사용 설정되어 있으면 해당 장면도 기존 순서와 시간에 따라 계속 재생된다.

### 7.1 여러 안전수칙 이미지

- 이미지 매니페스트는 위험 종류와 표시 범위별 배열을 지원한다.
- 한 번의 안전수칙 구간에는 이미지 한 장만 표시한다.
- 이미지가 여러 장이면 다음 안전수칙 구간에서 다음 이미지를 표시하고, 마지막 이미지 다음에는 첫 이미지로 돌아간다.
- 첫 버전에는 한 안전수칙 구간 안에서 여러 이미지를 다시 넘기는 별도 재생 모드를 추가하지 않는다.

## 8. 표시 범위와 전환

### 8.1 전체 화면

- 모니터링 화면 전체와 안전수칙 화면을 하나의 수평 트랙에 배치한다.
- 슬라이드 효과를 선택하면 현재 모니터링 화면 전체가 자연스럽게 왼쪽으로 이동하고 안전수칙 화면이 오른쪽에서 이어서 들어온다.
- 지도 패널을 포함한 실제 모니터링 화면이 이동해야 하며, 라이브 화면 위에 이미지만 덮어 움직이는 방식으로 대체하지 않는다.
- 전환 중에도 모니터링 데이터 갱신과 지도 상태는 유지한다.

### 8.2 지도 패널

- 모니터링 화면의 나머지 정보는 계속 보인다.
- 지도 패널 안에서만 `지도 ↔ 안전수칙 이미지`가 교대한다.
- 이미지가 표시되는 동안에도 Mapbox 지도를 마운트 상태로 유지해 카메라, 레이어와 로드 상태를 보존한다.

### 8.3 공통 전환 규칙

- 설정한 전환 효과와 속도를 사용한다.
- 기존 화면 전환의 reduced-motion 처리와 활성 운영 알림의 상위 표시 규칙을 유지한다.
- 안전수칙 전환이 기존 알림 평가, 팝업, 마키 또는 데이터 폴링을 멈추거나 가리면 안 된다.

## 9. 안전수칙 자산

안전수칙 이미지는 배포 버전에 포함된 정적 런타임 자산으로 관리한다. 프로젝트 구조 규칙에 따라 브라우저 런타임 자산은 `frontend/public/` 아래에 둔다.

자산 목록은 다음 두 축으로 구분한다.

```text
폭염
├── 전체 화면용 이미지 목록
└── 지도 패널용 이미지 목록

한파
├── 전체 화면용 이미지 목록
└── 지도 패널용 이미지 목록
```

- 사용자가 각 표시 영역에 맞는 크기와 비율의 이미지를 제공한다.
- 런타임 자동 크롭, 포스터 재배치, 여백 합성 또는 다른 비율 자산의 자동 대체는 구현하지 않는다.
- 선택한 위험과 표시 범위에 맞는 이미지가 없으면 안전수칙 장면을 활성화하지 않는다.
- 기존 개인 이미지용 IndexedDB 저장소는 안전수칙 자산 저장에 사용하지 않는다.
- 이미지 교체를 위한 관리자 업로드 기능은 첫 범위에 포함하지 않는다.

## 10. 안전수칙 화면 정보

정적 이미지와 함께 현재 조건을 알아볼 수 있는 간결한 상태 정보를 표시한다.

- 위험 종류: 폭염 또는 한파
- 현재 영향예보 단계
- 현재 모니터링 공항
- 분야: 산업
- 기상청 발표 시각

상태는 이미지의 핵심 내용을 가리지 않는 고정된 상태 바 형태로 표시한다. 단계는 색만으로 구분하지 않고 텍스트 라벨을 함께 사용한다.

## 11. 데이터 경계

기상청 영향예보는 기존 백엔드 데이터 수명주기 규칙을 따른다.

```text
기상청 API
→ API 클라이언트
→ 입력 검증과 파서
→ 정규화 프로세서
→ 마지막 정상 스냅샷 저장
→ 캐시 API
→ 모니터링 데이터 로더
→ 조건부 안전모드 판정
```

- 외부 응답은 파서 경계에서 검증한다.
- 수집 작업은 타입별 잠금과 기존 스케줄러 등록 규칙을 따른다.
- 프론트엔드는 원문 응답 구조가 아니라 정규화된 위험 종류, 지역, 분야, 단계, 발표·유효 시각을 받는다.
- 단계 비교 순서는 하나의 정규화된 도메인 값으로 정의하며 화면 문자열 비교에 의존하지 않는다.

## 12. 기능 요구사항

- FR-001: 시스템은 폭염과 한파의 기상청 영향예보를 지원해야 한다.
- FR-002: 안전모드 활성화 판단은 산업 분야 영향예보를 사용해야 하며 METAR 온도 임계값을 사용하면 안 된다.
- FR-003: 현재 모니터링 공항은 검증된 기상청 영향예보 지역코드에 자동으로 대응되어야 한다.
- FR-004: 사용자는 모니터별 설정에서 조건부 안전모드 사용 여부, 표시 범위, 두 장면의 표시 시간, 최소 표시 단계, 전환 효과와 속도를 정할 수 있어야 한다.
- FR-005: 폭염과 한파는 하나의 공통 모니터별 설정을 사용해야 한다.
- FR-006: 조건 충족과 해제는 안전수칙 장면의 사용 가능 여부만 변경해야 하며 전용 즉시 전환이나 타이머 초기화 동작을 만들면 안 된다.
- FR-007: API 실패 시 유효기간 안의 마지막 정상 영향예보를 보존해야 하고, 유효기간이 지난 뒤 새 정상 데이터가 없으면 안전수칙 장면을 비활성화해야 한다.
- FR-008: 안전수칙 장면은 기존 슬라이드 순환에 조건부로 참여해야 하며 기존 장면의 사용 설정을 변경하면 안 된다.
- FR-009: 한 안전수칙 구간에는 이미지 한 장을 표시하고, 여러 이미지가 있으면 구간마다 다음 이미지를 순환해야 한다.
- FR-010: 전체 화면 슬라이드 효과는 지도 패널을 포함한 실제 모니터링 화면 전체와 다음 화면을 함께 수평 이동시켜야 한다.
- FR-011: 지도 패널 표시는 주변 대시보드를 유지하고 Mapbox 지도를 언마운트하면 안 된다.
- FR-012: 안전수칙 자산은 배포에 포함된 정적 자산이어야 하며 위험 종류와 표시 범위별 목록을 지원해야 한다.
- FR-013: 안전수칙 화면은 위험 종류, 단계, 공항, 산업 분야와 발표 시각을 표시해야 한다.
- FR-014: 조건부 안전모드가 활성화되어도 기존 폴링, 알림 평가와 운영 알림 표시가 계속 동작해야 한다.

## 13. 제외 범위

- METAR 온도 기반 자체 위험 단계 판정
- 폭염·한파 외의 영향예보 위험 종류
- 다른 공항의 도착지 날씨 순환
- 단계에 따른 전체 화면·지도 패널 자동 선택
- 재해별 또는 단계별 별도 시간과 표시 범위 설정
- 활성화나 단계 변경 시 즉시 안전수칙을 재생하는 긴급 중단 로직
- 이미지 자동 크롭, 비율 변환, 재배치 또는 합성
- 외부 이미지 URL 핫링크
- 관리자 이미지 업로드와 원격 자산 관리
- 기존 개인 슬라이드 이미지의 서버 공유

## 14. 수용 기준

- AC-001: 조건부 안전모드를 켜고 현재 공항의 산업 분야 폭염 또는 한파 단계가 설정 임계값 이상이면 안전수칙 장면이 기존 순환의 다음 정상 순서에 나타난다.
- AC-002: 조건이 충족되어도 현재 장면이 즉시 중단되거나 타이머가 다시 시작되지 않는다.
- AC-003: 조건이 해제되면 별도 종료 애니메이션이나 지연 로직 없이 안전수칙 장면이 일반 가용성 규칙에 따라 목록에서 제외된다.
- AC-004: 기본 설정의 단순 구성에서 모니터링 화면은 180초, 안전수칙 이미지는 20초 표시된다.
- AC-005: 이미지가 여러 장이면 각 안전수칙 구간마다 한 장씩 순서대로 바뀐다.
- AC-006: 전체 화면 슬라이드 전환을 녹화하거나 프레임별로 캡처했을 때 지도 패널을 포함한 기존 화면 전체가 왼쪽으로 이동하고 다음 안전수칙 화면이 연속해서 따라온다.
- AC-007: 지도 패널 모드에서 안전수칙이 표시되는 동안 주변 모니터링 카드가 계속 보이고, 복귀 후 지도 카메라와 레이어 상태가 보존된다.
- AC-008: 안전수칙 화면에서 위험 종류, 단계, 공항, 산업 분야와 기상청 발표 시각을 읽을 수 있다.
- AC-009: 일시적인 API 실패 후에도 마지막 정상 예보의 유효기간 안에서는 기존 안전모드 상태가 유지된다.
- AC-010: 유효기간이 지난 뒤 새 정상 예보가 없으면 안전수칙 장면이 표시되지 않는다.
- AC-011: 새 브라우저 프로필에서 조건부 안전모드 설정이 공유되지 않지만, 배포된 안전수칙 자산과 서버 영향예보 데이터는 동일하게 사용할 수 있다.
- AC-012: 사용자 제공 이미지가 선택한 표시 범위의 매니페스트에 없으면 깨진 이미지나 잘못된 비율의 대체 화면 대신 안전수칙 장면 자체가 나타나지 않는다.

## 15. 검증 요구사항

- 단계 정규화, 최소 단계 비교, 공항-지역 매핑, 마지막 정상값 유효기간과 API 실패 처리를 단위 테스트한다.
- 슬라이드 가용성, 이미지 순환과 브라우저별 설정 영속성을 프론트엔드 단위 테스트한다.
- 실제 `/monitoring` 브라우저 계약으로 전체 화면과 지도 패널 두 표시 범위를 각각 검증한다.
- 전체 화면 슬라이드의 실제 수평 이동은 Playwright 스크린샷 또는 영상 프레임 증거로 확인한다. 정적 DOM 존재만으로 통과시키지 않는다.
- 지도 패널 전환 후 Mapbox 카메라와 레이어 상태 보존을 브라우저 계약으로 검증한다.
- reduced-motion 상태와 운영 알림이 안전수칙 위에 유지되는 기존 계약을 회귀 검증한다.

## 16. 기존 기능과의 관계

이 문서는 기존 [Monitoring Personal Slideshow](../archive/specs/2026-07-22-monitoring-personal-slideshow.md)를 대체하지 않는다. 기존 기능에 다음 사항만 확장한다.

1. 서버가 제공하는 영향예보 상태
2. 조건부 `안전수칙` 장면
3. 위험 종류·표시 범위별 배포 이미지 목록
4. 안전수칙 상태 정보

기존 개인 이미지의 브라우저 전용 저장, 기존 장면 설정, 지도 유지와 알림 우선순위 계약은 그대로 보존한다.

## 17. 미결정 사항

사용자 동작에 영향을 주는 미결정 사항은 없다. 정확한 기상청 API 엔드포인트, 수집 주기와 공항별 지역코드 목록은 구현 계획에서 공식 API 계약과 현재 수집기 구조를 확인해 확정한다.
