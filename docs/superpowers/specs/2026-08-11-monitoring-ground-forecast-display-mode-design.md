# Monitoring 지상 예보 표시 모드

## 목적

지상 모드 사용자가 설정창에서 현재의 사이니지형 예보와 이전 카드형 예보 중 하나를 선택할 수 있게 한다. 선택은 즉시 반영되고 다음 접속에도 유지된다.

## 사용자 경험

- 설정창의 지상 모드 설정에 `지상 예보 표시` 선택을 둔다.
- 선택지는 `사이니지형`과 `기존 카드형` 두 가지다.
- 기본값은 `사이니지형`이다.
- 저장을 누르면 모달/인라인 설정창 모두에서 즉시 예보 영역이 전환된다.
- 선택 값은 `localStorage`에 저장한다. 저장된 값이 없거나 잘못된 값이면 `사이니지형`을 사용한다.
- 선택은 지상 모드의 예보 영역에만 적용한다. 공항경보, 현재 날씨, 지도, 운항 모드는 바꾸지 않는다.

## 화면 정의

### 사이니지형

현재의 `GroundForecastViewport`를 유지한다. 시간별·주간 화면을 자동 순환하며, 아이콘 음영·강수 음영·최고/최저 기온 강조를 포함한다.

### 기존 카드형

이전 지상 화면과 같은 구성으로 시간별 예보와 주간 카드형 예보를 함께 표시한다. 시간별 아이콘의 베이지/강수 파란 음영, 주간 오전·오후 강수 셀의 파란 음영, 최저/최고 기온 색상을 유지한다.

## 구현 경계

- `MonitoringPage`가 표시 모드 상태를 소유하고 저장값을 초기화한다.
- `Settings`는 모드 값을 임시 편집하고 저장/초기화 시 상위 콜백으로 전달한다.
- 예보 표시 모드의 읽기·정규화·저장은 작은 순수 유틸리티로 분리한다.
- 기존 카드형은 Git 이력의 예보 컴포넌트를 그대로 복원해 별도 컴포넌트로 연결한다. 새 카드형 디자인이나 데이터 계약은 만들지 않는다.
- 사이니지형 자동 순환 상태와 기존 카드형을 섞지 않는다.

## 오류 처리와 접근성

- 잘못된 저장값은 사용자에게 오류를 보이지 않고 기본 모드로 정규화한다.
- 선택 컨트롤에는 한국어 레이블을 제공한다.
- 전환 후에도 각 예보 영역의 기존 region/table/SVG 접근성 이름을 유지한다.

## 검증

- 순수 유틸리티: 기본값, 유효값, 잘못된 값 정규화와 저장을 테스트한다.
- 브라우저 계약: 설정에서 각 모드를 선택하면 해당 예보 구조만 표시되고, 새로고침 후 선택이 유지되는지 검증한다.
- Playwright로 1920×1080 사이니지형과 기존 카드형을 각각 캡처하고 직접 확인한다.
