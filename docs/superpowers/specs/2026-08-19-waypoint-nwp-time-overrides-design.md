# 웨이포인트 기준 NWP 시간 변경점

## 목표

연직단면도에서 사용자가 웨이포인트를 기준으로 NWP 시간 오프셋 변경점을 만들 수 있게 한다. 기본 동작은 현재처럼 전체 단면도가 하나의 출발시각 기반 NWP 기준시각을 사용하며, 사용자가 지정한 변경점부터만 다른 상대 시각을 적용한다.

## 범위

- 대상은 경로 브리핑의 연직단면도 KIM/KTG 기상 표시다.
- 시간 변경점은 이름 있는 경로 웨이포인트에서만 만들 수 있다. 단면도 거리 축의 임의 위치와 자동 예상 통과시각 계산은 범위 밖이다.
- 기존 전체 NWP 기준시각 선택은 유지한다. 사용자가 기준시각을 바꾸면 모든 변경점의 상대 오프셋도 함께 이동한다.

## 사용자 경험

### 기본 상태

- 단면도 하단 웨이포인트/거리 축 바로 위에 항상 보이는 `NWP 시간 규칙` 레일을 둔다.
- 변경점이 없으면 레일은 전 구간이 기준시각을 쓴다는 상태를 보인다. 현재 단면도 동작은 바뀌지 않는다.
- 자동 예상 통과시각 선택은 제공하지 않는다. 비행 예상시간 계산의 정밀도를 전제하지 않는다.

### 변경점

- 사용자는 시간 레일의 웨이포인트 시간 칩을 눌러 메뉴를 연다.
- 메뉴는 `기준`, `+1h`부터 `+12h`, `변경점 삭제`를 제공한다.
- 선택한 웨이포인트에서 만든 값은 다음 변경점 직전까지, 또는 다음 변경점이 없으면 도착까지 적용된다.
- 예: WP2에서 `+1h`, WP4에서 `+2h`를 선택하면 WP2~WP4 직전은 `+1h`, WP4 이후는 `+2h`를 사용한다.
- 변경점은 시간 레일의 세로 경계선과 시간 칩으로 보여야 한다. 차트 본문이나 기존 웨이포인트 상호작용은 시간 편집을 위해 바꾸지 않는다.

### 사용 가능 시간

- 메뉴에는 현재 KIM 수집 창의 모든 상대 오프셋 `0..12h`를 보여 준다.
- 선택한 전역 기준시각과의 합이 실제 KIM 자료 범위를 벗어나면 해당 항목은 비활성화하고 `수집된 NWP 시간 범위 밖` 이유를 제공한다.
- 자료가 없을 때 가장 가까운 KIM 시각으로 자동 대체하지 않는다.

### KTG 표시

- KIM은 선택한 정확한 시각의 시간장을 쓴다.
- KTG 원천은 `+6/+9/+12h`만 있으므로, KIM 선택시각에 가장 가까운 사용 가능 KTG 시각을 사용한다.
- 단면도/범례는 실제 적용된 KTG 시각을 명확히 표시한다. KIM과 KTG의 실제 시각이 다를 수 있음을 숨기지 않는다.

## 상태와 저장 계약

- 시간 규칙은 실제 NWP 응답, URL, API 키를 저장하지 않고 사용자 선택만 저장한다.
- 저장 경로/저장 브리핑 payload에 전역 기준시각 선택과 변경점 목록을 함께 포함한다.
- 변경점은 표시 이름이 아니라 경로를 재구성할 때 안정적인 웨이포인트 식별자에 연결한다.

```js
{
  nwpTimeSelection: {
    baseTime: '2026-08-19T10:00:00.000Z',
    waypointOverrides: [
      { waypointId: 'stable-waypoint-id', offsetHours: 1 },
      { waypointId: 'stable-waypoint-id-2', offsetHours: 2 },
    ],
  },
}
```

- `baseTime`이 기본 출발시각 기반 선택과 같으면 저장 구현은 이를 생략할 수 있지만, 복원 시에는 동일한 기준시각을 재현해야 한다.
- 저장된 브리핑을 나중에 다시 열 때 해당 NWP 자료가 보관 범위 밖이면 선택을 다른 시각으로 바꾸지 않는다. 저장된 규칙을 그대로 보이고 해당 구간을 자료 없음으로 표시한다.

## 데이터 흐름

1. 전역 NWP 기준시각과 웨이포인트 변경점을 정렬해 각 경로 구간의 상대 오프셋을 계산한다.
2. 각 구간은 `기준시각 + offsetHours`로 KIM 격자를 선택한다.
3. 같은 구간에서 KTG는 선택된 KIM 시각에 가장 가까운 유효 KTG 시간으로 선택한다.
4. 단면도 샘플러는 구간 경계마다 적절한 KIM/KTG 시간장을 읽어 하나의 연속 단면으로 조합한다.
5. UI 레일과 범례는 요청 시각이 아니라 실제 사용한 KIM/KTG 시각과 자료 없음 상태를 보여 준다.

## 오류 및 경계 조건

- 웨이포인트 식별자가 복원된 경로에 없으면 그 변경점은 적용하지 않고 제거 가능한 경고 상태로 표시한다.
- 중복 또는 순서가 뒤바뀐 변경점은 경로의 웨이포인트 순서로 정규화한다. 한 웨이포인트에는 하나의 변경점만 둔다.
- 새 경로 계산으로 웨이포인트 집합이 달라지면, 살아남는 안정 ID의 변경점만 유지한다.
- 데이터 누락, KTG 근접시각 사용, 비활성 시간값은 기존 last-good 원칙을 깨지 않으며 실제 데이터 상태를 명시한다.

## 검증

- 변경점이 없을 때 기존 단일 기준시각 단면도와 동일한 결과를 낸다.
- 웨이포인트 변경점이 이후 구간을 덮고, 다음 변경점에서만 값이 바뀐다.
- 전역 기준시각 변경 시 상대 오프셋이 유지된다.
- `0..12h` 중 범위 밖 선택지는 비활성화되고 자동 대체하지 않는다.
- KIM은 정확한 구간 시각을, KTG는 가장 가까운 `6/9/12h` 시각을 선택하며 실제 KTG 시각을 표시한다.
- 저장·불러오기 후 기준시각과 안정 웨이포인트 변경점이 복원된다.
- 오래된 저장 브리핑에서 자료가 없으면 규칙은 유지하고 자료 없음 상태를 표시한다.
- 데스크톱과 iPad 가로, 모바일에서 시간 레일의 읽기·터치·접근성(44px 터치 타깃, 레이블, 색 이외 시간 텍스트)을 브라우저로 검증한다.
