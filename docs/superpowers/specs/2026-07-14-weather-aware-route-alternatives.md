# 기상 기반 대체 항로 비교 스펙

- 작성일: 2026-07-14
- 상태: 초안
- 적용 범위: 국내 IFR 사전 비행계획

## 1. 목적

조종사가 계획한 항로와 같은 출발·도착 절차를 유지한 대체 en-route 항로를 기상 정보로 비교할 수 있게 한다.

이 기능은 항로를 추천하거나 안전 여부, 연료·성능·관제 수용성, 법적 대체공항 필요 여부를 판단하지 않는다. 각 경로에서 어떤 기상 현상이 사라지거나 새로 나타나는지만 보여 주며, 최종 판단은 조종사가 한다.

## 2. 비교 경로의 구성

비교 대상은 다음 순서의 하나의 전체 경로다.

```text
사용자가 선택한 SID → en-route 항공로 후보 → 사용자가 선택한 STAR → 선택한 IAP(있을 때)
```

- 국내 8개 공항의 SID/STAR 절차 데이터와 각 절차의 구간 거리·좌표를 사용한다.
- 자동으로 바꾸는 범위는 SID와 STAR 사이의 en-route 항공로뿐이다. SID, STAR, IAP는 사용자가 선택한 것을 그대로 붙인다.
- 따라서 이 기능은 절차 변경을 제안하지 않는다.
- 출발·도착 공항에 해당 절차 데이터가 없거나 사용자가 절차를 선택하지 않은 경우, 기존 경로 표시만 제공하고 대체 en-route 항로 자동 생성은 제공하지 않는다.
- 모든 후보는 항공로/FIX 그래프에서 방향과 항로 종류 규칙을 지키는 경로여야 한다. 지도 위 임의 선은 후보가 될 수 없다.

### 2.1 계획 경로 설정과 en-route 직접 수정

기존의 자동 경로 선택 흐름을 유지한다. 사용자가 출발·도착 공항을 입력하면 앱은 SID, en-route 기본 항로, STAR, IAP를 자동 선택해 전체 계획 경로를 보여 준다.

사용자는 별도 `ENR 수정` 영역에서 자동 생성된 en-route 부분만 직접 바꿀 수 있다. SID, STAR, IAP는 기존 선택기에서 별도로 바꾼다.

```text
SID  BINIL3C
ENR  BINIL → Y711 → OLMEN
     [+ FIX 추가]  [+ 항공로 추가]
STAR OLMEN1Y
IAP  RWY 33L
```

- `FIX 추가`: 알려진 FIX/NAVAID만 자동완성으로 검색해 현재 위치에 삽입한다.
- `항공로 추가`: 현재 선택한 FIX에서 연결 가능한 항공로만 보여 준다. 사용자는 이어서 해당 항공로 위의 이탈 FIX를 선택한다.
- 항공로 입력의 유효한 단위는 `진입 FIX → 항공로 → 이탈 FIX`다.
- 앱은 항공로 이름을 간결하게 표시하되, 내부적으로는 중간 FIX를 모두 펼쳐 경로 연결·방향 규칙·거리 계산을 검증한다.
- 사용자가 SID/STAR/IAP를 바꾸면 en-route의 시작/끝 연결을 다시 검증한다. 연결되지 않는 수동 en-route 입력은 사용자에게 수정이 필요하다고 알린다.
- 사용자가 확정한 en-route 경로가 이후 기상 비교의 기준 경로가 된다.

이번 MVP에서는 지도 위 임의 지점으로 경로를 그리거나, 자유 형식 항로 문자열을 붙여넣어 해석하지 않는다. 항로 문자열 입력은 `FIX → 항공로 → FIX` 검증과 오류 표시를 갖춘 후속 단계로 둔다.

## 3. 입력과 계획 통과시각

사용자가 이미 입력하는 ETD, TAS, 순항고도를 사용한다.

- TAS는 성능·연료 계산에 사용하지 않는다.
- TAS는 각 절차 및 en-route 구간의 누적 거리로부터 **계획 통과시각**을 계산하는 데만 사용한다.

```text
구간 통과시각 = ETD + (출발지부터 해당 지점까지의 누적 거리 / 입력 TAS)
```

- SID/STAR/IAP도 경로의 구간 거리로 누적 계산에 포함한다.
- 이 시각은 climb, descent, 실제 관제 지연, 실제 속도 변화를 반영하지 않은 `입력 TAS 기반 계획 시각`으로 표시한다.
- ETD를 바꾸면 모든 후보의 구간 통과시각과 SIGMET 유효시간 비교를 다시 계산한다.

## 4. 기상 자료의 역할

### 4.1 대체 en-route 후보 생성 조건

다음 SIGMET이 경로의 위치·계획 통과시각·순항고도와 겹치면, 해당 위험구역을 탐색 제약으로 적용한 비교 후보를 생성한다.

- 대류: `TS`, `CB`, `SQL_TS`, `OBSC_TS`, `EMBD_TS`, `FRQ_TS`
- 화산재: `VA`
- 열대저기압: `TC`

후보가 없으면 `해당 기상 제약으로 생성된 비교 후보 없음`이라고 사실만 표시한다. 후보 사이에 추천 순위는 만들지 않으며, 표시 순서는 거리 오름차순으로 한다.

### 4.2 후보 생성과 표시 순서

이 기능은 단일한 `기상 위험 점수`를 만들지 않는다. 난류·착빙·낙뢰에 임의 가중치를 주어 서로 다른 현상의 위험도를 앱이 판단하지 않기 위해서다.

후보는 다음의 두 단계로 만든다.

1. 항공로/FIX 그래프에서, 현재 경로와 다른 합법 en-route 경로를 여러 개 찾는다.
2. 각 경로에 선택된 SID/STAR/IAP를 붙이고 구간별 계획 통과시각을 계산한다. 대류/VA/TC SIGMET과 위치·계획 통과시각·고도가 겹치는 경로는 후보에서 제외한다.

남은 후보는 총거리 오름차순으로 최대 3개 표시한다. 이는 추천 또는 안전 순위가 아니라 표시 순서일 뿐이다.

완전히 피하는 후보가 없을 때 `덜 위험한` 경로를 자동으로 만들거나 제시하지 않는다. `해당 기상 제약으로 생성된 비교 후보 없음`으로 표시하고, 현재 경로의 기상 노출 사실만 보여 준다.

### 4.3 고정 절차 구간

SID, STAR, IAP는 사용자가 선택한 고정 구간이며 자동 후보 생성으로 바꾸지 않는다.

- 이 고정 구간에서 대류/VA/TC SIGMET 교차가 있으면 en-route 후보가 이를 해결한 것처럼 표시하지 않는다.
- 후보 카드에는 `선택한 출발/도착 절차 구간에 교차가 남아 있음`을 별도로 표시한다.
- 절차 변경은 사용자가 경로 설정 화면에서 직접 바꾼 뒤 다시 기상 비교를 실행하는 흐름으로 둔다.

### 4.4 비교만 하는 조건

난류, 착빙, 바람, 구름, 운고, 시정, AIRMET/SIGMET의 그 밖의 현상은 후보 생성·제외 조건이 아니다. 각 후보에서의 교차 구간, 계획 통과시각, 고도 범위, 유효시간만 함께 보여 준다.

### 4.5 SIGMET의 위치·시간·고도 비교

- 위험구역과 경로의 교차는 선분-폴리곤 교차로 판정한다. 단순 점 샘플만으로 작은 구역을 놓치지 않는다.
- 교차 구간의 시작·끝 누적 거리로 계획 통과시각 범위를 계산한다.
- 그 범위가 SIGMET 유효기간과 겹칠 때만 해당 후보의 기상으로 표시한다.
- SIGMET 고도 범위가 있으면 입력 순항고도와 비교한다.
- 상한 또는 하한만 있는 값도 그대로 표시하고 비교한다.
- 고도 정보가 없으면 고도 필터를 적용하지 않고 `고도 정보 없음`으로 표시한다. 이를 근거로 위험이 없다고 표시하지 않는다.

## 5. 낙뢰: 출발 임박 실황 정보

낙뢰는 예보나 대체 경로 생성 조건이 아니라 현재 관측 정보다.

- 지도에 최근 60분 낙뢰 지점을 표시한다.
- 각 후보에 `경로 20 NM 이내 최근 60분 낙뢰 수`, `가장 최근 낙뢰 시각`, `자료 갱신시각`을 표시한다.
- ETD가 현재부터 60분 이내이고 낙뢰 자료가 최신이면, 위 정보를 `출발 임박 관측`으로 강조한다.
- 20 NM은 낙뢰 근접도를 읽기 쉽게 보여 주는 참고 거리이며 자동 회피 기준이 아니다.
- ETD가 더 먼 미래이면 낙뢰는 여전히 현재 실황으로 표시하되, 해당 예정 시각의 예보가 아니라는 점을 명시한다.
- 낙뢰 위치를 이동시키거나 미래 낙뢰를 추정하지 않는다.

## 6. 20 NM과 레이더 에코

- 일반 TS/CB SIGMET에는 일괄 20 NM 버퍼를 적용하지 않는다. SIGMET 폴리곤 교차만 사용한다.
- 현 데이터에 ‘강한 에코’ 또는 ‘심한 뇌우’를 판정할 신뢰할 수 있는 속성이 없으므로, 레이더 에코 강도 기반 자동 제외는 MVP 범위 밖이다.
- FAA의 심한 뇌우 또는 강한 레이더 에코 20 NM 회피 지침은 참고 문맥으로만 제공하며, 일반화한 앱 규칙으로 쓰지 않는다.

## 7. 화면

### 지도

- 현재 계획 경로와 최대 3개의 비교 후보를 동시에 표시한다.
- 선택한 경로만 강조하며, SIGMET 폴리곤과 최근 60분 낙뢰를 겹쳐 표시한다.
- 경로 선택 시 해당 후보의 상세 기상 비교 카드로 전환한다.

### 후보 카드

각 후보에는 다음을 같은 순서로 표시한다.

- 사용한 ETD, TAS, 순항고도
- 원래 경로 대비 거리 차이
- 대류/VA/TC SIGMET 교차 여부와 그 변화
- 선택한 SID/STAR/IAP의 고정 구간에 남아 있는 대류/VA/TC SIGMET 교차 여부
- 난류·착빙 등 비교 전용 현상의 교차 구간, 계획 통과시각, 고도 범위, SIGMET 유효기간
- 최근 60분 경로 20 NM 이내 낙뢰 수와 최신 관측시각
- SIGMET 발표시각·유효기간, 낙뢰 자료 갱신시각

표현은 `교차`, `교차하지 않음`, `유효기간 겹침`, `고도 정보 없음`처럼 검증 가능한 사실로 한정한다. `추천`, `최선`, `안전`, `대체공항 필요` 같은 결론 표현은 쓰지 않는다.

## 8. MVP에서 제외

- 레이더 에코로 CB 자동 식별 또는 미래 이동 예측
- 낙뢰만으로 후보 생성·제외
- 항공기 성능, 연료, 비행시간 절감, 최적고도 계산
- ATC 승인 가능성, 실제 비행 중 회피 지시
- 목적지·대체공항의 기상 최소치 경고 또는 법적 대체공항 판단
- 기존 미국식 1-2-3 결과를 이 기능의 결론으로 사용하는 것

## 9. 수용 기준

1. 국내 IFR에서 사용자가 선택한 SID/STAR/IAP와 en-route 항공로 후보가 하나의 전체 경로로 지도와 기상 비교에 사용된다.
2. 대류/VA/TC SIGMET과 위치·구간별 계획 통과시각·고도가 겹치는 기존 경로에 대해, 항공로/FIX 그래프 기반 비교 후보를 최대 3개 표시한다.
3. ETD 변경 시 후보별 SIGMET 유효시간 비교가 구간 통과시각을 기준으로 바뀐다.
4. 후보 카드와 지도에 최근 60분 낙뢰가 표시되며, ETD가 60분 이내일 때만 출발 임박 관측으로 강조된다.
5. 낙뢰와 20 NM이 대체 경로 자동 생성·제외의 조건으로 사용되지 않는다.
6. 어떤 화면도 항로 추천, 안전 판정, 법적 대체공항 필요 여부를 말하지 않는다.
7. 대류/VA/TC를 완전히 피하는 후보가 없을 때, 앱이 `덜 위험한` 후보를 자동으로 제시하지 않는다.
8. 사용자는 en-route에 FIX와 항공로를 직접 추가할 수 있으며, 앱은 모든 입력이 항공로/FIX 그래프에서 유효하게 연결되는지 검증한다.

## 10. 구현 전 확인

- 절차의 끝 FIX와 시작 FIX가 선택된 en-route 후보와 실제로 연결되는지 검증한다.
- SID/STAR/IAP 구간 거리의 누적값과 지도 선형의 순서가 같은지 검증한다.
- 해외 SIGMET의 고도 범위가 파서에서 보존되는지 표본과 자동 테스트로 확인한다.
- 선분-폴리곤 교차 및 경로 20 NM 이내 낙뢰 집계에 대한 작은 단위 테스트를 둔다.

## 11. 현재 경로 확인 기능과의 적용 경계

현재 경로 확인 탭은 출발·도착 공항을 입력하면 SID, en-route 기본 경로, STAR, IAP를 자동 선택하고, 이를 하나의 지도 경로와 전체 거리로 만든다. 이 자동 선택 및 절차 결합 기능은 이 스펙의 계획 경로 기준선으로 그대로 사용한다.

다만 현재 IFR en-route는 `진입 FIX → 이탈 FIX` 사이의 단일 최단경로만 생성한다. 수동 en-route 입력과 기상 비교 후보에는 아래 변경이 필요하다.

- 경로 입력 상태에 사용자가 확정한 순서 있는 en-route FIX 목록을 저장한다.
- 경로 생성기는 `진입 FIX → 경유 FIX 1 → … → 경유 FIX n → 이탈 FIX`의 각 구간을 항공로/FIX 그래프에서 연결하고, 항공로 종류와 방향 규칙을 각각 검증한다.
- SID/STAR/IAP 선택을 바꾸면 새 시작·끝 FIX에 대해 수동 en-route 목록을 다시 검증한다.
- 저장 경로에는 수동 en-route 목록과 사용자가 선택한 SID/STAR/IAP를 함께 저장하고 복원한다. 재불러오기 때 자동 선택으로 덮어쓰지 않는다.

현재 전체 경로의 거리와 TAS 기반 ETA는 이미 계산된다. 그러나 현재 SIGMET 비교는 ETD부터 ETA까지의 전체 시간창이 유효기간과 겹치는지 먼저 판단한다. 이 기능에서는 다음으로 교체해야 한다.

- 위험구역과 교차한 경로 구간의 시작·끝 누적 거리를 구한다.
- 각 거리에서 입력 TAS 기반 계획 통과시각을 계산한다.
- 그 구간 통과시각만 SIGMET 유효기간과 비교한다.
- 단순 점 샘플이 아닌 선분-폴리곤 교차로 위험구역 통과를 판정한다.

대체 후보 생성은 기존 단일 최단경로 탐색을 대체하지 않는다. 여러 합법 en-route 경로를 찾은 뒤 대류/VA/TC 제약을 만족하지 않는 후보를 제외하고, 남은 경로를 거리순으로 최대 3개 표시하는 별도 기능으로 만든다.

경로 20 NM 이내 낙뢰 집계는 새로 추가한다. 지도에는 선택 후보 하나만 표시하며, 기존 route-briefing 경로 미리보기 source/layer를 재사용한다. 이 기능을 위해 `MapView`에 새 상태나 효과를 추가하지 않는다.
## 12. 구현 검토 결론과 필수 기준

이 기능은 기존 경로 브리핑에 조건을 더하는 방식이 아니라, 여러 en-route 후보를 만들고 같은 기상 기준으로 비교하는 별도 기능 단위로 구현한다. 기존에 사용자가 선택한 SID, STAR, IAP는 모든 후보에서 고정하고, en-route 구간만 바꾼다.

### 12.1 후보 경로와 수동 수정

- 후보 생성은 현재 항로-FIX 그래프와 항로 종류·방향 검증 규칙을 재사용한다.
- 서로 같은 FIX/항로 순서인 미세한 변형은 하나의 후보로 본다. 실제로 다른 중간 FIX 또는 항로 구간이 있는 후보만 남긴다.
- 수동 en-route 수정은 자유 형식 문자열을 해석하지 않는다. `진입 FIX → 항로 → 이탈 FIX` 단위의 검증된 구간 목록으로 저장한다.
- SID, STAR, IAP를 바꾸면 수동 en-route 구간의 시작·끝 연결을 다시 검증한다. 연결되지 않으면 사용자가 수정할 수 있도록 상태를 표시한다.

### 12.2 SIGMET 교차, 통과 시각, 고도

- 위험구역 판정은 경로 표본점 하나가 다각형 안에 있는지로 끝내지 않는다. 모든 경로 선분과 Polygon/MultiPolygon의 교차를 계산하여 진입·이탈 지점과 누적 거리를 구한다.
- 각 교차 구간의 계획 통과 시각은 전체 경로의 ETD/ETA 겹침이 아니라 `ETD + (누적 거리 / 입력 TAS)`로 계산한다. 따라서 비교 요청에는 TAS를 포함한다.
- 해당 구간의 계획 통과 시각과 SIGMET 유효기간이 겹칠 때만 기상 교차로 표시한다.
- SIGMET 고도 범위가 있으면 입력 순항고도와 비교한다. 상한 또는 하한만 있는 범위는 그대로 보존한다. 고도 정보가 없으면 제외하지 않고 `고도 정보 없음`으로 표시한다.
- 대체 후보 제외에는 VA와 TC SIGMET만 사용한다. 그 밖의 SIGMET, AIRMET, 난류, 착빙, 구름, 바람 등은 후보 카드의 비교 정보로만 표시한다.

### 12.3 낙뢰와 지도 표시

- 최근 60분 낙뢰는 경로 20 NM 이내 여부, 가장 최근 관측 시각, 자료 갱신 시각을 후보 카드에 표시한다.
- 낙뢰 20 NM은 참고 거리이며 후보 생성·제외·추천의 조건으로 사용하지 않는다.
- 지도에는 사용자가 선택한 후보 하나만 강조한다. 기존 route-briefing 경로 미리보기와 절차 결합을 재사용하며, 이 기능만을 위한 새 MapView 상태나 효과를 추가하지 않는다.

### 12.4 구현·검증 경계

- 경로 후보 생성과 수동 경로 검증은 기존 route-briefing 플래너를 확장한다.
- 후보별 기상 판정은 백엔드의 순수 계산 모듈에서 수행하고, 화면은 결과만 렌더링한다.
- 최소 단위 검증에는 좁은 위험구역의 선분 교차, 다중 다각형, 유효기간 경계, 고도 정보 없음, 항로 방향 위반, 연결 불가 수동 구간, 20 NM 낙뢰 참고 표시를 포함한다.
- UI 구현 전에는 후보 카드와 선택 상태의 데스크톱·iPad 가로 화면 증거를 먼저 캡처하고, 구현 후 Playwright로 선택 경로·지도 미리보기·브리핑 갱신을 검증한다.
