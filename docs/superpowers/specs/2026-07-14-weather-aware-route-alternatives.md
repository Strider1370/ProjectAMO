# 기상 노출 기반 대안 경로 비교 설계 스펙

- 상태: **설계 초안. 미구현.**
- 작성일: 2026-07-14
- 개정: 2026-07-17
- 적용 범위: 국내 IFR 사전 비행계획의 en-route 경로 비교
- 목적: 고도 미확정 상태에서 기본 경로와 유효한 en-route 대안 경로의 수평 기상 노출을 비교한다. ProjectAMO는 회피 검토가 필요한 기상현상과 각 경로의 트레이드오프를 근거와 함께 제시하며, 최종 경로 선택·운항 가능성 판단은 조종사에게 남긴다.

## 1. 기능의 위치와 원칙

이 기능은 비행계획 흐름의 첫 단계다.

```text
대안 경로 기상 비교
→ 수평 경로 확정
→ 고도별 기상 비교
→ 계획고도 확정
→ 경로 구간 기상 브리핑
```

대안 경로 비교는 고도·항공기 성능·구간 통과 시각이 정해지기 전의 수평 경로 판단을 돕는다. 따라서 "이 위험을 만난다", "안전한 대안이다", "최적 경로다"라고 결론 내리지 않는다. 대신 각 경로가 위험 영역과 수평으로 어떻게 관계되는지, 현상의 공표 고도범위·유효시간·자료 상태가 무엇인지, 기본 경로와 비교해 무엇이 줄고 무엇이 새로 생기는지를 보여 준다.

## 2. 입력과 결과

### 입력

```text
출발지 / 도착지
사용자가 선택한 SID / STAR / IAP
기본 en-route 경로
사용자가 선택·편집한 대안 en-route 경로 또는 graph 탐색 후보
선택 사항: 비행계획에서 가져온 ETD / ETA
```

TAS, 항공기 성능, 계획 순항고도는 이 단계의 입력이 아니다. `누적거리 / TAS`로 구간 통과 시각이나 ETA를 계산하지 않는다.

### 결과

사용자가 하나의 수평 경로를 확정하면 다음을 다음 단계로 넘긴다.

```text
routeGeometry
순서가 보존된 enRouteSegments
선택된 SID / STAR / IAP
AIP route/fix 식별자와 적용 cycle 정보
```

고도별 기상 비교는 이 결과를 받아 AIP 항공로 제약 안에서 계획고도 후보를 비교한다. 경로 구간 기상 브리핑은 최종 경로·고도에서 구간별 조건을 보여 준다.

## 3. 경로 후보 구성

```text
사용자가 선택한 SID
+ 기본 또는 사용자가 편집한 en-route 경로
+ 사용자가 선택한 STAR
+ 사용자가 선택한 IAP(있는 경우)
```

- 대안으로 바꿀 수 있는 범위는 SID와 STAR 사이의 en-route 부분뿐이다. SID/STAR/IAP는 사용자가 선택한 것을 그대로 보존한다.
- route graph에서 연결·방향 규칙을 만족하는 경로만 후보로 만든다.
- AIP 항공로 데이터가 정규화되면 ENR 3.1/3.3의 구간·방향·발효정보로 graph 후보를 검증한다. 그 전에는 `graph 연결 확인` 상태로만 표시하고 운항상 유효를 주장하지 않는다.
- 사용자는 `ENR 수정` 영역에서 FIX와 항공로를 직접 추가·변경할 수 있다. 자유 형식 route 문자열은 이 MVP에서 해석하지 않는다.
- 기본 경로는 항상 표시한다. 후보가 많을 때에는 서로 실제로 다른 항공로 구간을 가진 경로만 중복 제거하며, 표시하지 못한 유효 graph 후보 수를 명시한다. 거리순 표시는 정렬일 뿐 안전·추천 순위가 아니다.

### 3-A. 대안 탐색을 여는 조건

대안 경로는 모든 검색에서 만들지 않는다. 기본 en-route 경로가 회피 검토 대상 위험기상 영역과 **수평으로 교차할 때만** 대안 탐색을 연다.

- MVP의 자동 탐색 대상은 유효한 polygon geometry를 가진 TS/CB 계열 SIGMET, TC, VA다. VA는 VAA/VA SIGMET geometry 어댑터가 준비된 뒤 활성화한다.
- 기본 경로의 교차 거리가 0보다 크고, ETD~ETA 시간창과 위험기상 유효시간이 겹치면 자동으로 후보를 생성한다.
- 위험 영역은 교차하지만 ETD/ETA 또는 유효시간이 없어 시간 판단을 할 수 없으면 자동 생성하지 않는다. 대신 `수평 노출은 있으나 시간 판단 불가`를 표시하고 사용자가 `대안 경로 비교`를 직접 열 수 있게 한다.
- 위험기상 geometry가 없거나 자료가 부분적이면 대안 생성의 근거로 쓰지 않는다. 자료 부족 사실을 표시하며, 위험 없음으로 바꾸지 않는다.
- 난류·착빙 AIRMET과 최근 낙뢰는 고도·시간 의존 비교 정보다. MVP에서는 자동 대안 탐색의 직접 트리거가 아니다.
- 자동 생성 대상이 없으면 `현재 경로에서 대안 비교 대상 위험기상 노출 없음`과 자료 시각을 표시하고 기본 경로만 유지한다. 이는 운항 가능 또는 안전 판정이 아니다.

### 3-B. MVP 후보 한계

대안은 위험기상을 점수화해 추천하는 결과가 아니라, 사용자가 지도와 카드에서 비교할 탐색 후보다.

- SID·STAR·IAP는 고정하고, 기본 경로의 위험기상 교차 구간을 피하도록 en-route graph 안에서 후보를 찾는다.
- AIP 방향·AIRAC cycle·항로 제약을 통과하지 못한 경로, 되돌아가기 또는 순환 경로는 제외한다.
- 후보의 추가 en-route 거리는 `min(50 NM, max(15 NM, 기본 en-route 거리의 25%))`를 넘지 않는다.
- 기본 경로와 최소 15 NM 또는 전체 en-route 거리의 20% 이상 다른 항로 구간이 있어야 한다.
- 기본 경로와 대안 최대 3개만 첫 화면에 표시한다. 후보는 거리순으로 정렬하며, 위험 점수·안전 순위·추천 순위는 만들지 않는다.
- 이 거리·후보 수 기준은 공개 EFB 업계 표준이 아니라 국내선 MVP의 초기 정책이다. 실제 항로 사례 검증 뒤 수치를 조정한다.

## 4. 기상 노출 비교

### 4-A. 회피 검토 대상과 현상별 역할

위험 데이터는 발행 형식(SIGMET/AIRMET)이 아니라 현상 중심으로 정규화한다.

| 현상 | 대안 경로 단계의 역할 | 고도 확정 뒤의 역할 |
| --- | --- | --- |
| TS/CB·대류성 SIGMET | 수평 교차를 최상위 회피 검토 대상으로 표시 | 선택 고도와 공표 고도범위를 함께 확인 |
| 화산재(VAA/VA SIGMET) | 수평 교차와 예측 구름 위치·고도·시각 표시 | 선택 고도와 예측 고도범위 확인 |
| 태풍(TCA/TC SIGMET) | 태풍 영향 영역·예측 시각과 수평 경로 관계 표시 | 고도별 바람·난류 등 별도 비교 |
| 난류·착빙 | 경로별 노출 참고 정보 | 고도별 비교와 구간 브리핑의 핵심 대상 |
| 대류운 발생 가능성 | `잠재성 예보`로서 수평 노출 참고 정보 | 고도별 조건과 함께 표시 |
| 최근 낙뢰 | 최근 관측으로만 표시 | 선택 고도·구간과 함께 참고 표시 |
| 목적지 TAF·공항 경보 | 경로 카드의 필터가 아닌 공통 터미널 브리핑 | 공통 터미널 브리핑 |

TS/CB, 화산재, 태풍은 대안 탐색에서 우선적으로 드러내는 회피 검토 대상이다. 하지만 이 현상과 수평으로 교차하는 후보를 조용히 제거하지 않는다. 기본 경로와 대안에서 줄어든 위험과 새로 생긴 위험을 조종사가 비교할 수 있어야 한다.

### 4-B. 수평 노출 모델

고도 미확정 단계의 현상별 결과는 다음 사실을 보존한다.

```js
{
  phenomenon: 'convection' | 'volcanic_ash' | 'tropical_cyclone'
            | 'turbulence' | 'icing' | 'convective_potential',
  source: 'SIGMET' | 'AIRMET' | 'VAA' | 'TCA' | 'KIM' | 'KTG' | 'LIGHTNING',
  geometry,
  horizontalExposure: {
    intersects: true | false | 'unknown',
    distanceNm: number | null,
    intervals: [{ startNm, endNm }]
  },
  verticalRange: { lowerFt, upperFt } | null,
  validTime: { from, to } | null,
  forecastOrObservation: 'forecast' | 'observation' | 'mixed',
  movementOrForecastPosition: [],
  confidence: 'available' | 'partial' | 'unavailable'
}
```

- `intersects: true`는 수평 경로가 위험 영역과 겹친다는 뜻일 뿐, 해당 비행이 위험을 실제로 조우한다는 뜻은 아니다.
- 공표 고도범위가 있으면 그대로 표시한다. 고도가 미확정이므로 이 단계에서 수직 필터를 적용하지 않는다.
- ETD/ETA가 비행계획에 있으면 전체 비행 시간창과 위험 유효시간의 관계를 보조 정보로 표시할 수 있다. 구간 통과 시각을 계산하거나 특정 leg 조우시각을 주장하지 않는다.
- ETD/ETA가 없거나 필요한 자료가 없으면 `시간 판정 불가`와 원본 유효시간을 표시한다. 위험 없음으로 바꾸지 않는다.
- 화산재·태풍 데이터가 중심점만 제공하고 영향 영역 또는 예측 영역을 제공하지 않으면, 중심점과 경로 거리만 참고로 보이고 `영향 영역 데이터 없음`을 표시한다. 중심점 비교로 비교 경로가 안전하다고 판단하지 않는다.

### 4-C. 경로별 비교 내용

모든 후보 카드에는 기본 경로 대비 다음을 표시한다.

```text
기본 경로 대비 거리: +28 NM

회피 검토 대상 노출 변화
- TS SIGMET: 수평 교차 24 NM → 없음
- 화산재: 수평 교차 없음 → 없음

새로 생긴 기상 노출
- 대류운 발생 가능 영역: 14 NM
- 최근 60분 낙뢰: 경로 20 NM 이내 3건

자료 상태
- TS 공표 고도 FL200–FL400
- 유효 10:00–16:00Z
- 시간: ETA 미제공 — 구간별 시간 판정 불가
```

표현은 `수평 교차를 제거하는 대안`, `새로 생긴 기상 노출`, `거리 +28 NM`처럼 검증 가능한 사실이어야 한다. `안전`, `최적`, `회피 권장`, `운항 불가` 같은 결론 표현은 사용하지 않는다.

### 4-D. 고도 미확정 상태의 한계

난류·착빙·고도 범위가 있는 SIGMET/AIRMET은 수평 경로만으로 완결된 판단을 할 수 없다. 이 화면에서는 현상과 수평 노출을 보여 주되, 다음 단계에서 확인할 항목을 명시한다.

```text
고도 확인 필요: 난류 SIGMET FL180–FL300
다음 단계에서 선택 고도와의 수직 교차를 비교합니다.
```

이 경고는 대안 경로 비교의 실패가 아니라, 수평 경로 결정과 고도 결정을 분리한 결과다.

## 5. 데이터 의존성

### 현재 활용 데이터

- route graph, route segment, navpoint, 사용자 선택 절차
- 국내/해외 SIGMET, AIRMET, 기존 NOTAM, 낙뢰
- KIM 고도별 바람·기온·착빙과 KTG 난류
- 목적지 METAR/TAF 및 공항 경보
- `geo-time-match.js`의 수평 도형 교차와 경로 거리축 구간 계산

### 선행 또는 추가 데이터

| 데이터 | 목적 |
| --- | --- |
| AIP ENR 3.1/3.3, ENR 4.4, Amendment/AIRAC 변경분 | 항공로 구간·방향·연결·발효 cycle 검증 |
| VAA | 화산재 예측 구름의 도형·고도·시각 |
| TCA | 태풍 영향 영역·예측 위치·시각·풍속 정보 |
| 대류운 발생 가능성 예보 | 잠재 대류 노출 비교 |

복수 위험 영역이 있는 SIGMET/AIRMET은 각 polygon과 해당 고도범위·유효시간을 짝으로 보존해야 한다. 여러 영역의 첫 고도범위만 대표값으로 쓰면, 실제 경로가 교차한 영역에 잘못된 수직 범위를 적용할 수 있다.

## 6. 구현 경계

- 경로 graph 탐색, 사용자 en-route 편집, 지도 미리보기는 프런트엔드 route-briefing 모듈에 둔다.
- AIP 정규화·cycle 최신성·원본 보존은 백엔드/데이터 계층 책임이다.
- 수평 기상 노출 비교는 프런트와 백엔드가 공유 가능한 순수 모듈로 분리한다.
- 기존 `geo-time-match.js`의 polygon 교차와 거리축 구간 계산은 재사용한다.
- 고도 미확정용 `horizontalExposure`와, 고도 확정 뒤의 `altitudeExposure`를 분리한다. 후자는 고도별 기상 비교 스펙에서 다룬다.
- 기존 NOTAM 수집·저장 파이프라인은 재사용한다. 대안 경로 화면에서는 경로·공역·시간의 관련 사실을 표시하고, 고도별 후보 제외는 고도 비교 단계에서 처리한다.

## 7. 화면

### 지도

- 기본 경로와 비교 경로를 동시에 표시하되, 사용자가 선택한 한 경로만 강조한다.
- TS/CB, 화산재, 태풍의 위험 영역과 최근 낙뢰를 지도에서 겹쳐 볼 수 있다.
- 지도 레이어는 기존 route-preview와 기상 overlay 소유 모듈을 재사용한다. 이 기능을 위해 `MapView`에 새 상태 또는 `useEffect`를 추가하지 않는다.

### 비교 카드

```text
대안 A
기본 경로 대비 +28 NM

TS SIGMET 수평 교차 없음
기본 경로의 TS SIGMET 수평 교차 24 NM 제거

새로 생긴 기상 노출
대류운 발생 가능 영역 14 NM

공표 고도 FL200–FL400 · 유효 10:00–16:00Z
고도·구간 통과 시각은 다음 단계에서 확인 필요
```

- 카드에는 기상 노출이 줄어든 사실과 새로 생긴 사실을 함께 보인다.
- 기상 결과를 하나의 위험 점수로 합산하거나, 카드 순서를 안전 순위로 표현하지 않는다.
- 목적지 TAF와 공항 경보는 카드마다 반복하지 않고 공통 터미널 브리핑에 표시한다.
- `시간 판정 불가`, `영향 영역 데이터 없음`, `AIP graph 검증 전`은 위험 없음과 시각적으로 구분한다.

## 8. 완료 기준

- 조종사는 기본 경로와 대안 en-route 경로에서 TS/CB, 화산재, 태풍 등 회피 검토 대상 현상의 수평 노출 차이를 비교할 수 있다.
- 각 경로에서 사라지는 위험과 새로 생기는 위험, 거리 차이, 공표 고도범위·유효시간·자료 상태가 함께 표시된다.
- 고도 미확정 상태에서 수직 조우·구간 통과 시각·운항 가능성·안전/최적 경로를 주장하지 않는다.
- 사용자가 확정한 수평 경로는 고도별 기상 비교로, 최종 고도는 경로 구간 기상 브리핑으로 자연스럽게 이어진다.
- AIP·VAA/TCA·대류 예보가 없거나 부분적인 경우 그 한계가 노출되며, 자료 부재를 위험 없음으로 표시하지 않는다.
