# 지상 모니터링: 경보 공백 및 사이니지 예보 출처 표시

**작성일:** 2026-08-11

**상태:** 사용자 검토 대기

## 목적

지상 모니터링의 사이니지와 기본 카드형 모두에서 실제 공항경보가 없을 때 경보 영역이 빈 공간을 점유하지 않게 한다. 사이니지의 예보 전환 헤더는 현재 보이는 예보 종류와 그 출처만 간결하게 표시한다.

## 적용 범위

- 지상 모드에서 경보 패널 표시 규칙은 **사이니지와 기본 카드형(클래식)에 공통 적용**한다.
- 사이니지의 예보 전환 헤더만 변경한다. 기본 카드형의 예보 헤더는 이번 범위에서 변경하지 않는다.
- KMA 데이터 요청·예보 데이터 산출 방식은 변경하지 않는다.
- 시간별 예보는 기존 동네예보 격자자료를 계속 사용한다.
- 주간 예보는 기존 단기·중기 데이터 조합을 계속 사용한다. 화면의 출처 문구만 아래 규칙으로 표시한다.

## 경보 영역

1. 실제 공항경보 목록이 비어 있으면 사이니지와 기본 카드형 모두에서 경보 패널을 렌더링하지 않는다.
2. 사이니지에서는 경보 패널이 빠진 경우 그 행의 고정 높이와 여백도 함께 제거하여 현재 날씨와 예보 영역이 위로 이동하고 남은 공간을 사용한다.
3. 기본 카드형에서는 경보 패널 자체가 없어져 뒤따르는 카드가 자연스럽게 위로 붙는다.
4. 실제 공항경보가 하나 이상이면 두 레이아웃 모두 기존의 경보 패널을 표시한다.
5. 현재 경보가 없을 때 같은 위치에 표시되는 `일기개황` 대체 패널도 이번 규칙에서는 표시하지 않는다. 즉, 실제 공항경보가 없는 상태에는 두 레이아웃 모두 경보용 영역 자체가 없다.

## 사이니지 예보 전환 헤더

자동 전환 중인 화면에서 활성 예보 종류의 제목과 출처만 한 번 표시한다. 비활성 예보의 제목·출처는 시각적으로도 접근성 트리에서도 노출하지 않는다.

| 활성 화면 | 제목 | 출처 문구 |
| --- | --- | --- |
| 시간별 예보 | `시간별 예보` | `{공항 읍면동} 동네예보 {발표시각}` |
| 주간 예보 | `주간 예보` | `중기예보 {발표시각}` |

- 기존의 `현재`, `다음` 접두어를 모두 제거한다.
- 시간별 예보에서는 `중기예보`를 함께 표시하지 않는다.
- 주간 예보에서는 동네예보 출처를 함께 표시하지 않는다.
- 주간 예보 데이터가 내부적으로 단기와 중기 데이터를 함께 사용하더라도, 사용자에게는 합의된 문구인 `중기예보 {발표시각}`만 표시한다.

## 공항 읍면동 표기

동네예보 격자는 행정구역명을 제공하지 않으므로, 지상 서비스 대상 공항의 중심점 주소를 기준으로 프로젝트가 관리하는 ICAO별 읍면동 매핑을 사용한다. 화면 전환이나 API 호출마다 역지오코딩하지 않는다.

| ICAO | 공항 | 표기 |
| --- | --- | --- |
| RKSI | 인천국제공항 | 운서동 |
| RKSS | 김포국제공항 | 공항동 |
| RKPC | 제주국제공항 | 용담2동 |
| RKPK | 김해국제공항 | 대저2동 |
| RKJB | 무안국제공항 | 망운면 |
| RKJY | 여수공항 | 율촌면 |
| RKPU | 울산공항 | 송정동 |
| RKNY | 양양국제공항 | 손양면 |

매핑이 없는 공항은 지역 접두어 없이 기존과 같은 `동네예보 {발표시각}` 문구로 안전하게 폴백한다.

## 구현 경계

- 경보 존재 여부는 두 레이아웃이 동일한 실제 경보 상태를 기준으로 계산한다. 빈 상태용 대체 패널을 별도로 렌더링하지 않는다.
- 사이니지 그리드 행은 실제 경보 상태와 동일하게 계산한다. 숨겨진 패널의 행이 남아서는 안 된다.
- 예보 헤더의 활성 화면 상태는 현재 슬라이드 전환 상태를 그대로 사용한다. 전환 주기와 예보 카드 내용은 바꾸지 않는다.
- 제목과 출처 문구는 화면 전환 시 함께 갱신하며, 숨겨진 화면의 중복 텍스트가 보조기술에 읽히지 않게 한다.
- 읍면동 매핑은 데이터/뷰모델 계층에 두고 JSX·CSS에 하드코딩하지 않는다.

## 검증 기준

1. 실제 경보가 없는 지상 사이니지와 기본 카드형에서 `공항경보 없음` 및 `일기개황` 경보 패널이 없다.
2. 사이니지에는 그 높이만큼 빈 행이 남지 않고, 기본 카드형의 뒤따르는 카드도 빈 경보 패널 공간을 점유하지 않는다.
3. 실제 경보가 있는 두 레이아웃에서는 경보 패널이 유지된다.
4. 시간별 화면에는 `시간별 예보`, 예를 들어 `망운면 동네예보 20시`만 보인다.
5. 주간 화면에는 `주간 예보`, `중기예보 18시`만 보인다.
6. `현재`, `다음`, 결합 출처 문구(`동네예보 … · 중기예보 …`)가 사이니지 헤더에 남지 않는다.
7. 지상 사이니지·기본 카드형 계약 테스트와 브라우저 캡처로 경보 유무 및 두 예보 전환 상태를 확인한다.

## 이번 범위에서 보류하는 항목

- 실제 경보가 있을 때의 경보 패널 높이·글자 크기 재설계
- 현재 날씨의 온도·체감온도·최저/최고 온도 간격 및 미세먼지 아이콘 정렬
- 주간 예보 최저/최고 온도 슬래시 겹침
- 기본 카드형 레이아웃의 경보 공백 이외 시각 조정

위 항목은 문제 제기는 되었지만, 사용자에게 제시할 구체적인 레이아웃·크기 결정이 아직 확정되지 않아 이번 변경에 포함하지 않는다.
