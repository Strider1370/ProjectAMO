# 어드민 레이더 상태를 합성 HSR로 전환

## 목표

어드민 데이터 현황의 `레이더` 항목이 더 이상 폐기된 BIN 기반 `radar_echo` 수집 결과를 보지 않고, 지도에서 실제 국내 레이더로 쓰는 기상청 합성 HSR 이미지 수집 결과를 표시한다.

## 원인

`radar_echo` 수집 스케줄은 2026-08-15에 제거됐다. 그러나 어드민 카탈로그의 `레이더` 행은 계속 `radar/echo_meta.json`과 `radar_echo` 통계를 참조한다. 따라서 정상적으로 갱신되는 HSR 이미지와 달리, 어드민에서만 오래된 BIN 기반 메타 파일을 기준으로 지연 또는 멈춤으로 판정한다.

## 설계

- 기존 `radar_echo` 카탈로그 행을 `radar` 행으로 교체한다.
- 새 행은 `statsKey: 'hsr'`, `meta: 'radar/hsr/hsr_meta.json'`을 사용하고, 표시 이름은 `레이더(합성 HSR)`로 한다.
- 기존 별도 `hsr` 행은 제거한다. `레이더`가 이미 지도에서 사용하는 HSR 제품을 의미하므로 같은 수집 결과를 두 번 노출하지 않는다.
- 합성 HSR의 실제 수집 주기에 맞춰 정상/지연/멈춤 기준은 각각 10분, 30분, 1시간으로 둔다.
- 나머지 자료·그룹·API 응답 형식은 변경하지 않는다. 전체 자료 수는 34종으로 유지한다.
- 더 이상 실행되지 않는 BIN 수집기의 `index.js` import와 lock 항목도 제거한다. `radar_echo` 문자열은 에코탑 설정 이름(`radar_echo_top`)과는 무관하므로 유지한다.

## 검증

- 단위 테스트로 `레이더(합성 HSR)` 행이 HSR 통계와 HSR 메타 파일의 시각으로 상태를 판정하는지 확인한다.
- 자료 수가 계속 34종인지 확인한다.
- 백엔드 관련 테스트와 프런트엔드 프로덕션 빌드를 실행한다.
- 어드민 브라우저 계약을 실행해 데이터 현황 화면이 실제로 열리는지 확인한다.

## 범위 제외

- BIN 수집기 소스·설정 파일의 완전 삭제
- 지도 레이더 렌더링과 타임라인 동작 변경
- 어드민 화면의 레이아웃 또는 시각 디자인 변경
