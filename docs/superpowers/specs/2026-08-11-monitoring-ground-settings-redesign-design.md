# Monitoring 지상 설정창 재구성 설계

## 목표

모니터링 설정창을 모드별 업무에 맞게 분리한다. 지상 모드에서는 `일반`과 `화면 전환`만 보여주고, 화면 전환 설정은 지상 담당자가 장면과 표시 시간을 직관적으로 조정할 수 있도록 핵심 항목을 앞에 배치한다.

## 범위

- 운항 모드의 기존 `일반 / 알림 / 항적 / 공역예보 / 화면 전환` 탭은 유지한다.
- 지상 모드에서는 `일반 / 화면 전환` 탭만 렌더링한다.
- 지상 모드의 `일반` 탭에는 시간대, 사이트 테마, 지도 배경, 지상 예보 표시를 유지한다.
- `화면 전환` 탭은 다음 순서로 재구성한다.
  1. 화면 전환 사용 및 현재 상태
  2. 전환 대상과 표시할 장면·장면별 머무는 시간
  4. 운영 시간
  5. 안내 이미지 선택·제거
  6. 미리보기·중지·다음 페이지
  7. 전환 효과·애니메이션 속도는 고급 설정으로 접음
- 기존 localStorage/IndexedDB 키, 저장·적용·초기화 동작, 슬라이드 순서와 검증 규칙은 변경하지 않는다.
- `다음 페이지`는 현재 사용 가능한 장면 순서에서 다음 장면을 즉시 표시하고, 필요하면 미리보기 상태를 시작한다.
- 전환 애니메이션 기본 속도는 `1000ms`로 한다. 이미지·기상정보에서 지도로 돌아갈 때는 퇴장 레이어를 애니메이션 종료까지 유지해 지도가 자연스럽게 드러나도록 한다.
- 운항 모드에서도 화면 전환 기능의 동작과 저장 호환성은 유지한다.

## 화면 원칙

설정 화면은 “켜져 있는가 → 무엇을 보여주는가 → 언제 실행하는가” 순서로 읽힌다. 장면 행은 체크박스와 표시 시간을 한 행에 두고, 이미지가 선택된 경우에만 이미지 관리 세부 정보를 표시한다. `전환 대상`은 기본 설정에 두고, `전환 효과`와 `애니메이션 속도`만 접을 수 있는 고급 영역으로 이동한다.

## 검증

- 지상 모드에서 설정 탭이 `일반`, `화면 전환`만 보이는지 확인한다.
- 운항 모드에서 기존 다섯 탭이 모두 보이는지 확인한다.
- 화면 전환의 지도·기상정보·이미지 장면, 장면별 시간, 일정, 이미지 선택, 미리보기/중지와 저장 동작을 확인한다.
- 기존 모니터링 설정 계약과 slideshow 단위 테스트를 통과시킨다.
