# 모바일·태블릿 대안경로 드래그 편집

- 작성일: 2026-07-28
- 상태: 사용자 설계 승인, 구현 전

## 목표

모바일·태블릿에서 선택한 대안경로 선을 손가락으로 끌어 놓아 임의 waypoint(WP)를 추가하고, 사용자가 확인한 경우에만 경로에 반영한다.

## 범위

### 드래그로 WP 추가

- 대안경로를 새로 만들거나 선택하면, 모바일 경로 시트는 `peek` 상태로 내려가 지도를 가리지 않는다. 별도의 편집 모드는 만들지 않는다.
- 선택된 대안경로 선 위에서만 터치 드래그를 시작한다. 드래그 중에는 WP 초안과 변경 경로를 지도에 미리 보인다.
- 손을 놓으면 기존의 좌표 WP 생성 흐름을 재사용한다. 가까운 공개 FIX를 자동으로 찾거나 스냅하지 않는다.
- 데스크톱의 마우스 드래그 동작은 유지한다. 모바일·태블릿에는 동일한 흐름을 터치 이벤트로 추가한다.

### 확인 카드

- 드롭한 지점의 화면상 세로 위치에 확인 카드를 표시한다.
- 카드는 지도 폭을 사용해 좌우 12px에 고정한다. 드롭 지점의 가로 위치를 따라가지 않는다.
- 카드의 세로 위치는 상단 지도 조작부 아래와 하단 작업바·peek 시트 위 사이로 제한한다. 따라서 가장자리에서 드롭해도 화면 밖으로 나가지 않는다.
- 카드는 앱 최상위 레이어에 렌더해 지도 배지, 지도 버튼, 모바일 시트보다 앞에 표시한다.
- `적용`은 WP 삽입과 대안경로 갱신을 확정하고, `취소`는 초안을 버리고 원래 경로로 되돌린다. 두 버튼의 터치 영역은 최소 44px이다.

## 제외 범위

- 가까운 공개 waypoint 자동 스냅 또는 연결
- 기존 WP 이동·삭제의 모바일 제스처
- 다중 터치 제스처 추가

## 검증

- 선택된 대안경로에서 터치 드래그 → 드롭 → 확인 카드 → 적용 시 좌표 WP가 경로에 반영된다.
- 취소 시 원래 선으로 돌아간다.
- 카드가 화면 상·하단에서 드롭해도 화면 안에 남고 지도 조작부보다 앞에 보인다.
- 데스크톱 마우스 드래그와 기존 대안경로 흐름은 유지된다.
