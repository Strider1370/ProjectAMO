# 국내 공항 운항정보 스트립 설계

작성일: 2026-07-28
상태: **명세 승인됨**

## 목적

국내 공항패널을 열었을 때 공항경보보다 먼저 공항 표고와 오늘의 일출·일몰을 한눈에
확인하게 한다. 일반 공항 소개나 추가 운항정보는 넣지 않는다.

## 확정 UI

공항패널의 스크롤 본문 맨 위, `공항경보` 섹션 바로 위에 동일 너비의 3열 정보 스트립을
표시한다.

```text
표고  23 ft  │  ☀ 일출  05:32  │  일몰  19:42
────────────────────────────────────────────
공항경보
```

- 국내 공항에만 표시하며 해외 공항패널에는 표시하지 않는다.
- 데스크톱, iPad, 모바일 모두 3열을 유지하되 가로 스크롤은 만들지 않는다.
- 새로운 섹션, 레일 항목, 탭, 접기 동작은 추가하지 않는다.
- 정상 참고정보이므로 위험 의미색을 쓰지 않고 현재 모니터링 화면의 muted text 표현을
  따른다.
- 일출·일몰 문구는 모니터링 화면과 동일하게 `☀ 일출 HH:MM · 일몰 HH:MM` 표현을
  사용한다. 3열 배치에서는 `☀ 일출 HH:MM`과 `일몰 HH:MM`을 각각 한 칸에 둔다.
- 누락 값은 모니터링 화면과 동일하게 `-`로 표시한다.

## 데이터

### 공항 표고

- `shared/airports.js`의 국내 공항 메타데이터에 정수 `elevation_ft`를 추가한다.
- 값은 구현 시점의 대한민국 공식 eAIP 각 공항 `AD 2.2 AERODROME GEOGRAPHICAL AND
  ADMINISTRATIVE DATA`에 기재된 aerodrome elevation을 사용한다.
- 지형 DEM 조회값이나 지도 좌표의 추정 표고로 대체하지 않는다.
- 기존 공항 객체가 이미 패널까지 전달되므로 별도 API와 비동기 요청은 추가하지 않는다.

### 오늘의 일출·일몰

- 공항의 기존 `lat`·`lon`과 현재 시각으로 계산한다.
- “오늘”의 날짜 경계는 국내 공항 기준 KST로 정한다.
- 표시 시각은 앱의 기존 KST/UTC 선택을 따른다.
- 모니터링의 `computeSunTimes()` 구현 두 벌을 공통 순수 helper 하나로 이동하고,
  모니터링 화면과 새 공항 스트립이 동일 helper를 사용한다. 계산식과 반올림, `-` fallback은
  변경하지 않는다.
- 네트워크 요청, 저장, polling은 추가하지 않는다.

## 컴포넌트 경계

- 작은 표시 컴포넌트 하나가 `airport`, `tz`, `now`를 받아 세 값을 렌더링한다.
- 국내 여부와 좌표·표고 누락 처리는 표시 컴포넌트에서 결정한다.
- `AirportPanel`은 공항경보 섹션 앞에 이 컴포넌트를 배치하기만 한다.
- 시간 계산 helper는 React와 무관한 순수 함수로 유지해 모니터링에서도 재사용한다.

## 오류와 접근성

- 공항 또는 좌표가 없으면 일출·일몰을 `-`로 표시한다.
- 표고가 없으면 표고를 `-`로 표시하고 지형값을 추정하지 않는다.
- 세 칸은 텍스트 라벨과 값을 함께 제공하므로 색이나 아이콘에만 의미를 의존하지 않는다.
- 장식용 태양 기호는 스크린리더 중복 낭독을 만들지 않게 숨긴다.

## 검증

- 공통 helper가 기존 모니터링 test fixture와 같은 일출·일몰 문자열을 반환한다.
- KST 날짜 경계와 UTC 표시 변환을 고정 시각 test로 검증한다.
- 국내 공항에는 3열 스트립이 공항경보보다 먼저 보이고 해외 공항에는 보이지 않는다.
- 표고·좌표 누락 시 `-` fallback을 검증한다.
- Linux Playwright로 데스크톱, iPad 가로, 모바일에서 3열 유지, 잘림, 가로 스크롤,
  공항경보 순서를 확인한다.
- 기존 모니터링 일출·일몰 표시가 시각·문구·값 면에서 바뀌지 않았는지 회귀 검증한다.
