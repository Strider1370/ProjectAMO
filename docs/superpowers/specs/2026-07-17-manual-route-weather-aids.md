# 수동 경로 수정용 기상 보조

## 목적

자동 우회 경로를 생성하거나 안전·추천으로 제시하지 않는다. 조종사가 지도에서 위험기상을 보고 경로를 판단·수정할 때, 필요한 레이어와 고도별 단면 비교를 같은 흐름에서 제공한다.

현재의 자동 대안경로 생성은 전환 전 구현으로만 남아 있으며, 더 확장하지 않는다. 후속 수동 경로 설계 기능이 준비되면 이를 제거하고, 사용자가 복제·수정한 여러 경로 설계안을 사실 정보로 비교한다. 각 설계안에는 거리, 예상 시간, 맞바람/순풍, 착빙·난류, SIGMET/AIRMET 수평 노출을 표시하되 추천 순위나 운항 가능 판정은 표시하지 않는다.

## 경로 설계·비교 단계

- 사용자는 기본 경로를 복제해 여러 설계안을 만들고, 지도·문자열 입력으로 각각의 경유 지점과 절차를 수정한다.
- 설계안마다 SimBrief류와 교환할 호환 경로 문자열(`FIX → 항로명 → FIX`, `DCT`)을 제공한다. 지도 수정은 이 문자열을 갱신하고, 붙여넣기 적용은 같은 설계안을 갱신한다. SID·STAR·IAP는 호환 문자열 밖의 독립 절차 데이터이며, AMO의 전체 계획 표시에서만 함께 읽는다.
- 지도 조작이 끝난 뒤 또는 사용자가 경로 계산을 요청했을 때만 해당 설계안의 비교 정보를 갱신한다. 지도 포인터 이동마다 API를 호출하지 않는다.
- 고도 비교와 브리핑 준비에는 사용자가 선택한 설계안 하나만 전달한다.

- 기존 브리핑의 지도 기상 레이어 제어를 재사용한다.
- `SIGMET`, `AIRMET`, `낙뢰`, `레이더` 칩을 경로 비교 카드 위에 표시한다.
- 칩은 지도 레이어만 켜고 끈다. 경로 설계안·위험 판정·비교 결과를 바꾸지 않는다.
- 선택 경로와 실제로 수평 교차한 현상에서 관련 칩만 보인다. 자료가 없는 레이어는 숨긴다.

## 고도 비교 단계

- 기존 `VerticalProfileChart` 한 장을 재사용한다.
- 사용자가 입력해 조회한 계획 고도와 반환된 비교 후보 고도를 모두 수평선으로 겹쳐 표시한다.
- 선택 고도는 진하게, 나머지 후보는 옅게 표시한다. 후보 행 선택은 이미 받은 결과의 강조선만 바꾸며 재조회하지 않는다.
- 기존 단면 레이어(기온·습도·착빙·바람·난류·SIGMET/AIRMET) 토글을 그대로 제공한다.
- 단면은 자료가 있을 때만 보이며, 자료가 없으면 고도 후보 대신 부재 상태를 명확히 표시한다.

## 경계

- 지도 제어 상태나 effect를 `MapView.jsx`에 새로 만들지 않는다.
- 새 기상 데이터·안전 판정·추천 점수·새 지도 레이어는 만들지 않는다.
- 자동 대안경로 탐색·순위화·자동 회피 판단은 만들지 않는다.
- 고도 후보는 AIP 제약과 사용자가 입력한 계획 고도에서만 만들어진다.
