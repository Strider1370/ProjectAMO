# 수동 경로 수정용 기상 보조

## 목적

자동 우회 경로를 안전 또는 추천으로 제시하지 않는다. 조종사가 지도에서 위험기상을 보고 경로를 판단·수정할 때, 필요한 레이어와 고도별 단면 비교를 같은 흐름에서 제공한다.

## 경로 비교 단계

- 기존 브리핑의 지도 기상 레이어 제어를 재사용한다.
- `SIGMET`, `AIRMET`, `낙뢰`, `레이더` 칩을 경로 비교 카드 위에 표시한다.
- 칩은 지도 레이어만 켜고 끈다. 경로·위험 판정·후보 순위를 바꾸지 않는다.
- 선택 경로와 실제로 수평 교차한 현상에서 관련 칩만 보인다. 자료가 없는 레이어는 숨긴다.

## 고도 비교 단계

- 기존 `VerticalProfileChart` 한 장을 재사용한다.
- 사용자가 입력해 조회한 계획 고도와 반환된 비교 후보 고도를 모두 수평선으로 겹쳐 표시한다.
- 선택 고도는 진하게, 나머지 후보는 옅게 표시한다. 후보 행 선택은 이미 받은 결과의 강조선만 바꾸며 재조회하지 않는다.
- 기존 단면 레이어(기온·습도·착빙·바람·난류·SIGMET/AIRMET) 토글을 그대로 제공한다.
- 단면은 자료가 있을 때만 보이며, 자료가 없으면 고도 후보 대신 부재 상태를 명확히 표시한다.

## 경계

- 지도 제어 상태나 effect를 `MapView.jsx`에 새로 만들지 않는다.
- 새 기상 데이터·안전 판정·추천 점수·새 지도 레이어는 만들지 않는다.
- 고도 후보는 AIP 제약과 사용자가 입력한 계획 고도에서만 만들어진다.
