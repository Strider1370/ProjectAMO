## Gate 1 — QCD 가용성 실측 (2026-07-25)

- 시도한 후보 사이트: 18개
- 응답 확인 사이트: `BRI,GDK,KWK,KSN,MYN,PSN,GSN,SSP,JNI,GNG` (10개)
- 사이트당 다운로드 시간: 최소 115ms / 중앙값 142ms / 최대 374ms
- 표본 파일 크기: ~1MB (범위 490KB~2.7MB)
- **확정 운영 목록** (최종): `BRI,GDK,KWK,KSN,MYN,PSN,GSN,SSP,JNI,GNG`

### 실패 분석 (완전히 조사됨)

프로브 실행 후 컨트롤러가 8개 실패 코드(IIA, PMK, SBS, YIT, CHY, MUJ, ODS)와 1개 의심 코드(SDG)에 대해 추가 검증을 수행:

- **39바이트 응답**: API의 정해진 무효 지점코드 오류메시지 (`# 지점코드를 확인해 주세요.`)
  - 시도된 코드: 원래 프로브의 8개 + 추가 검증 16개(IMJ, SDS, GRS, MHS, YBS, SCK, BSL, KMA, JMS, DNH, HAN, SJN, ULJ, DGU, WJU, CJU) + SDG = 총 25개 코드 테스트
  - 결과: 모두 같은 39바이트 무효-코드 응답
- **SDG의 429**: 우연의 일시적 속도 제한이 아니라, 재검증 시 동일하게 39바이트 무효-코드 응답 수신

**결론**: 확인된 10개 사이트는 KMA 운영 기상레이더 네트워크의 **전체 집합**이다(백령도, 관악산, 광덕산, 오성산, 면봉산, 구덕산, 진도, 고산, 성산, 강릉). 이는 임시 추정치가 아니라 확정된 상태.

**스펙 추정치의 변경**: 스펙 "12~13개 사이트" 추정치는 실측으로 정정됨.
- 예정 일일 호출량: ~3,456회 (12개 × 288프레임/일) → **실제: 2,880회** (10개 × 288프레임/일, 5분 간격 = 288프레임)

### 용량 신호 (다운스트림 작업용 입력)

18개 코드를 순차 프로브 중 한 번 HTTP 429 응답 수신(SDG). 다운스트림 수집기(5분 주기, 동시성 4)의 재시도/백오프 전략은 Task 8에서 결정할 사항.
