## 판정과 조사 범위

**진단 산출물 완료, A12 동작·시각·권리 검증은 부분 확인이다.** 우선 검토 후보는 정의되지 않은 CSS 변수(W12-01), 공유 기상 아이콘의 feature CSS 의존(W12-02), 화면 분리 전에 보존할 전역 CSS 계약(W12-03), 모달의 키보드 계약(W12-04)이다. 폰트 최적화 재구현, 자산 일괄 삭제, 이름/크기만으로 CSS 분할은 권고하지 않는다.

- A01 A12 494개를 부록의 개별 경로로 전부 분류했다. 이 494개는 ‘이미지 494개’가 아니다: PNG 244(소문자238+대문자6), WOFF2 92, SVG60, JSON53, GeoJSON18, CSS12, WebP8, TXT2, HTML/GIF/MD/JPG/JS 각1이다.
- `frontend/src`의 CSS **44개 전부**에서 import, 선택자·변수 선언/참조, media/container, 전역 규칙을 텍스트로 조사했다. 이 중 generated Pretendard와 vendored Wanted CSS 2개는 손코드 중복 분석에서 제외했다. A12 밖 CSS32개도 UI 소유 경계를 보완했다. 모든 선택자의 모든 DOM 상태/최종 cascade를 실행 검증했다는 뜻은 아니다.
- CSS를 소비하는 App/공항·모델비교/지도·브리핑/모니터링/터미널/기관 라운지·발표/설정·인증·공용 피커의 실제 JSX, 지도 DOM 생성기를 읽었다. 데이터 로직은 표시 계약까지 추적하고 W04~W10의 내부 조사를 반복하지 않았다.
- A12 JSON/GeoJSON 71개는 JSON을 읽어 상위 구조를 분류했다. 모든 좌표·항법 절차의 유효성·날짜·저작권을 검증하지 않았다. 래스터 픽셀 비교, SVG 전체 경로의 시각 의미, 폰트 모든 glyph도 미검증이다.
- 사실 = 현재 파일의 선언/import/참조와 로컬 원본·메타데이터에서 확인한 내용. 가설 = 해당 구조가 실제 브라우저 상태에서 만들 것으로 예상하는 영향. 기존 보고서/과거 측정 = 선행 입력이며 이번 실행 통과로 전용하지 않는다.

### W12-03 — standalone 분리에 필요한 전역·feature CSS 계약과 reduced-motion cascade (사실, RF-124 선행)
