## 빠진 범위와 후속 배정 제안

반환 완료 범위는 **전체 feature 파일 목록, 기능별 소유권, 위험 유형별 대표 소스 흐름, 구체적인 진단 카드와 검증 질문**이다. 의미/수명 검토가 깊은 대표 경로는 위 R1~R6이며 A03 모든 코드의 동작 확인은 아니다. 다음 범위는 미확인으로 남긴다.

1. 실제 Mapbox style 재생성 이벤트 순서·source readiness·두 번 토글 이후의 시각적 stacking/handler 중복. 주 담당의 기존 실패는 대부분 selector/fixture 경계에서 멈추므로 이 검증을 대신하지 못한다.
2. 모든 runtime image key·geojson anchor의 실물 검증, 이미지 decode 원인, worker/WebGL/Canvas 자원의 장시간 반복 생성 후 잔존 측정. GPU 경고만으로 성능 결함을 판정하지 않았다.
3. 모든 weather 조합의 데이터 없음/오래됨/부분 성공/유효 빈 결과 계약, metadata hash와 동일 URL frame 게시의 종단 일치, 기관 pinned bundle와 live state 교차. A10/A11/W06/W09 계약이 필요한 지점만 반환했다.
4. 경로/브리핑 route preview 계산과 공항/모니터링 전체 내부, 개인/기관 저장·서버 API의 보안/저장 트랜잭션, 모든 KML/KMZ 파일 변종과 ZIP 입력 한도. A03에서 필요한 인터페이스만 읽었고 해당 담당의 심화 조사로 남긴다.
5. CSS 선택자 실제 사용·전체 반응형/접근성·시각 기준선. CSS는 전체 파일 목록과 MapView/UI 관련 역할을 식별했고 A12의 실제 selector/visual 검증을 선점하지 않았다.

후속 ID 제안(등록하지 않음): **RF-002-W05-02 / 비동기 지도 수명과 빈 선택 계약**. 선행은 W03의 last-good/valid-empty 및 frame revision 계약, W04의 clock/snapshot 소유, W05-08 보정 후 주 담당 브라우저 증거다. 범위는 W05-Q1~Q5에서 ‘이미지 pending 중 owner 제거’, ‘shared source 같은 ID 교체’, ‘빈 선택 후 지도·카드 일치’ 각 대표 1개로 한정한다. 완료 조건은 실제 소비자·종료 경로·실행 소유자·관찰 결과 또는 재현 불가 근거를 명시하는 것이며, 전체 지도 리팩터링이나 프로토타입 삭제가 아니다.
