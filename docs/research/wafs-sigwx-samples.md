- 합본마다 15개 예보가 개별 파일과 의미상 일치한다. UUID/identifier 차이는 비교에서 제외했다.

## 지도에서 확인

개발 서버의 `/?wafsSample=1`에서 예보 기준시각을 선택하고 이전/다음, 슬라이더,
시간 변화 재생을 사용한다. 선택한 기준시각의 15개 예보만 순환한다.
화면의 KST/UTC 설정을 반영하며, 시각 전환 중 현상 필터와 지도 위치를 유지한다.
시간 변경 시 선택했던 객체의 상세 정보는 닫아 오래된 속성이 남지 않게 한다.

재생성 및 검사:

```bash
python3 scripts/wafs-sigwx-samples.py --download
python3 scripts/test_wafs_sigwx_preview.py
npm run build
DISABLE_COLLECTION=1 PROJECTAMO_FRONTEND_HOST=0.0.0.0 npm run dev:serve
```

다운로드는 일회성이다. 운영 수집과 연결하지 않았으며 서버 수집은 꺼둔다.
초기 단계에는 운영 빌드에 포함하지 않았다. 아래 정식 UI 연결 이후에는 고정 샘플 한 회차를 public 자산으로 제공한다.

## 검증 범위와 후속 구현

이번 확인은 원본 구조·내용 집계, 합본 중복 대조, 좌표 변환·시간 전환·실제 지도 표시 검사다.
Python 검사 14개, 렌더러 수치 검사 6개와 프런트엔드 빌드가 통과했다. 실제 브라우저에서 시간별 형상 변경,
FRQ 보존, 필터·카메라 유지, F27 태풍 제거, 기준시각 분리, 재생/정지,
배경지도 변경 후 시간 유지, KST/UTC를 확인했고 페이지 오류는 없었다.
상세 실행 결과는 `artifacts/wifs-sigwx/chart-browser-verification.json`에 있다.
전체 XSD 적합성 검증이나 공식 SIGWX 차트와의 형상 대조를 완료했다는 의미는 아니다.
지역 수량은 보간 후 촘촘한 선분으로 근사한 경계/지점의 교차 결과이며 정확한 spline 면 교차 결과가 아니다.

정식 사용 전에는 동일 기준·유효시각의 공식 차트와 곡선·기호 방향을 대조해야 한다.
누락된 두 현상은 추가 fixture를 확보해야 한다.


## 차트 렌더러 1차 구현

- Mapbox: 난류·착빙 면과 클릭용 원본 경계(표시 선은 Canvas에서 그림).
- Canvas: 대류권계면, CB scallop, 제트 축, SVG 기호, 풍속 기호, 화살촉과 라벨.
  지도 투영 좌표를 매 프레임 공유한다. 점 기호는 화면 픽셀 크기를 유지한다.
  CB 경계 장식은 지리 좌표에 고정해 줌 중에는 지도와 함께 확대·축소한다.
  줌/피치/화면 크기 변경이 끝난 뒤 160ms 동안 추가 조작이 없으면 간격을 한 번 재계산한다.
  매 프레임 장식 개수를 바꾸면서 경계가 흘러 보이던 현상을 방지한다.
- 제트 풍속은 가장 가까운 5kt로 반올림해 50kt 깃발, 10kt 긴 깃털, 5kt 짧은 깃털로 분해한다.
  지정 풍속 좌표는 이동시키지 않고 인접한 축의 접선 방향으로 회전한다. 북/남반구의 깃털 방향을 구별한다.
- 고도 라벨은 축 방향에 맞춰 회전한다. 영역 라벨은 원본 경계 앵커와 연결선을 유지하며 충돌 시 이동하거나 생략한다.
  실제 기호는 충돌 때문에 숨기지 않는다. 상세 조회에서는 생략된 속성도 확인할 수 있다.
- 원본에 존재하는 제트 끝점에만 화살촉을 둔다. 잘린 영역 끝에 가짜 끝점 화살촉을 만들지 않는다.
- 난류: MOD 주황 / SEV 빨강. 착빙: MOD 연한 파랑 / SEV 진한 파랑. 상세에서 강도별 SVG와 문자를 표시한다.
- 기호 출처·라이선스와 수정 사항은 `frontend/src/features/weather-overlays/assets/wafs/README.md`에 기록했다.
  패널에도 출처 및 CC BY 4.0 링크를 표시한다.

### 곡선 매개변수 가정

[OGC GML 3.2.1 스키마](https://schemas.opengis.net/gml/3.2.1/geometryPrimitives.xsd)는
끝점 벡터의 방향을 사용하도록 설명한다. 이 구현은 날짜변경선을 연속화한 lon/lat에서
점 사이 거리(chord length)를 매개변수로 사용하고 끝점 벡터를 정규화한 clamped C2 spline을 푼다.
원본 knot를 모두 통과하고, 끝점 접선 방향 및 벡터 크기에 대한 불변성을 검사했다.
구간당 8개 선분으로 출력한다. 고배율에서는 추가 세분화가 필요할 수 있다.

[WMO의 spline 논의](https://github.com/wmo-im/iwxxm/discussions/263)에는 끝점 미분과
매개변수 해석에 관한 논의가 있다. 현 단계에서는 동일 시각 공식 차트와의 일치를 검증하지 않았으므로
이 매개변수 선택을 WAFC 원본 구현과 동일하다고 단정하지 않는다.


## 난류·착빙 선택 표시

난류·착빙은 상시 라벨과 경계선을 숨기고 강도별 면색으로 표시한다.
영역 내부 또는 경계 7px 이내를 누르면 겹친 난류·착빙을 모두 목록에 표시한다.
목록에서 선택한 한 영역은 면 불투명도를 12%p 높여 강조하며, SVG 강도 기호와 하한/상한을 표시한다.
선택 상태에서도 경계선을 그리지 않는다. 겹친 면은 색이 혼합되므로 상세 목록에서 강도와 고도를 확인한다.
미상 고도는 `알 수 없음`으로 표시한다.
선택 시 재생을 멈추며, 시각 변경·필터 변경·표시 해제·닫기 시 강조와 상세를 함께 비운다.
모바일은 상세를 보는 동안 시간 조절부를 접어 지도와 선택 목록 공간을 확보한다.

개별 프레임의 `areas`에는 난류·착빙의 원본 exterior/interior 관계를 보존한 보간 링을 별도로 담는다.
지역으로 자른 열린 경계 조각을 임의로 닫아 면을 만들지 않는다. 날짜변경선은 연속화하고,
극을 한 바퀴 도는 링은 표시 범위 바깥의 극 쪽에서 닫아 지역 안에 가짜 연결선을 만들지 않는다.
면 채움만 표시 범위에 clip하며, 잘린 가장자리는 경계선으로 그리지 않는다.

검증 기록: `artifacts/wifs-sigwx/selection-browser-verification.json`.
상시 라벨 제거, 실제 영역 내부 중첩 선택, 목록 전환, 단일 면 강조, 두 차례 배경지도 전환,
닫기/시간/필터/표시 해제 동기화, 모바일 탭을 확인했다.

### AWC 웹 지도 방식으로 변경 (2026-09-28)

사용자 요청에 따라 난류 파선과 착빙 지그재그를 제거하고 모든 표시 영역을 상시 채운다.
[AWC SIGWX](https://aviationweather.gov/sigwx/)의 공개 범례·렌더링 코드를 참고했다.
이는 AWC 웹 지도 구현의 표현이며, IWXXM 스키마나 PNG 차트 공통 규정이라는 의미는 아니다.

| 현상 | MOD | SEV | 기본 불투명도 |
| --- | --- | --- | --- |
| 난류 | `#FF9900` | `#CC0000` | 30% |
| 착빙 | `#99CCFF` | `#6699FF` | 50% |

해당 팔레트는 샘플 전용 `wafsChartPalette.js`에 한정하고 필터·범례와 공유한다.
상세 글자는 기존 텍스트 토큰을 유지해 밝은 파랑 때문에 읽기 어려워지지 않도록 한다.
MOD 다음에 SEV를 그리며, 기존 원본 링·구멍·날짜변경선 처리와 클릭 조회를 유지한다.
확인 기록: `artifacts/wifs-sigwx/fill-browser-verification.json` 및 선택 동작 검사 기록.

면 상시 표시 검사에서 일부 극지방 spline 링의 위도가 ±90°를 초과하는 보간 overshoot를 확인했다.
화면 투영 전에 ±85°에서 링과 교점을 계산해 자른다. 이 선은 샘플 표시 범위(-20°..70°) 밖에 있어
표시 범위 안의 경계·구멍을 유지한다. 원본 XML이나 샘플 값 자체를 수정하지 않는다.
극지방 clipping 수치 검사 1개를 추가했다(렌더러 수치 검사 총 7개).

### 어두운 배경지도 대응 (2026-09-29)

`basemapId`를 샘플에 전달하고 `wafsChartPalette.js`에서 지도·범례에 사용할 색을 함께 결정한다.
기본 지도는 기존 밝은 팔레트, 단색·위성·윤곽 3종은 어두운 배경용 팔레트를 사용한다.
어두운 배경용 팔레트는 AWC 색상 계열을 유지한 로컬 가독성 조정이며 공식 AWC 팔레트가 아니다.

- 제트 축·풍속 깃털·깃발·화살촉과 화산은 회백색 `#e2e8f0`.
- CB는 밝은 보라색 `#b49aff`, 대류권계면은 밝은 파랑 `#7dd3fc`, 태풍은 `#ff9494`.
- 라벨·점 기호 바탕과 선 외곽은 어두운 남회색 `#0f172a`.
- 난류 MOD/SEV는 `#FFB347` / `#FF6262`, 불투명도 40%.
- 착빙 MOD/SEV는 `#B3DDFF` / `#6DAAFF`, 불투명도 55%.

### 겹침 순서 정리 (2026-09-29)

CSS z-index만 조정하면 Mapbox 내부의 선과 Canvas 면 사이의 순서를 바꿀 수 없다.
난류·착빙을 `wafsHazardFill.js`의 네이티브 Mapbox fill 레이어로 옮겼다.

아래에서 위로:

1. 기본지도와 middle slot의 레이더·위성 등 면 영상
2. 난류·착빙 면: top slot의 첫 레이어. MOD 아래/SEV 위, 같은 강도에서는 착빙 아래/난류 위
3. 기존 top slot의 FIR·항로·공항 등 항공 정보
4. Canvas의 SIGWX: 대류권계면 → CB → 제트 축·깃털·화살촉 → 점 기호 → 라벨
5. 샘플 패널(z-index 6), 지도 메뉴·팝오버(z-index 7)

선택 면 강조는 같은 fill 레이어의 opacity만 바꾼다. 별도의 Canvas 면이나 윤곽선은 없다.
지도 스타일 재설치와 시간·필터 갱신 시 면 레이어의 위치와 팔레트를 재적용한다.
제트 축과 깃털을 같은 Canvas에서 그려 CB 경계가 축만 가리는 순서 불일치도 제거했다.
기존 Mapbox 경계 레이어는 클릭 검사 용도로만 남기고 line-opacity=0으로 둔다.
Canvas의 투명한 나머지 부분은 지도 클릭을 막지 않는다. SIGWX 라벨과 다른 항공 라벨 사이의
충돌 회피까지 해결한 것은 아니며, 실제 혼잡 화면 확인은 여전히 필요하다.

fill 데이터는 원본 외곽·구멍 링을 지역 경계에서 자르고 날짜변경선의 연속 경도를 유지한다.
30개 프레임 전체에서 자르기 전후 내부 판정을 격자 표본으로 비교했으며, 구멍·오목 영역·극지방 링 검사를 통과했다.
네이티브 fill용 1,214개 폴리곤의 earcut 면적 편차는 최대 약 0.023%였다.
수치/순서 테스트 10개, 오프라인 Canvas 호출 순서·테마 전환 검사, 빌드를 통과했다.
실행 환경의 브라우저/네트워크 제한 때문에 실제 지도 화면 검증은 수행하지 못했다.
추가 기록: `artifacts/wifs-sigwx/layer-order-renderer-verification.json`.


### 선 굵기·CB 보라색 조정 (2026-09-29)

사용자 화면 피드백에 따라 대류권계면 선을 1.3px → 2.2px, CB 선을 1.5px → 2.3px로 조정했다.

### SIGWX_LOW 방식의 CB 반원 경계 (2026-09-29)

기존 얕은 quadratic 곡선을 SIGWX_LOW와 같은 반원 호로 교체했다.
좌표 방향을 판별해 외곽은 영역 바깥으로, 구멍은 빈 내부 쪽으로 볼록하게 그린다.
보라색과 2.3px 굵기를 유지하고 바깥 halo는 제거했다. 반원 간격은 안정된 화면에서 약 14px이다.
원본 WAFS spline을 추가로 평활화하지 않는다.

변환기가 `cloudBoundaries`에 잘리지 않은 CB 전체 링을 보존한다. 전체 둘레에 정수 개 반원을
균등 배치한 뒤 화면을 표시 범위로 clip하므로, 잘린 조각을 임의로 닫거나 끝에 작은 반원을 남기지 않는다.
완전한 링의 장식 앵커를 지리 좌표로 캐시해 줌 중에 유지하고, 조작 종료 후 기존 160ms 규칙으로 재계산한다.

- 기존 XML을 재사용해 30프레임을 재생성했으며 CB 링 531개의 닫힘·객체 대응을 확인했다.
- 렌더러 수치 검사 9개(반원 방향·구멍·닫힘·줌 캐시 포함), Python 검사 14개, 오프라인 렌더러 검사와 빌드를 통과했다.
- 밝은/어두운 배경의 코드 기반 경계 비교 이미지는 `artifacts/wifs-sigwx/cb-comparison.png`.
  이 이미지는 모양 비교용이며 실제 지도 스크린샷이 아니다. 현재 브라우저 실행 제한으로 실제 지도 검증은 하지 못했다.

### 축소 시 CB 돌기 과대 표시 수정 (2026-09-29)

사용자 스크린샷에서 축소 종료 후 반원 간격을 다시 14px로 맞추는 동작이 작은 영역의
상대적 돌기 크기를 키우는 것을 확인했다. 이제 zoom 6에서 최대 간격 14px를 기준으로,
그보다 축소하면 `14 * 2^(zoom - 6)`에 따라 간격·반지름을 함께 줄인다.
각 링의 화면상 짧은 변 길이의 1/8도 간격 상한으로 적용한다.
반지름이 모두 2px 미만인 링은 돌기 대신 장식 기준점을 잇는 닫힌 경계로 표시한다.
색과 2.3px 선 굵기는 유지한다. 매우 가까운 원본 영역 자체의 중첩을 제거하는 처리는 아니다.

줌 중 캐시 고정은 유지하며, 축소 종료 후 재계산에서도 반원 개수와 지리적 기준점이
유지되는 것을 회귀 검사했다. 작은 링 크기 제한, 30프레임 오프라인 렌더링 및 빌드도 통과했다.
실제 브라우저 확대·축소 확인은 실행 환경 제한으로 수행하지 못했다.

### 작은 반원 표시 복구 (2026-09-29)

일반 경계로 전환하는 이전 처리 때문에 반원이 사라졌다는 피드백을 반영해 해당 분기를 제거했다.
이제 모든 크기에서 반원을 그린다. 간격은 zoom 5에서 최대 12px, 축소하면 지도와 함께 줄이며
작은 링의 짧은 변 1/6을 상한으로 적용한다. 작은 반원이 두꺼운 선에 메워지지 않도록
평균 반지름에 따라 선 굵기를 0.6~2.3px 사이에서 줄인다.
오프라인 Canvas 호출에서 반지름 2px 미만의 호가 실제 그려지고 선 굵기도 줄어드는 것을 확인했다.

### 축소 화면의 CB 반복 밀도 조정 (2026-09-29)

사용자 의도는 반원 크기뿐 아니라 축소 화면의 반복 개수를 줄이는 것이었다.
간격과 돌출 높이를 분리했다. 조작 종료 후 약 12px 간격으로 다시 배치하므로 축소할수록
반원 개수가 줄어든다. 돌출 높이는 zoom 5에서 최대 6px, 축소하면 지도와 함께 줄고
작은 링의 짧은 변 1/6도 상한으로 적용한다. 따라서 축소 화면에서는 낮고 넓은 반타원이다.
일반 선으로 전환하는 분기는 없다. 줌 조작 중 지리 앵커 고정과 종료 후 160ms 재배치는 유지한다.
반복 개수 감소·돌출 높이 감소·닫힘·조작 중 앵커 유지 검사와 오프라인 Canvas 타원 호출 검사를 통과했다.

### CB 경계 원래 표현 복구

사용자 요청으로 위 SIGWX_LOW 반원 및 축소 밀도 실험을 되돌렸다. CB는 기존 13px 간격의 얕은 이차 곡선 물결과 2.3px 선·halo로 복구했다. 줌 동작 중 지리 좌표 앵커를 유지하고 동작 종료 후 재배치하는 기존 방식, 밝은/어두운 지도별 보라색은 유지한다. 반원용 전체 CB 링 데이터와 크기·개수 조절 코드는 제거했다.

### SIGWX LOW / HIGH 정식 UI 연결 (고정 샘플)

- 기존 `sigwx`의 사용자 표시 이름은 SIGWX LOW, 새 `sigwxHigh`는 SIGWX HIGH다. HIGH의 현상별 필터는 기상 메뉴 안에 있고 샘플 표·별도 재생기는 제거했다.
- 현재 UTC 타임라인에 공개 샘플 첫 회차의 T+6~48(15장, 첫/마지막 간격 42시간)을 48시간 주기로 반복 배치한다. T+48→다음 T+6 사이는 6시간이다. 최근접 프레임을 선택하고 동률은 앞 프레임을 사용한다. 공간/시간 보간은 하지 않는다. 공통 재생기는 다른 활성 자료와 합친 시간 목록 끝에서 처음으로 반복한다.
- 원본 발표/유효시각은 변경하지 않는다. 우상단 자료 시각 카드에 고정 샘플·표시 시각·원본 유효시각을 구분하고 정보창에는 원본 발표도 표시한다.
- `frontend/public/samples/sigwx-high/index.json` + 프레임별 JSON을 켰을 때만 불러온다. 다음 프레임만 미리 가져오며 실패 시 재시도 버튼을 제공한다. 실제 수집·API·서버 설정은 변경하지 않는다.
- 난류/착빙 MOD/SEV 범례는 기존 모델 범례와 구분한다. 영역 클릭 시 겹친 현상 목록·강도·FL 정보창과 선택 면 강조를 제공한다. 공항 클릭과 지도 그리기는 우선하며, HIGH를 클릭했을 때 모델 지점 정보창이 함께 열리지 않게 한다.
- 카메라·지도 범위·투영을 변경하지 않는다. 시간/필터 변경 시 선택을 해제하고, 레이어 OFF 시 Canvas/Mapbox 소스·레이어·클릭 핸들러를 제거한다. 기본지도 교체 시 현재 자료/색으로 복구한다.
- 검증: 시간 매핑·48시간 반복·UTC/KST·public 15프레임 일치, 레이어 설치/해제, 범례 SSR, 기존 타임라인/가시성/형상/면 회귀검사와 오프라인 Canvas 30프레임·7회 팔레트 전환 검사. 브라우저 실화면 검증은 이 실행 환경에서 미수행.
