# VFR 비행 준비 조사 보고서

작성일: 2026-07-31
범위: 한국 국내 중심 / 고정익 자가용·사업용, 헬기, 운항관리사, 비행훈련 관점
방법: 병렬 조사 에이전트 5개(비행절차 / 준비물 / 기상판단 / 도구 벤치마크 / 코드 감사) + 법령 원문 직접 검증

> **읽기 전 주의.** 규정 수치는 조사 에이전트의 웹 검색 결과를 그대로 쓰지 않고, 국가법령정보센터 공개 API로 「항공안전법 시행규칙」(시행 2026-07-01) 원문과 별표 이미지를 직접 받아 대조했습니다. 대조 과정에서 **에이전트가 내놓은 규정 수치 여러 개가 틀린 것으로 확인**되어 7장에 정정표를 따로 두었습니다. 법령 원문으로 확인한 항목은 조문 번호를 붙였고, 확인하지 못한 항목은 "확인 필요"로 표시했습니다.

## 1. 한눈에 보기

**지금 상태.** 이 앱에서 VFR은 "이름만 있는 기능"이 아닙니다. 비행규칙(VFR/IFR)에 따라 수직 프로파일을 다르게 만들고, VFR 전용 경보 기본값(운고 1,000ft / 시정 5,000m)을 갖고 있으며, 지형 고도 데이터와 공역 경계 데이터를 이미 보유하고 있습니다. 예상보다 기반이 있습니다.

**진짜 빈 곳.** 빠진 것은 "VFR 기능"이라기보다 **VFR 조종사가 실제로 내리는 판단을 도와주는 화면**입니다. 지금 앱은 공항 한 점의 기상을 잘 보여주지만, VFR 조종사가 알아야 하는 것은 *출발지와 목적지 사이 전 구간에서, 지형 위로 구름 밑을 계속 볼 수 있는가*입니다. 지형 데이터도 있고 구름 데이터도 세 갈래로 있는데, 이 둘을 한 화면에서 겹쳐 보여주는 곳이 없습니다.

**2차 검증에서 뒤집힌 것.** 1차 조사는 "한국에는 저고도 비행용 기상 자료가 비어 있다"고 봤지만, 「항공기상 운영규정」 원문을 받아 확인하니 **저고도(10,000ft 미만) 전용 중요기상예보 도표와 저고도위험기상정보(AIRMET)가 모두 발표 의무 사항**이었습니다. 그리고 **우리 앱은 그 저고도 SIGWX를 이미 받아서 구름·전선 오버레이까지 만들고 있습니다**. 즉 "자료가 없다"가 아니라 "가진 자료를 VFR 판단 형태로 배치하지 않았다"가 정확한 진단입니다.

**가장 큰 외부 제약.** 한국의 공식 시계비행용 항공지도(VFR 차트)를 지도에 깔 수 있는 형태로 공개 입수하는 경로가 확인되지 않습니다. 이것 하나가 해외 VFR 도구를 그대로 따라 하기 어렵게 만드는 지점입니다. 다만 공역 경계는 앱이 이미 자체 GeoJSON으로 갖고 있어, 차트 없이도 상당 부분 대체됩니다.

## 2. VFR 비행이 실제로 어떻게 진행되는가

### 2.1 단계별 흐름

| 단계 | 조종사 / 운항관리사가 하는 일 | 필요한 정보 |
|---|---|---|
| **사전 계획** | 경로 초안, 지형 회피 고도, 연료·중량 계산 | 지형 고도, 장애물, 공역 경계, 기종 성능표 |
| **브리핑** | 기상과 NOTAM 확인, GO/NO-GO 판단 | 출발·경로·도착의 시정·운고, 악화 추세, 일몰시각, 활성 NOTAM |
| **비행계획 제출** | 비행정보구역(FIR) 안에서 비행하려면 **비행 시작 전 제출 의무** (시행규칙 §182①) | 식별부호, 비행방식, 출발·도착, 순항고도, 예정항로, 소요시간 (§183) |
| **이륙** | 관제권이면 최저치 확인 | 운고 450m(1,500ft) 이상 + 지상시정 5km 이상 (§172①) |
| **항로 비행** | 지문항법·추측항법, 위치보고, 고도 유지 | 지형 대비 구름 밑 여유, 실제 풍향, 시각보고점 |
| **도착·착륙** | 착륙 최저치 재확인 | 도착지 실황, 활주로 방향, 바람 |
| **종료** | 착륙 즉시 도착보고 (§188①) | 식별부호, 출발·도착지, 착륙시간 |

### 2.2 VFR을 정의하는 규칙 (법령 원문 확인)

**시계상의 양호한 기상상태 — 시행규칙 별표 24 (제175조 관련)**

| 고도 | 해당 공역 | 비행시정 | 구름으로부터의 거리 |
|---|---|---|---|
| 해발 3,050m(10,000ft) 이상 | B·C·D·E·F·G | **8,000m** | 수평 1,500m / 수직 300m(1,000ft) |
| 3,050m 미만 ~ 해발 900m(3,000ft) 또는 장애물 상공 300m(1,000ft) 중 높은 고도 초과 | B·C·D·E·F·G | **5,000m** | 수평 1,500m / 수직 300m(1,000ft) |
| 해발 900m(3,000ft) 또는 장애물 상공 300m(1,000ft) 중 높은 고도 **이하** | B·C·D·E | **5,000m** | 수평 1,500m / 수직 300m(1,000ft) |
| 〃 | **F·G** | **5,000m** | **지표면 육안 식별 및 구름을 피할 수 있는 거리** |

비고: F·G 등급의 저고도 구간은 ① 우세시정 하에서 다른 항공기·장애물을 보고 피할 수 있는 속도로 움직이는 경우, ② 그 지역 교통량이 적어 마주칠 확률이 낮은 경우 **비행시정 1,500m까지 완화** 가능. **A등급 공역에서는 시계비행이 허용되지 않음.**

이것과 별개로, **관제권 안 비행장에서 이·착륙하거나 관제권에 진입**하려면 운고 450m(1,500ft) 이상 **그리고** 지상시정 5km 이상이어야 합니다 (§172①, 관제기관 허가 시 예외). 흔히 말하는 "5km / 1,500ft"는 이 조문이지, 모든 공역의 최저치가 아닙니다.

**순항고도 — 별표 21 (피트 단위 지역, 시계비행 열)**

| 자침로 000°~179° (동향) | 자침로 180°~359° (서향) |
|---|---|
| 3,500 / 5,500 / 7,500 / 9,500 / 11,500 ft … | 4,500 / 6,500 / 8,500 / 10,500 / 12,500 ft … |

즉 **동향은 홀수천 + 500ft, 서향은 짝수천 + 500ft**입니다. 이 규칙은 **지표면·수면 상공 900m(3,000ft) 이상**을 비행할 때만 적용됩니다 (§173①). 그 아래에서는 순항고도 규칙이 없습니다.

**최저비행고도 (§199 제1호, 시계비행)**
- 사람·건축물 밀집지역: 항공기 중심 **수평거리 600m** 안의 가장 높은 장애물 상단에서 **300m(1,000ft)**
- 그 외 지역: 지표면·수면 또는 물건 상단에서 **150m(500ft)**
- 예외: 이·착륙 중, 항공교통업무기관 허가, 지상에 위해 없이 착륙 가능한 비상상황 (§172⑤)

**시계비행이 금지되는 경우 (§172③④)**
- 평균해면 6,100m(20,000ft) 초과 고도
- 천음속·초음속 비행
- 수직분리축소공역(RVSM, 29,000~41,000ft)

### 2.3 변형과 예외

**특별시계비행 (§174)** — 예측할 수 없는 급격한 기상 악화 등 부득이한 사유로 관제기관 허가를 받은 경우:
- 허가받은 **관제권 안**에서만
- 구름을 피하여 비행
- **비행시정 1,500m 이상** 유지
- 지표 또는 수면을 **계속하여 볼 수 있는** 상태
- 조종사가 계기비행 자격이 없거나 항공계기를 갖추지 않은 항공기는 **주간에만**. 다만 **헬리콥터는 야간에도 가능**
- 이·착륙은 지상시정 1,500m 이상(보고되지 않으면 비행시정 1,500m 이상)일 때만

**야간 VFR (§172②)** — "야간에 시계비행방식으로 비행하는 항공기는 **지방항공청장 또는 해당 비행장의 운영자가 정하는 바에 따라야 한다**." 즉 전면 금지가 아니라, 지방항공청·비행장별 규정에 위임되어 있습니다. 실제 조건은 관할 지방항공청과 해당 비행장에 확인해야 합니다.

**기상이 나빠졌을 때의 법정 절차 (§184⑥)** — 관제비행 중 VFR 유지가 불가능하다고 판단되면 순서대로: ① 시계비행 상태를 유지할 수 있도록 관제허가 변경 요청(목적지·교체비행장 또는 관제공역 이탈), ② 허가를 못 받으면 관제공역 이탈 또는 가까운 비행장 착륙 예정임을 통보, ③ (관제권 안이면) 특별시계비행 허가 요구, ④ 계기비행 허가 요구. **이 네 갈래가 곧 도구가 지원해야 할 "탈출 선택지"입니다.**

### 2.4 한국 고유의 제약

**공역의 구분 — 시행규칙 별표 23**

| 구분 | 등급 | 내용 |
|---|---|---|
| **관제공역** | A | 모든 항공기가 **계기비행을 해야 하는** 공역 (시계비행 불가) |
| | B | 계기·시계비행 모두 가능, 모든 항공기에 분리 포함 관제업무 제공 |
| | C | 모든 항공기에 관제업무 제공, 단 시계비행기 상호간에는 교통정보만 |
| | D | 모든 항공기에 관제업무 제공, 계기↔시계 및 시계↔시계 간에는 교통정보만 |
| | E | 계기비행기에 관제업무, 시계비행기에 교통정보 |
| **비관제공역** | F | 계기비행기에 비행정보업무 + 항공교통조언업무, 시계비행기에 비행정보업무 |
| | G | 모든 항공기에 **비행정보업무만** |

사용목적별로는 관제권·관제구·비행장교통구역(관제공역), 조언구역·정보구역(비관제공역), **비행금지구역·비행제한구역**(통제공역)으로 나뉩니다.

**비행금지·제한구역 — 실제 지정부호** *(우리 레포의 공역 GeoJSON 기준, 총 211개 구역)*

- **비행금지(P) 19개**: P73, P73A, P518 / P518E / P518W(휴전선), P61A·B, P62A·B, P63A·B, P64A·B, P65A·B, D4006
- **비행제한(R) 85개**: R1, R10, R17, R19~R21, R35, R72, **R75**, R77, R80·81, R84, R88·89, R90A·B, R97A~F, R99, R100, R104·105, R107, R108A~F, R110·111, R114~R129, R131~R141, R142A~C, R143~R147, R148A·B, R149~R158
- **위험(D) 32개**: D1, D2, D5~D9, D13~D37
- **군작전 65개**: MOA 1~41(H/L/E/W 세분 포함), CATA 2~7, HTA 1·2

> 즉 앱은 이미 개별 구역을 지정부호 단위로 갖고 있습니다. AIP ENR 5.1 원문 대조는 최신성 확인용으로만 남습니다.

**초경량비행장치의 기상 요건 — 시행규칙 §310① (확인 완료)**

- 제5호: **별표 24의 비행시정·구름간격 기준을 그대로 적용**. 항공기보다 엄격한 별도 수치는 없습니다.
- 제4호: 안개 등으로 **지상목표물을 육안 식별할 수 없는 상태에서 비행 금지**.
- 제6호: **일몰 후~일출 전 야간 비행 금지**(허가받은 경우와 150m 미만 계류식 기구는 예외).
- 제3호: 관제공역·통제공역·주의공역 비행 금지(비행승인 시 예외). 단 25kg 이하 무인동력비행장치 등은 관제권·비행금지구역이 아닌 곳에서 150m 미만 고도 비행 가능.
- **비행계획 제출 범위**: 관제공역만이 아니라 **비행정보구역 안에서 비행하려는 모든 경우** 제출 의무 (§182①). 긴급출동 등으로 사전 제출이 어려우면 비행 중 제출 가능. 구술·전화·서류·팩스·정보통신망 모두 가능 (§182②).
- **제출 마감시각**: 시행규칙에 일반 항공기용 고정 마감시각 조문 없음. 흔히 인용되는 "출발 1시간 전"은 운영 관행 또는 개별 기관 규정으로 보이며 *확인 필요*.

## 3. VFR 계획에 필요한 준비물

### 3.1 항공지도·항법자료

시계비행은 눈에 보이는 지형지물로 위치를 확인하며 납니다. 그래서 IFR 항로도에 없는 것들이 필요합니다: 지형 고도, 장애물, 시각보고점(VRP), 랜드마크, 공역 경계.

- 항공정보통합관리 **AIM** (aim.koca.go.kr) — 공식 항공지도, eAIP, NOTAM 지도
- **항공정보포털** (airportal.go.kr) — 국내 비행장 정보, 활주로 제원
- **국토지리정보원** (ngii.go.kr) — 지형도
- 민간 앱 **하늘지도** (skymaps.co.kr)

> **도구화 판단**: 지형·장애물은 지도에 얹고 자동 경고까지 가능. 다만 한국 공식 VFR 차트를 지도 타일로 쓸 수 있는 공개 경로는 확인되지 않음.

### 3.2 경로 구성

랜드마크 기반 웨이포인트 선정 → 구간 거리·침로 → 자기편차 보정(한국 약 7~8°W) → 편류수정각 → 예상소요시간(ETE) → 지형 회피를 위한 상승·강하 지점.

> **도구화 판단**: 거리·침로·바람 보정·ETE는 전부 자동 계산 가능. 앱이 이미 Mapbox 위에서 경로를 다루므로 계산 자체는 추가 데이터 없이 가능.

### 3.3 성능과 적재

밀도고도(기온+기압고도) → 이·착륙거리 보정, 상승률 vs 지형, 중량 및 평형(W&B). 기준값은 기종별 POH/AFM에서 나옵니다.

> **도구화 판단**: 밀도고도 계산은 즉시 가능. 이·착륙거리와 W&B는 기종별 성능표를 사용자가 넣어줘야 하므로 "입력 틀 + 계산기" 형태.

### 3.4 연료 — 법정 요건 (시행규칙 별표 17, 제119조 관련)

**항공운송사업·항공기사용사업 외의 비행기(일반 항공)**

| 구분 | 필요 연료 |
|---|---|
| **주간** 시계비행 | 최초 착륙예정 비행장까지 필요한 양 **+ 순항고도로 30분** 더 비행할 수 있는 양 |
| **야간** 시계비행 | 최초 착륙예정 비행장까지 필요한 양 **+ 순항고도로 45분** 더 비행할 수 있는 양 |

**항공운송사업·항공기사용사업용 비행기** 시계비행: 목적지까지 필요한 양 + 순항속도로 **45분**.
**항공운송사업·항공기사용사업용 헬리콥터** 시계비행: 목적지까지 필요한 양 + **최대항속속도로 20분** + 운항기술기준상 예비연료.

### 3.5 공역·NOTAM 확인

- **NOTAM**: aim.koca.go.kr 검색 또는 지도 모드. 출발 전 반복 확인, 유효시간 반영.
- **비행금지구역 좌표**: 공공데이터포털에 국토교통부 비행금지구역 오픈API 존재.
- **제한공역 진입**: 관할 지방항공청 사전 승인.

### 3.6 교체비행장 — VFR은 원칙적으로 불필요

시행규칙 §183 제8호: 비행계획에 포함할 사항 중 **교체비행장은 "시계비행방식에 따라 비행하려는 경우" 제외**. 즉 VFR 비행계획서에는 교체비행장이 요구되지 않습니다. 다만 §161②는 기장에게 비행 전 **대체 비행경로**를 포함한 정보 숙지 의무를 지웁니다 — 법적 서류 요건이 아니라 실무상 "돌아갈 곳" 계획은 여전히 필요하다는 뜻입니다.

## 4. VFR 기상 판단이 IFR과 갈리는 지점

### 4.1 질문 구조가 다르다

**IFR**은 점(point)을 묻습니다 — "목적지가 최저치 이상인가, 교체공항은 되는가."
**VFR**은 선(line)과 시간축을 묻습니다:

- 출발부터 착륙까지 **전 구간**에서 시정이 유지되는가
- **모든 지점**에서 구름 밑면과 지형 사이에 비행할 공간이 남는가 (지형 대비 AGL 개념)
- 시정이 나빠지는 **추세**인가, 그렇다면 되돌아갈 지점이 어디인가
- **일몰**까지 시간이 남는가

### 4.2 VFR에서 더 중요해지는 요소

- **운고를 MSL이 아니라 지형 대비로 읽어야 함.** 태백산맥 상공에서 MSL 2,100m 운고는 산릉선 기준으로는 여유가 거의 없습니다. 앱이 운고와 지형을 각각 갖고 있으면서 함께 보여주지 않는 것이 여기서 문제가 됩니다.
- **연무·황사·미세먼지에 의한 시정 저하** — 상대습도가 낮아도 입자 농도만으로 시정이 떨어짐. 습도가 80%를 넘으면 흡습 성장으로 급락.
- **경사시정(slant visibility)** — 수평시정 5km라도 구름 밑을 비스듬히 내려다보는 시정은 훨씬 짧을 수 있음.
- **산악파·회전 난류**, 계곡 안개·이류무, 해무, 저층 윈드시어.

### 4.3 헬기 고유

저고도 시정, 도심 빌딩풍, brownout/whiteout, DVE(시야 저하 환경). 헬기는 즉시 착륙 가능한 지형이 판단의 핵심인데, 시정이 나쁘면 착륙지 자체를 찾을 수 없습니다. 헬기 운용 고도(100~500m AGL)는 AIRMET 발령 고도대보다 낮아 기존 경고 체계의 사각지대입니다.

### 4.4 계절·지형별 위험

| 시기 | 주요 위험 | 지역 | VFR 영향 |
|---|---|---|---|
| 봄 (3~5월) | 황사·연무 | 전국, 서·남부 | 시정 급락 |
| 봄~가을 | 산악파·회전 난류 | 태백산맥 동사면, 제주 | 저고도 난류, 고도별 풍향 급변 |
| 여름 (6~8월) | 해무 | 서·남해안 | 시정 수백 m, 예보 신뢰도 낮음 |
| 여름 | 국지 대류·뇌우 | 산악 사면 | 예보되지 않은 소나기 |
| 장마 | 저운고 지속 | 남부 중심 | 구름 밑 공간 소멸 |
| 가을 | 산업먼지 연무 | 수도권·영남 | 시정 2~3km |
| 겨울 | 서해 해기차 강설대 | 동해안·영동, 서해안 | 운저 급강하, 시정 붕괴 |
| 겨울 | 역전층 오염 축적 | 내륙 분지 | 혼합층 아래 시정 저하 |

### 4.5 기존 자료의 한계 — **1차 조사의 판단을 뒤집습니다**

1차 조사는 "국내 AIRMET은 FL150 이상만 대상이고, 저고도 항공기용 자료가 비어 있다"고 봤습니다. **틀렸습니다.** 「항공기상 운영규정」(기상청 훈령) 원문을 받아 확인한 결과는 정반대입니다.

**제37조 — 중요기상예보(SIGWX)는 고도대별로 나눠서 발표됩니다**
> 인천비행정보구역 내 **10,000~60,000ft("중·고고도")**와 **10,000ft 미만(산악지역은 15,000ft 또는 그 이상 포함, "저고도")**의 고도로 **각각 나누어 도표로 발표**한다.

즉 **저고도 전용 SIGWX 도표가 이미 존재**합니다. 그리고 중·고고도판은 세계공역예보센터 자료를 쓰지만, 저고도판은 국내에서 만듭니다.

**제41조 — 저고도위험기상정보(AIRMET)는 발표 의무입니다**
> 기상감시소는 인천비행정보구역 내 **저고도를 운항하는 항공기에 영향을 줄 수 있는** 기상현상이 발생하거나 예상되는 경우 저고도위험기상정보를 **발표해야 하며** … 유효시간은 **4시간을 초과하지 않아야** 한다.

**제38조 — GAMET은 "할 수 있다" 규정입니다**
> 기상청장은 저고도 운항을 위한 공역예보의 정기적인 발표가 필요하다고 인정되는 경우 … 이용자와 협의하여 **정할 수 있다.**

발표한다면 평문 약어의 **GAMET 형식** 또는 **도표 형식(상층풍·상층기온 예보 + 중요기상예보)** 중 하나이고, 지면부터 저고도까지의 층을 모두 포함하며 6시간 유효·6시간 주기입니다. 한국은 사실상 **도표 형식(= 저고도 SIGWX)** 쪽을 택한 구조로 보입니다.

**그래서 실제 남는 한계는 이것입니다**

- **GAMET식 서술형 구간 예보는 없습니다.** "이 구간에서 VFR 가능한가"를 문장으로 답해주는 자료가 아니라, 조종사가 도표를 읽고 스스로 해석해야 합니다.
- **TAF는 여전히 공항 주변만** 다룹니다. 공항과 공항 사이는 저고도 SIGWX 도표의 해상도로만 채워집니다.
- **AIRMET은 4시간 유효의 "경보"**입니다. 현상이 기준을 넘을 때만 나오므로, 기준 미만이지만 VFR에는 치명적인 조건(예: 시정 5km 언저리의 연무)은 잡히지 않습니다.
- **격자 자료의 해상도**(수 km)로는 계곡·협곡 규모의 안개와 바람을 표현하지 못합니다. 산악 지역은 AWS가 드물어 보간 신뢰도가 떨어집니다.

> **그리고 결정적으로 — 우리 앱은 이 저고도 SIGWX를 이미 받고 있습니다.** `backend/src/parsers/sigwx-low-parser.js`, `backend/src/processors/sigwx-low-processor.js`, 데이터 디렉터리 `sigwx_low`. 심지어 **구름 오버레이(`sigwx-cloud-overlay.js` → `SIGWX_LOW_CLOUDS`)와 전선 오버레이(`sigwx-front-overlay.js` → `SIGWX_LOW_FRONTS`)까지 이미 만들고 있습니다.** 6장의 레이어 분류에서 SIGWX를 "IFR 중심"으로 적은 것은 잘못입니다 — 이것은 **저고도용, 즉 VFR용 자료**입니다.

### 4.6 VFR용으로 쓸 만한 국내 데이터 후보

| 소스 | 무엇을 주는가 | 접근 |
|---|---|---|
| 기상청 초단기·동네예보 격자 | 시정 직접값은 없고 습도·바람·강수 → 변환 필요 | 기상청 API 허브 / 공공데이터포털 |
| 산악 AWS·시정계 관측망 | 국지 실황 | 기상자료개방포털 (신청 필요) |
| 기상청·도로공사 CCTV | 실제 눈으로 보는 시정 확인 | 기관별 상이, 항공로와 불일치 |
| 위성 저층운·안개 산출물 | 안개 영역 탐지 | 기상청 위성센터 (정확도 육지 50~70%) |
| 에어코리아 미세먼지 | 시정 대리지표 | 공공데이터포털 |

### 4.7 도구가 할 수 있는 것 / 사람이 해야 하는 것

**도구가 계산 가능**: 경로-시간축 단면(각 지점의 시정·운고·바람), 지형 대비 구름 밑 여유 공간, 시정 악화 추세(시간 미분), 일몰시각, 도달 가능한 착륙지 후보, 법정 최저치 대조.

**사람이 판단**: 시정의 질(연무인지 구름인지), 출발 결심 시점의 여유, 산악파의 실시간 회피, 격자가 놓치는 국지 변동, 자신의 기량과 기체 상태.

**거의 모든 도구가 갖춘 기본기 (table stakes)**
1. 항공차트 표시 2. 공역 경계 + 진입 경고 3. NOTAM 통합 4. 기본 기상 오버레이 5. 경로 작성과 거리·시간 계산 6. 지형·장애물 인식 7. 오프라인 대비

**드물지만 가치가 큰 기능 (differentiators)**
- **Hazard Advisor 방식의 지형 색칠** — 현재 고도 기준 100ft 이내 적색, 1,000ft 이내 황색. 지도를 보는 것만으로 "지금 고도로 여기를 지나갈 수 있나"가 읽힘.
- **Glide Advisor** — 엔진이 멈추면 어디까지 활공해서 갈 수 있는지 지도에 원으로 표시.
- **웹캠 통합(Windy)** — 예보가 아니라 실제 사진으로 시정 확인. 해무·계곡 안개처럼 예보가 약한 현상에서 결정적.
- **프로파일 뷰에 기상+지형+공역 동시 표시**.
- **오토라우터** — 지형과 공역을 피하는 경로 자동 생성.

**한국에서의 데이터 제약 (검증된 것)**
- 한국 공식 VFR 섹셔널 차트를 지도 타일/GeoTIFF로 받는 공개 경로: **확인되지 않음**. KOCA 협의가 필요할 가능성.
- 고해상도 지형·장애물 DB: 보안·소관 문제로 공개 여부 불확실. 전역 DEM(SRTM 30m)은 대체 가능하나 저고도용으로는 거칠음.
- **다만 이 앱은 이미 자체 지형 고도 타일과 공역 GeoJSON을 갖고 있어**, 위 제약의 상당 부분을 이미 우회한 상태입니다 (6장 참조).

### 6.5 수직 프로파일의 VFR 적합성

두 개의 서로 다른 세로 단면이 있습니다.

1. **VFR 수직 프로파일** — `buildVfrProfile()` (`profile-composer.js:264-319`). 웨이포인트별 고도 + **지형 윤곽선**. 여기에는 기상이 없습니다.
2. **항로 기상 단면(enroute cross-section)** — `backend/src/briefing/enroute-cross-section.js`, `loadRouteCrossSection()`. 경로 방향의 기상 단면으로, 토글 가능한 층이 **기온·바람·착빙·습도·난류·주의보** 6종입니다 (`crossSectionLayers.jsx:6,15`).

**빠진 것은 "구름 밑면" 한 겹입니다.** 기상 단면에 습도(rh)는 있지만 운저/운고 층은 토글에 없습니다. 그리고 KIM 모델의 **구름량 변수 `cld`는 이미 받아오고 있습니다** — 착빙 계산용으로만 쓰이고 화면에는 노출되지 않습니다 (`enroute-cross-section.js:19,82`).

즉 VFR 조종사가 가장 알고 싶은 "지형 위, 구름 밑에 날 공간이 남는가"는, 지형은 1번 그림에 / 구름 재료는 2번 파이프라인에 각각 흩어져 있어 **한 화면에서 겹쳐 보이지 않는** 상태입니다. 데이터를 새로 구할 필요는 없습니다.
