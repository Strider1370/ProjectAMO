# NOTAM 수집·해석·표시

2026-11-06 운영 자료 전수 점검 뒤 수정한 계약이다.

## 수집과 누락 점검

- KOCA 유효 NOTAM의 기본 24시간 검색 범위를 사용한다. 일정은 기존과 같은 6시간 간격이다.
- 공식 검색 결과 JSON과 KML을 함께 받는다. 검색의 `Total`과 반환 건수가 다르거나, 중복 번호·파싱 탈락·두 원본의 번호/위치/Q-code/유효시각 불일치가 있으면 게시하지 않고 이전 스냅샷을 유지한다.
- KML이 제외하는 QKKKK 체크리스트는 검색 결과의 원문에서 보완한다. 분할 공지 번호(`D3444/26A02` 등)를 각각 보존한다. 위치가 없는 공지를 가짜 위치로 지도에 올리지 않는다.
- 원본 JSON·KML·검색 조건·수집시각·대조 건수·파서 버전을 `DATA_PATH/notam/source/*.json.gz`에 원자 저장하고 최근 12회를 보관한다. 게시 데이터의 `source`에는 경로와 압축 전 JSON의 SHA-256이 있다.
- 새 원본 보관은 배포 후 수집부터 시작한다. 이전 수집 시점의 원본 KML을 복원할 수 있다는 뜻은 아니다.

## 정형 데이터

- `shared/notam-fields.js`가 원문 필드 경계, UTC 시각, 고도, 지리적 제외 조건을 소유한다. E) 본문의 `BOARD)`, `ETD)`, `GND)` 등은 D) 필드로 해석하지 않는다.
- `validity_end`: `fixed` / `estimated` / `permanent`. PERM은 기존 `valid_to` 호환값을 유지하되 화면에서 PERM으로 표시한다. EST도 기간에 표시한다.
- `altitude.lowerBound` / `upperBound`: 각 경계의 `value`, `unit`(SFC/FT/M/FL/UNL), `ref`(AGL/AMSL/STD/null)를 독립 보존한다. 기존 숫자 `lower`·`upper`·`unit`은 호환용이며 새 경계가 우선이다.
- F/G 없이 Q-line만 있는 밴드는 실제 영향 고도라고 단정하지 않고 `고도 확인`으로 표시한다.
- 기존 스냅샷도 캐시에 올릴 때 원문에서 새 표현을 복구한다. 원본 파일은 고치지 않으며 API 콘텐츠 해시에는 보정된 표현이 반영된다.

## 현재 유효 필터

- NOTAM 패널의 `지금 유효한 NOTAM만` 버튼은 목록과 지도에 같이 적용한다.
- B) 이상 C) 미만이며 D) 활동시간 안에 있는 항목만 현재 발효로 판정한다. 종료시각과 정확히 같으면 종료다.
- D)가 없으면 B/C 유효기간을 사용한다. D)를 해석하지 못하면 시간 확인 상태로 남기고, 현재 유효 필터에서는 제외하되 해당 건수와 전체 보기 동작을 제공한다.
- 필터를 끄면 예정 공지도 표시한다. 만료 공지는 기본 목록·지도·공항 탭에서 제외한다.
- 다음 D) 활동 구간이 2시간 안에 시작하면 곧 발효로 표시한다. 현재 판정은 서버의 유효 현재시각을 기준으로 갱신하고 예보 시간 슬라이더와 혼동하지 않는다.
- 새 NOTAM 게시 해시는 기존 60초 증분 갱신 경로에 포함한다. 재요청 실패 시 이전 자료를 유지한다.

## 영역과 브리핑

- FIR 소속(`scope:fir`)과 지역 공역(`coverage:area`)을 구분한다. 지역 금지·제한·위험·사격 NOTAM은 경로 매칭에서 FIR 코드만으로 제외하지 않는다.
- 회랑은 중심선과 NM 반폭을 보존하고 지도에 폭을 가진 면으로 표시한다.
- Q-line 근사 영역과 해석되지 않은 지리적 제외 조건은 목록·팝업에 원문 확인 안내를 표시한다. 해당 도형을 정밀한 확정 저촉으로 승격하지 않는다.
- 지형을 알아야 하는 AGL 경계를 AMSL 순항고도와 그대로 비교하지 않는다. 지형 기준을 확정할 수 없으면 고도 판정 불가다.
- 비행시간과 D) 활동 구간은 실제 구간 교차로 비교한다. 과거 5분 표본 사이의 짧은 활동을 놓치는 방식은 사용하지 않는다.
- RKNY CTR·UA37·ATS 항로 제외의 실제 경계 차감은 구현하지 않았다. 공신력 있는 경계와 수직 적용조건이 확보되기 전까지 제외 조건을 명시하고 판정 불가로 유지한다.
