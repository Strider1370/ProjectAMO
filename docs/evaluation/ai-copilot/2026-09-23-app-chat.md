# 자체 챗봇 구현·Luna 품질 보완

기준일: 2026-09-23 KST. 실제 구현/실행 증거와 미완료 항목을 구분한다. API 성공은 기상 설명 정확도 통과를 뜻하지 않는다.

## 사용자 결정과 구현 상태

- 공급자: OpenAI API. 서버 환경변수만 사용하며 키 값은 문서/로그에 기록하지 않는다.
- 기본 설정: `AMO_AI_ENABLED=1`, `AMO_AI_MODEL=gpt-6-luna`, `AMO_AI_REASONING_EFFORT=low`. Sol 전환 제안 뒤 사용자가 **Luna 개선을 우선**하라고 지시했다. 추가로 low/medium/high의 동일 조건 비교를 진행한다. 테스트 프로세스의 설정 변경과 앱 기본값 변경은 별개다.
- 3A: 인증·Origin·소유권, 대화 revision/멱등 재전송, 45초·모델 3회·도구 4회 상한, 취소, 인메모리 만료, 서버 전용 Responses 어댑터를 구현했다. 실제 API 호출과 자동 테스트를 실행했다.
- 3B: 우측 하단 기상이 버튼, 이동/확대/접기 가능한 플로팅 창, 모바일 full sheet, 메시지·근거·초안 보존을 구현했다. 실제 공급자와 브라우저 인증을 모두 관통하는 통합 인수, 공항 상세 action은 남는다.
- 4A: 적용 경로 export/등록, UTC·geometry·marker·NWP 선택·서버 절차 자료 검증과 `context_ref` 연결을 구현 중이다. 맥락 충돌 UI와 여러 경로/시각 동등성은 남는다.
- 4B/4C 및 5~7 전체 완료를 의미하지 않는다. KIM NWP 추가 수집 및 배포는 하지 않았다.

## Luna 개선 내용

1. 현재 시각과 이전 시간창은 코드로 결정한다. `hoursFromNow`, `usePreviousWindow`, `localWindow/localAt`로 모델의 UTC 산술·이전 ISO 문자열 재작성을 줄인다. 다른 시각 모드를 동시에 지정하면 거부한다.
2. 모델에 전달하는 시간은 사용자 표시 시간대로 변환한다. 원본 결과·UI 카드·저장은 UTC 그대로다. 기상 수치, 누락 상태, 자료 시간과 coverage는 유지하고 opaque hash/storage metadata만 모델 입력에서 제외한다.
3. TAF의 요청 이후 변화, 이미 끝난 일시/확률 변화는 모델용 결과에서만 제외하고 개수·인덱스·사유를 남긴다. 이전 FM/BECMG와 시각 미상 변화는 남겨, 전이 후 상태를 기본 예보로 잘못 되돌리지 않는다. 원본 카드의 전체 변화는 보존한다.
4. OpenAI strict 도구 schema 및 구조화 답변을 사용한다. optional 필드의 nullable 전송과 앱 Zod 검증을 분리한다. **구조가 맞는 응답도 의미상 틀릴 수 있으므로 사실 검증을 대체하지 않는다.**
5. 모델에 매번 보내는 일반 대화 문장은 최근 3쌍+새 질문으로 제한하고, 공항·조회 구간·관측/예보 시각은 도구 결과 기반 슬롯에 보관한다. UI의 대화 기록은 이 제한과 별개다. 없는 과거 사실을 모델 요약으로 만들어 저장하지 않는다.

[OpenAI 공식 도구 호출 지침](https://developers.openai.com/api/docs/guides/function-calling)의 코드로 계산 부담 이전·명확한 인자·strict schema 원칙을 적용했다. [구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs)은 형식 제약이지 항공기상 정확도 보장이 아니다. [Luna 모델 문서](https://developers.openai.com/api/docs/models/gpt-6-luna)로 Responses/추론 설정 지원을 확인했다.

## 평가 방법과 발견

- `backend/ai-chat-eval.js --live`만 실제 유료 API를 호출한다. 일반 자동 테스트는 실제 API를 호출하지 않는다.
- `--frozen=artifacts/ai-copilot/luna-eval-etKEJU`는 공개 공항/경보 snapshot과 `2026-09-23T11:46:06Z`를 고정한다. live 수집이 평가 도중 자료를 바꾸지 않는다. frozen 평가 결과를 최신 날씨로 제공하지 않는다.
- 기본 10턴: 공항 현재/후속 시간창, 경로 착빙/난류 한계, TAF 범위, 시간 의미, unknown, AIRMET 단독 조회.
- `--suite=boundaries`: 자정 날짜 경계, KST/UTC 전환, 지정 시각 SIGMET, 잘못된 안심 요청, 모호한 공항명, 출발공항 미정, 과거 관측 구분.
- `--suite=advisories`: 합성 자료로 실제 존재하는 착빙/난류, FL/FT/AMSL, 유효시각 미상/취소, source prompt injection, 만료 후 안전 단정 거부를 추가 확인한다. 합성 결과는 실제 날씨가 아니다.
- 최초 개선 두 번의 기본 10턴에서는 입력이 48,639 → 38,906/39,351토큰으로 약 19~20% 감소했다. 평균 지연은 3.85초 → 3.88/3.75초로 유의미한 속도 개선을 주장할 수 없다. 질문/수집 상태에 따라 달라지는 소규모 반복 표본이다.
- 발견을 숨기지 않는다: 기본 low에서 외국어 단어 혼입·TAF 종료일 오류, 개선 2차에서 요청 이후 변화 혼합, 후속 보완에서도 종료일 축약 오류가 관찰됐다. 경계 질문에서는 서울공항을 김포로 바꾸거나 공항 미정인데 이전 공항을 조회하는 문제도 있었다. 따라서 **Luna 사용 가능성은 확인했으나 품질 전체 통과는 아니다.**
- 추론 강도 비교는 같은 코드·고정 자료·동일 경계 10턴으로 실행했다. 각 설정 1회이므로 통계적 우열이나 성공률을 주장하지 않는다.

### 추론 강도만 변경한 비교

| 설정 | 입력 토큰 | 출력 토큰 | 캐시 입력(입력의 일부) | 평균 응답 | 표준 토큰 비용 추정/10턴 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Luna low | 42,785 | 2,057 | 19,832 | 4.60초 | $0.00352 |
| Luna medium | 36,138 | 2,834 | 13,838 | 4.98초 | $0.00379 |
| Luna high | 38,838 | 4,611 | 15,773 | 7.10초 | $0.00477 |

산식: `(입력−캐시입력)×$0.10/M + 캐시입력×$0.01/M + 출력×$0.50/M`. 2026-09-23 [공식 Luna 단가](https://developers.openai.com/api/docs/models/gpt-6-luna) 기준이며, 실제 청구액이 아니다. cache write·서비스 tier/지역 가산 등 별도 비용을 포함하지 않는다. 입력 차이는 모델의 도구 호출/답변 길이가 다음 턴에 영향을 주기 때문이다. 병렬 독립 평가이므로 네트워크·공급자 지연도 섞여 있다.

관찰:

- high는 21:03 KST가 평가 기준 20:46 KST보다 **미래**임을 정확히 구분했다. medium은 후속 답변에서 이를 과거라고 잘못 표현했다.
- 공항 미정 질문에서 medium/high는 추가 입력을 요청했다. low는 이전 공항에 길이 0인 시간창으로 불필요하게 호출했다가 오류를 설명했다.
- high도 완전하지 않았다. 직전 도구가 제공했던 20:45 KST 수집 시각을 후속 답변에서 미확인이라고 잘못 정정했다. 원자료를 다음 턴에 전부 반복하지 않더라도 필요한 출처 사실을 구조적으로 보존할 필요가 있다.
- 원문 공항명을 보내도록 보완한 뒤 서울공항→김포 임의 대체는 이 표본에서 재현되지 않았지만, “제주도”를 별칭으로 해석하지 못해 조회 대신 되묻는 문제가 세 설정 모두에서 발생했다. 추론 상향만으로 resolver/도구 계약의 빈틈을 해결할 수 없다.
- 출력 토큰은 high가 low의 약 2.24배, 평균 지연은 약 1.54배였다. 이 작은 표본에서는 상향 비용이 크지 않았지만, **high면 모든 오류가 사라진다거나 모든 질문에 최적이라고 결론내릴 수 없다.**

결론: 추론 상향은 유효한 비교축이다. 추가 구조 확대보다 먼저 확인했어야 한다는 사용자 지적을 반영했다. 앱 기본값은 임의 변경하지 않고 low로 유지했으며, 설정 선택과 후속 보완을 사용자와 이어서 결정한다. 원시 기록: `luna-reasoning-{low,medium,high}.jsonl`.
