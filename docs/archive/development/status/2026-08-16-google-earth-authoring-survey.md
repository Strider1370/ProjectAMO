# 구글어스 작성 기능 전수 조사 (2026-08-16)

**목적:** 구글어스에서 조종사가 지도를 **만드는** 기능 전부를 대화상자 항목 단위로 확인한다. 우리가 그리기 도구를 만들 때 무엇을 베낄지 판단하는 근거.

**조사 방법:** 구글 공식 문서(Earth Help, Earth Outreach, KML 개발자 문서, Earth 릴리스 노트) + 실제 파일 해부(`맥케이 비행지도 ver.230729.kmz`, 16.5MB `doc.kml`).

---

## 0. 구글어스는 두 개다

| | **Earth Pro (데스크톱)** | **Earth Web (브라우저)** |
|---|---|---|
| 만들기 단위 | `내 장소(My Places)` 트리 | `프로젝트(Project)` |
| 설정 방식 | **탭이 나뉜 속성 대화상자** | 오른쪽 속성 편집 패널 |
| 고도 | **5개 모드 + 값 입력 + 벽 내리기** | 없음 |
| 저장 | 로컬 파일 (KML/KMZ) | 구글 드라이브 |
| 3D 시점 저장 | 있음 (LookAt / Camera) | 있음 (Capture this view) |

**맥케이 지도는 Pro로 만들어졌다.** 근거: 파일에 `LookAt` 1,209개 · `Camera` 252개 · `gx:altitudeMode` 919개 · `ListStyle` 132개가 있는데, 이건 전부 데스크톱판이 쓰는 요소다. 웹판은 이것들을 만들지 않는다.

**결론: 베낄 대상은 Earth Pro다.** 웹판은 고도 설정이 아예 없어서 공역을 만들 수 없다.

## 1. 만들기 도구 — 넷

Pro 상단 도구모음에 있는 것 전부.

| 도구 | 하는 일 | 조작 |
|---|---|---|
| **지점 추가** (Add Placemark) | 좌표 하나에 아이콘 | 단추 누르면 대화상자가 열리고, 지도의 아이콘을 끌어 위치를 잡는다 |
| **경로 추가** (Add Path) | 열린 선 | 지도를 **클릭해서 점을 찍거나, 누른 채 끌면 자유곡선**이 그려진다 |
| **다각형 추가** (Add Polygon) | 닫힌 면 | 경로와 같은 조작. 자동으로 닫힌다 |
| **이미지 오버레이 추가** | 지도 위에 그림 깔기 | 초록 손잡이로 옮기고·돌리고·늘린다. 투명도 조절기 |

여기에 **폴더 추가**와 **투어 녹화**가 메뉴에 따로 있다.

**중요한 조작 두 가지:**

- **점을 찍는 중에도 대화상자가 열려 있다.** 그리면서 이름과 색을 동시에 고친다. 다 그린 뒤 설정하는 방식이 아니다.
- **꼭짓점은 언제든 추가·이동·삭제된다.** 대화상자가 열려 있는 동안 지도의 점을 끌면 움직이고, 누르면 지워진다.

## 2. 지점(Placemark) 대화상자 — 탭 4개

### 기본 탭

| 항목 | 내용 |
|---|---|
| **이름** | 지도에 글자로 뜬다 |
| **아이콘 단추** | 이름칸 오른쪽. 누르면 아이콘 고르개가 열린다 (§5) |
| **위도 · 경도** | 직접 입력 가능. **세 가지 형식을 다 받는다** — 십진도(`49.11675953N`), 도분초(`49 7'20.06"N`), 도분(`49 7.0055722'N`). `N/S/E/W` 또는 음수 부호 |
| **설명** | 여러 줄. **HTML 그대로 먹는다** |
| ─ 웹 이미지 추가 | 주소를 넣으면 `<img>` 태그가 설명칸에 자동 생성 |
| ─ 로컬 이미지 추가 | 내 컴퓨터 사진. KMZ로 저장하면 사진이 파일 안에 같이 들어간다 |
| ─ 유튜브 | 유튜브의 삽입 코드를 붙여넣으면 풍선 안에서 재생된다 |

### 스타일·색상 탭

**두 줄로 나뉜다 — 이름표와 아이콘을 따로 설정한다.**

| | 색 | 크기(배율) | 투명도 |
|---|---|---|---|
| **이름표(Label)** | ✔ | ✔ | ✔ (0~100%) |
| **아이콘(Icon)** | ✔ | ✔ | ✔ (0~100%) |

아이콘 색은 원본 그림에 **색을 덧입히는** 방식이다. 그래서 흰 아이콘 하나로 온갖 색을 만들 수 있다 — 맥케이 파일이 흰 원(`wht-circle`)에 32가지 색을 입혀 쓰는 이유다.

### 보기 탭

| 항목 | 내용 |
|---|---|
| **현재 화면 담기** (Snapshot current view) | 지금 보고 있는 카메라 위치·각도·거리를 이 지점에 저장. 나중에 이 지점을 누르면 그 화면으로 날아간다 |
| 경도·위도·고도·방위·기울기·거리 | 각각 직접 입력 가능 |

### 고도 탭

| 항목 | 내용 |
|---|---|
| **고도 모드** | 5개 중 선택 (§4) |
| **고도값** | 미터. 조절기 또는 숫자 입력. *땅에 붙임 모드에서는 입력 불가* |
| **땅까지 선 내리기** (Extend to ground) | 켜면 공중의 지점에서 땅까지 수직선이 그어진다 |

## 3. 경로·다각형 대화상자 — 탭 5개

지점의 4개 탭에 **측정 탭**이 하나 더 붙는다.

### 스타일·색상 탭 — 지점과 다르다

**선 부분 (경로·다각형 공통)**

| 항목 | 값 |
|---|---|
| 색 | 자유 |
| **굵기** | 숫자. 맥케이 파일 실사용값 0.9 / 1.5 / 2 / 3 / 4 / 5 / 7 |
| 투명도 | 0~100% |

**면 부분 (다각형만)**

| 항목 | 값 |
|---|---|
| 색 | 자유 |
| 투명도 | 0~100%. 맥케이 파일은 20~30%를 주로 씀 |
| **표시 방식** | **채움+테두리 / 채움만 / 테두리만** 셋 중 하나 |

> "테두리만"은 실무에서 자주 쓴다 — 면을 그려놓고 아래 위성사진을 보려고 채움을 끈다.

### 고도 탭 — 여기가 공역을 만드는 자리

| 항목 | 내용 |
|---|---|
| **고도 모드** | 5개 중 선택 |
| **고도값** | 미터 |
| **옆면을 땅까지 내리기** (Extend sides to ground) | **켜면 다각형이 기둥이 된다.** 면을 5,000ft에 띄우고 이걸 켜면 땅에서 5,000ft까지 벽이 선다 |

**옆면 색은 스타일·색상 탭의 면 색을 따라간다.**

### 측정 탭

| | 표시되는 값 |
|---|---|
| 경로 | **길이** |
| 다각형 | **둘레 · 면적** |

단위는 `도구 > 옵션 > 측정 단위`에서 피트/미터를 고른다. 이 탭은 읽기 전용이다 — 그린 결과를 재서 보여준다.

## 4. 고도 모드 5개 — 정확한 뜻

| 모드 | 기준 | 고도값 입력 |
|---|---|---|
| **땅에 붙임** (Clamped to ground) | 지형 표면에 딱 붙음. 언덕을 따라 오르내림 | **불가** |
| **해저에 붙임** (Clamped to sea floor) | 바다 밑바닥에 붙음 | **불가** |
| **지면 기준** (Relative to ground) | 그 자리 지면에서 ○m 위 | 가능 |
| **해저 기준** (Relative to sea floor) | 해저에서 ○m 위 | 가능 |
| **절대 고도** (Absolute) | **해수면에서 ○m 위.** 지형과 무관 | 가능 |

**항공 쓰임새 구분:**

- **공역·항로 고도는 `절대 고도`가 맞다.** MSL 기준이니까. 지면 기준으로 하면 산 위에서 공역 천장이 함께 올라가 버린다.
- **장주·지문항법 선은 `땅에 붙임`이 맞다.** 지형을 따라가야 읽힌다.

맥케이 파일 실측: `relativeToGround` 187곳, `absolute` 5곳, 나머지 1,943곳은 기본값인 `땅에 붙임`. **즉 그 파일은 고도를 거의 안 쓴다** — 작성자가 평면 지도로 만들었다.

## 5. 아이콘 고르개

| 묶음 | 개수 | 주소 형태 |
|---|---|---|
| **압정** (pushpin) | **8** | `.../kml/pushpin/[색]-pushpin.png` — 파랑·초록·하늘·분홍·보라·빨강·흰·노랑 |
| **판** (paddle) | **128** | `.../kml/paddle/[기호].png` — 숫자 1~10, 알파벳 A~Z, 8색 변형, 특수(go·stop·pause·route·blank·circle·diamond·square·stars) |
| **그림기호** (shapes) | **100+** | `.../kml/shapes/[이름].png` — 교통·시설·날씨·활동·일반 |
| pal2 / pal3 / pal4 | 각 64 | 옛 팔레트. **더 이상 핵심 아이콘이 아니며 표준 아이콘으로 자동 대체됨** |
| pal5 | 128 | 큰 변형 포함 |

**기본 고르개에 나오는 것은 압정+판+그림기호 = 236종 이상.**

**사용자 아이콘 추가** — 단추를 눌러 **웹 주소를 넣거나 내 컴퓨터 그림을 고른다.** KMZ로 저장하면 그림이 파일 안에 함께 들어간다.

맥케이 파일이 실제로 쓴 것은 37종. 가장 많이 쓴 것은 노랑 압정(174개), `pal2/icon24`(98개), 보라 압정(46개), 공항 기호(32개).

## 6. 자(Ruler) 도구 — Pro는 탭 6개

| 탭 | 재는 것 |
|---|---|
| 선 (Line) | 두 점 사이 직선거리 |
| 경로 (Path) | 여러 점을 이은 총 거리 |
| 다각형 (Polygon) | 둘레·면적 |
| **원 (Circle)** | 반경·면적 — *Pro 전용* |
| **3D 경로** | 고도를 반영한 실제 길이 — *Pro 전용* |
| **3D 다각형** | 고도를 반영한 면적·둘레 — *Pro 전용* |

**고도 단면도** — 경로를 고르고 `편집 > 고도 단면 보기`. 가로축 거리, 세로축 해발고도 그래프.

## 7. 정리와 저장

| 기능 | 내용 |
|---|---|
| **폴더** | 만들고 이름 붙이고 계층으로 쌓는다. 맥케이 파일은 175개 사용 |
| **끌어 옮기기** | 좌측 목록에서 도형과 폴더를 끌어 다른 폴더에 넣는다 |
| **폴더 설정 상속** | 폴더에 준 설정이 그 안의 모든 것에 적용된다 |
| **폴더 재생** (Play Folder) | 폴더 안의 것들을 순서대로 훑는 자동 투어 |
| **임시 장소** | 이번에 연 것은 `임시 장소`에 들어가고, 종료할 때 저장할지 묻는다 |
| **다른 이름으로 저장** | 폴더를 오른쪽 클릭 → **KML 또는 KMZ** |

**KMZ를 권하는 이유(구글 문서 표현):** 사용자 아이콘·사진이 파일 안에 함께 들어가서 **본체와 부속이 분리될 일이 없다.**

## 8. Earth Web에만 있는 것 (참고)

데스크톱에 없지만 웹에 있는 것들. 우리가 참고할 값어치가 있는 것만.

| 기능 | 시기 | 내용 |
|---|---|---|
| **자동 스타일 물려받기** | 2025-11 | 마지막에 고른 스타일을 다음에 그리는 같은 종류 도형이 자동으로 따라간다. 도형 종류별로 따로 기억한다 |
| **스타일 복사·붙여넣기·초기화** | 2025-11 | 한 도형의 모양새를 같은 종류 다른 도형에 찍어낸다 |
| **여러 개 한꺼번에 고치기** | 2026 | Shift·Ctrl 클릭으로 여러 도형을 골라 동시에 스타일 변경 |
| **자료값에 따른 색칠** | 2025-10 | 균일 / 종류별 / **숫자 크기에 따른 그라데이션** |
| **고도 단면도 자동 표시** | 2026-04 | 선을 그리면 옆 패널에 자동으로 뜬다 |
| 불러오기 형식 | 2026-06 | KML · KMZ · GeoJSON · **Shapefile** 정식 지원 |

**자동 스타일 물려받기는 반드시 베껴야 한다.** 지점 1,491개를 찍는데 매번 색을 다시 고르게 하면 도구를 안 쓴다.

## 9. 우리 상태와 대조

### 베낄 것

| 구글어스 기능 | 우리 상태 |
|---|---|
| 지점·경로·다각형 그리기 | 폴리곤만 있음 (`custom-area/usePolygonDraw.js`), 점·선은 측정용 일회성 |
| **그리는 중에 설정 대화상자가 열려 있음** | 없음 |
| **꼭짓점 추가·이동·삭제** | `mapbox-gl-draw`가 기본 제공 |
| 좌표 직접 입력 (3형식) | **있음** — `custom-area/coordFormat.js` |
| 이름 | 없음 |
| 설명 (여러 줄) | 없음 |
| 이름표 색·크기·투명도 | 없음 |
| 아이콘 236종 + 색 덧입히기 + 크기 + 투명도 | 없음 |
| 선 색·굵기·투명도 | 색만 (9색 고정) |
| 면 색·투명도 + **채움/테두리/둘다** | 색만 |
| 고도 모드 5개 + 고도값 | 없음 |
| **옆면을 땅까지 내리기 (기둥 만들기)** | 읽기만 됨 (`kmlWalls.js`) |
| 측정 (길이·둘레·면적) | **있음** — `map-tools/geo.js` |
| 폴더 만들기·끌어 옮기기 | 읽기만 됨 |
| KML/KMZ 내보내기 | **없음** |
| 자동 스타일 물려받기 | 없음 |

### 뺄 것 — 근거 있음

| 기능 | 왜 빼나 |
|---|---|
| **저장된 시점** (Snapshot view) | 맥케이 파일에 1,209개 있으나, 실측에서 **지점을 제대로 비추는 것이 4.5%뿐**. 45%는 1km 넘게, 14%는 10km 넘게 어긋남 |
| **강조 스타일** (StyleMap) | 543개 중 220개가 평상시와 완전 동일. 나머지도 아이콘 크기 1.2→1.4가 전부. 구글어스 기본값이지 작성자의 뜻이 아님 |
| **해저 기준 고도 2종** | 항공에 쓸 일 없음 |
| **이미지 오버레이** | 맥케이 파일에 0개. 우리는 레이더·위성을 이미 우리 자료로 깐다 |
| **투어 녹화 · 폴더 재생** | 발표용. 비행계획과 무관 |
| **설명칸 HTML·사진·유튜브** | 맥케이 파일의 설명 39개가 전부 짧은 평문(`물찻오름`, `위미항`). 여러 줄 글상자면 충분 |
| **폴더 아이콘 꾸미기** (ListStyle) | 구글어스가 자동 생성한 것 |
| **원 도구** | 구글어스엔 아예 없음. 우리 `map-tools` 반경 도구가 이미 더 나음 |

### 이길 것

| 구글어스의 한계 | 우리가 할 수 있는 것 |
|---|---|
| 공역 기둥을 만들려면 **세로 판자를 손으로 수천 장 이어붙여야 함** (맥케이 파일 `10NM wall` 폴더가 그 증거) | 면 하나 그리고 **바닥·천장 두 칸**만 채우면 기둥. 내보낼 때만 구글어스가 알아먹는 판자로 변환 |
| 다각형 고도가 **한 값뿐** — 바닥·천장을 따로 못 줌 | 두 값을 받는다 |
| 원 도구 없음 | 반경 도구 있음 |
| 기상 없음 | 그린 지도 위에 레이더·SIGMET·지형근접이 그대로 겹침 (스파이크에서 확인) |

## 10. 아직 확인 못 한 것

1. **자 도구 탭 이름 6개** — Pro 전용 3개(원·3D경로·3D다각형)는 확인됐으나, 표준 3개의 정확한 탭 이름은 문서마다 다르게 적혀 있다. 우리는 이미 측정 도구가 있어 설계에 영향 없음.
2. **아이콘 고르개의 정확한 화면 배치** — 개수와 주소 체계는 확인됐으나 몇 줄 몇 칸으로 보여주는지는 미확인.
3. **경로 자유곡선(누른 채 끌기)의 점 밀도** — 구글어스가 초당 몇 개를 찍는지 미확인. 맥케이 파일의 좌표 22만 개가 이 방식에서 나왔을 가능성이 크다.
