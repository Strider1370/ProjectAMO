# Spec: 위험기상 수평 교차와 경로 인접 분리

**Status:** Approved
**Created:** 2026-07-23

## Problem / Goal

현재 SIGMET/AIRMET 경로 판정은 항로가 위험 폴리곤 내부를 지나는 경우와 폴리곤에서 30NM 이내를 지나는 경우를 하나의 `horizontalExposure` 및 "수평 교차" 거리로 합친다. 그 결과 조종사가 폴리곤을 피한 대안 경로도 더 큰 "수평 교차" 거리로 보일 수 있고, 고도 비교와 정식 브리핑의 "실제 조우" 표기도 항행 여유를 반영한 수평 해당 여부와 일치하지 않을 수 있다.

이 작업의 목표는 실제 폴리곤 내부 통과와 30NM 브리핑 범위를 구분해, 경로 비교·고도 비교·정식 브리핑이 같은 사실을 같은 용어로 표시하게 하는 것이다. 이 시스템은 경로의 안전성이나 우선순위를 판단하거나 추천하지 않는다.

## Requirements

- FR-001: 시스템은 각 SIGMET/AIRMET에 대해 다음의 서로 겹치지 않는 수평 결과를 산출해야 한다.
  - **수평 교차:** 계획 항로 중심선의 좌우 2NM 항행 여유를 포함한 경로가 위험 폴리곤과 겹치는 구간과 거리.
  - **경로 인접 (30NM):** 2NM 항행 여유와는 겹치지 않으면서 항로 중심선에서 30NM 이내인 구간과 거리.
- FR-002: 경계 접촉은 별도 상태, 별도 표시, 별도 테스트 대상으로 만들지 않는다.
- FR-003: Polygon과 MultiPolygon 모두 지원해야 하며, 폴리곤의 hole은 위험 영역으로 계산해서는 안 된다. 항로가 진입·이탈을 반복하는 경우 각 연속 구간을 보존해야 하며, 그 사이의 비해당 구간을 거리로 포함해서는 안 된다.
- FR-004: 수평 교차와 경로 인접은 계획 고도 적용성 판정과 독립적으로 유지해야 한다. 시간 유효성이 비행 시간과 일치하지 않는 advisory는 현재와 같이 경로 결과에서 제외한다. 시간·고도 자료가 없거나 판정 불가인 경우에는 기존 데이터 상태를 보존해야 하며, 이를 "해당 없음"으로 바꾸어서는 안 된다.
- FR-005: 기본 경로와 모든 대안 경로 카드는 위험기상별로 `수평 교차 N NM`과 `경로 인접 (30NM) N NM`을 각각 표시해야 한다. 값이 0NM인 항목은 혼동을 줄 수 있으므로 표시하지 않아도 된다.
- FR-006: 경로 카드의 위험기상 합계는 수평 교차 합계와 경로 인접 합계를 별도로 표시해야 하며, 동일 종류의 여러 위험 폴리곤이 겹치는 구간은 각 합계 안에서 한 번만 계산해야 한다.
- FR-007: 고도 비교 화면과 정식 경로 브리핑은 수평 교차와 경로 인접을 구별해 표시해야 한다. 같은 advisory에 두 종류의 구간이 모두 있으면 정식 브리핑은 `수평 교차`와 `경로 인접 (30NM)` 구간을 모두 표시해야 한다.
- FR-008: 기본 경로와 대안 경로의 위험기상 표시는 고도를 고려하지 않고 수평 교차와 경로 인접만 표시한다. 고도 비교와 정식 경로 브리핑에서만 `encounter: 'on'`의 사용자 표시 의미를 수평 교차, 시간 일치, 고도 일치가 모두 확인된 경우로 제한한다. 수평 교차 없이 경로 인접만 해당하는 경우에는 시간·고도가 일치해도 `인근`으로 표시한다.
- FR-009: 기본 경로, 대안 경로, 고도 비교, 정식 브리핑은 모두 공통 `routeModel.enRouteRange`만 사용해야 한다. 기존 API의 advisory 식별자, 현상명, 유효 시간, 고도대 및 데이터 상태는 보존해야 한다.
- FR-010: 수평 교차 또는 경로 인접 결과가 없는 경우에만 해당 위험기상을 경로 결과에서 제외할 수 있다. geometry가 없거나 해석할 수 없는 경우에는 기존처럼 unavailable 상태를 보존해야 한다.
- FR-011: 2NM 항행 여유는 이번 기능의 고정값으로 모든 수평 판정 화면에 동일하게 적용해야 한다. 사용자가 변경하는 설정으로 만들지 않는다.
- FR-012: 수평 교차/경로 인접은 화면의 사실 표시에만 사용한다. 2NM 수평 교차가 없는 2–30NM 경로 인접 SIGMET/AIRMET도 기존과 같은 시간·고도 적용 조건에서는 기존 브리핑 심각도와 알림 대상 여부를 유지해야 한다.

## Non-Goals (out of scope)

- 30NM 또는 2NM의 폭을 사용자 설정으로 만들거나 값을 변경하지 않는다.
- SIGMET/AIRMET 원문 수집, 파싱, 지도 폴리곤 렌더링, 지도 위 경로 구간의 별도 색칠은 이번 범위에 포함하지 않는다.
- 기존 SIGMET/AIRMET의 브리핑 심각도 규칙 또는 알림 발송 기준을 완화하지 않는다.
- 위험기상별 심각도 점수, 경로 추천, 안전/위험 판정, 회피 경로 자동 생성은 만들지 않는다.
- NOTAM의 실제 영역 통과 규칙은 바꾸지 않는다.
- 기상 현상의 이동 예측이나 시각별 폴리곤 보정은 하지 않는다.

## Success Criteria

- SC-001: 폴리곤에서 2NM보다 멀리 떨어져 있으면서 30NM 안을 지나는 경로는 `수평 교차 0NM` 및 양수의 `경로 인접 (30NM)`으로 구분된다.
- SC-002: 폴리곤 내부를 지나거나 폴리곤이 계획 항로에서 2NM 이내인 경로는 양수의 수평 교차를 보이며, 그 구간은 경로 인접 거리와 중복 계산되지 않는다.
- SC-003: 기본 경로, 대안 경로, 고도 비교, 정식 브리핑에서 같은 advisory와 같은 항로에 대해 수평 교차/경로 인접 결과가 일관된다.
- SC-004: 폴리곤 재진입, MultiPolygon, hole, 30NM 밖, 시간 불일치 제외, geometry 불가, en-route 범위 제외를 포함한 자동 테스트가 통과한다.
- SC-005: 기존 경로 비교·고도 비교·브리핑 API 테스트와 브라우저 경로 워크플로 검증이 통과한다.

## Alternatives Considered

| Option | Trade-off | Why not chosen |
|---|---|---|
| 현재처럼 30NM 회랑을 `수평 교차`로 계속 표시 | 구현 변경이 가장 작음 | 실제 폴리곤 회피 여부를 숨겨 용어와 계산이 일치하지 않는다. |
| 30NM 회랑을 제거하고 실제 폴리곤 교차만 표시 | 화면은 단순해짐 | 브리핑에 필요한 주변 위험기상 정보를 잃는다. |
| 실제 교차와 30NM 인접을 별도 사실로 표시 | 화면과 응답 구조가 조금 늘어남 | 실제 회피와 브리핑 범위를 모두 명확하게 보여 준다. |
