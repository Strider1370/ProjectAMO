# 터미널 2안·3안 현재 날씨 패널 재구성 스펙

- 작성일: 2026-08-05
- 상태: 사용자 구현 승인
- 대상 경로: `/terminal/:departureIcao?view=weather`, `/terminal/:departureIcao?view=rail`
- 대상 사용자: 출발 전 공항 터미널의 대형 TV를 보는 여행객

## 1. 목적과 범위

2안과 3안의 상단 현재 날씨 영역을 같은 정보 구조와 시각 언어로 재구성한다. 여행객이 도착지의 **현재 수치 기상정보**를 빠르게 읽도록 하고, 이미 제공되는 시간별·주간 예보와 중복되는 예보 정보를 새로 추가하지 않는다.

이번 변경은 표시 계층과 레이아웃만 다룬다. 날씨 API, 데이터 정규화, 자동 전환 주기와 항공편 데이터는 변경하지 않는다.

## 2. 데이터 경계

상단 현재 날씨는 이미 화면 모델에 들어오는 아래 값만 사용한다.

| 값 | 용도 |
| --- | --- |
| `current.temp` | 현재 기온 |
| `current.feels` | 체감온도 |
| `current.humidity` | 습도 |
| `current.wind` | 풍향·풍속 |
| `current.icon` | 상태 텍스트·날씨 아이콘·배경 일러스트 종류 |
| `current.observedAt` | 관측 시각 |
| 출발 공항 기온과 `current.temp`의 차 | `김포보다 2°C 높아요` 문장 |

강수량, 자외선, 기압, 시정 등 현재 화면 모델에 없는 값을 추가하지 않는다. 시간별·주간 예보는 기존 하단 패널의 책임으로 유지한다.

## 3. 2안·3안 공통 상단

### 3.1 헤더

- 왼쪽에는 `목적지 날씨`, 오른쪽에는 날짜와 현재 시각만 둔다.
- 목적지 목록/탭/스테퍼 UI는 표시하지 않는다.
- 헤더 하단의 파란 진행선은 반드시 유지한다. 이는 현재 목적지 화면의 자동 전환 남은 시간을 보여 주며, 단순 구분선으로 대체하지 않는다.
- 헤더는 기존보다 낮게 만든다. Full HD 기준 시작값은 80px이며, 제목·시간·진행선의 판독성을 해치지 않는다.

### 3.2 현재 날씨 블록

- 도시·공항명, 현지 시각, `지금 · HH:MM 관측`, 현재 기온, 날씨 상태를 유지한다.
- 현재 기온과 전면 날씨 아이콘은 기존보다 축소한다. 배경 일러스트보다 주 정보가 커 보이되, 블록 전체를 압도하지 않아야 한다.
- 상태 텍스트 바로 아래에 출발 공항 대비 문장을 둔다. 예: `김포보다 2°C 높아요`. 기온차가 없거나 계산할 수 없으면 이 자리는 비운다.
- 상태에 따라 달라지는 저대비 날씨 일러스트를 패널 배경에 둔다. 일러스트는 장식이며 텍스트·수치보다 낮은 명도와 우선순위를 가진다. 사진·강한 그라데이션·카드 효과는 사용하지 않는다.
- 체감온도·습도·바람은 패널 하단의 동일 폭 3열 레일로 표시한다. 각 열은 `윤곽 아이콘 → 짧은 라벨 → 큰 수치` 순서이며, 열 사이에는 얇은 세로 구분선을 둔다.
- 흰색 둥근 카드, 과도한 테두리, 알약 형태의 기온차 배지는 제거한다.
- 아이콘은 보조 수단이다. 각 지표의 한국어 라벨과 값은 항상 함께 표시한다.

### 3.3 공유 구현 경계

- `CurrentWeatherBlock`은 2안과 3안 이외의 화면에서도 사용되므로, 기본 변형의 구조를 전역 변경하지 않는다.
- `variant="weekly"`와 2안의 현재 날씨 변형에만 공통 패널 구조/클래스를 적용하거나, 두 화면이 함께 쓰는 전용 변형을 명시적으로 만든다.
- 화면 전환 진행선(`tw-frame-progress`)의 동작 및 `frameSeconds` 입력은 보존한다.

## 4. 3안 전용 레이아웃

### 4.1 세로 비율

- 헤더 아래 콘텐츠는 상단 40%, 하단 60%를 기준으로 한다.
- 1920×1080 기준 시작값은 헤더 80px, 상단 400px, 하단 600px이다.
- 상단/하단의 좌우 열 경계는 계속 같은 x축에 맞춘다.

### 4.2 항공편 패널

- `출발공항 → 목적지공항` 요약 제목을 제거한다.
- 항공편 표의 헤더와 행이 상단부터 패널 전체 높이를 사용한다.
- 표 외 데이터나 신규 운항정보를 추가하지 않는다.

### 4.3 하단 예보 패널

- 시간별과 주간 패널의 제목 및 콘텐츠에 더 넉넉한 안쪽 여백을 준다.
- 시간별·주간 데이터, 행 수, 예보 표현 규칙은 바꾸지 않는다.
- 더 넓어진 하단 영역은 글자만 키우기보다 제목·표·그래프가 가장자리에서 숨 쉴 수 있도록 사용한다.

## 5. 검증 기준

- 2안과 3안 모두 헤더에 날짜·시각과 실제 자동 전환 진행선을 표시한다.
- 2안과 3안 모두 현재 기온, 체감, 습도, 바람, 관측 시각, 날씨 상태와 가능한 경우 기온차 문장을 표시한다.
- 3안에는 목적지 페이저와 항공편 노선 요약 제목이 없다.
- 3안에서 하단 예보 영역은 상단보다 높고, 두 열의 세로 경계는 일치한다.
- 수치 레일은 아이콘만으로 의미를 전달하지 않고 각 라벨과 값을 함께 표시한다.
- 기존 데이터가 없는 경우에도 레이아웃은 흔들리지 않으며, 해당 값은 기존의 `-` 표시 규칙을 따른다.
- Playwright 계약 테스트는 제거한 목적지 페이저·노선 제목 기대값을 새 헤더·지표 레일·3안 비율 기대값으로 교체한다.
