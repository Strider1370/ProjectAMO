# Terminal 기상이 상시 이동 디자인

## 목표

`/terminal`의 두 전광판 뷰에서 좌상단 기상이를 64px로 표시하고, 평소에도 짧은 범위에서 천천히 왕복하도록 한다. 첫 버전은 현재의 정적 투명 PNG를 재사용해 움직임의 인상과 전광판 가독성을 확인하는 데만 집중한다.

## 범위

- 기존 `/gisang-i/clear_3_avatar.png`를 그대로 사용한다.
- 기상이의 표시 크기를 64×64px로 변경한다.
- 기상이는 각 전광판 헤더의 좌상단 안전 영역 안에서 부드럽게 좌우로 이동하고, 작은 상하 움직임을 더한다.
- 마스코트는 장식 요소이며, 버튼과 데이터 위에 올라가거나 포인터 이벤트를 가로채지 않는다.
- 사용자가 `prefers-reduced-motion: reduce`를 설정한 경우 이동 애니메이션을 실행하지 않는다.

## 제외

- PixelLab API 연동, 런타임 이미지 생성, 새 의존성 추가
- 실제 보행 프레임·표정 변화·날씨 또는 항공편 상태 연동
- 헤더·전광판의 정보 구조 변경

## 구현 방향

`DestinationWeatherPage.jsx`의 공용 `AgencyMascot` 마크업과 `terminal.css`만 수정한다. CSS 키프레임이 이동과 가벼운 상하 바운스를 담당하며, 두 전광판 뷰가 같은 컴포넌트를 쓰므로 동작도 동일하다. 이동 범위는 좌상단 헤더에서 제목과 겹치지 않는 폭으로 제한한다.

## 검증

- 기존 보드 레이아웃 소스 계약에서 마스코트 경로와 64px 크기를 검증한다.
- 브라우저에서 `/terminal`의 보드·레일 뷰를 확인해 마스코트가 클릭을 가로채지 않고, 제목·데이터·제어부를 가리지 않는지 확인한다.
- reduced-motion 환경에서 정지 상태인지 확인한다.
