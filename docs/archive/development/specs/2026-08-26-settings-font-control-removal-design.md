# 설정 글꼴 제어 제거 설계

## 목표

설정 모달의 임시 글꼴 선택 UI와 계정 설정 이동 안내문을 제거한다.

## 범위

- `SettingsModal`에서 글꼴 상태·선택 항목·글꼴 적용 호출을 제거한다.
- 시간대, 언어, 초기화·적용·저장 동작은 변경하지 않는다.
- 모달 본문에는 시간대와 언어만 남긴다.

## 비범위

- 앱 시작 시 적용되는 현재 글꼴 설정과 `fontPrefs` 모듈의 동작은 변경하지 않는다.
- 프로필 또는 내 계정 화면은 변경하지 않는다.

## 검증

- 설정 모달 브라우저 계약에서 글꼴 레이블과 안내문이 보이지 않으며 시간대·언어 제어와 저장 버튼이 유지되는지 확인한다.
