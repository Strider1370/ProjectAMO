구름층과 착빙층을 동시에 표시

회색은 구름층 추정, 밝은 파랑·중간 파랑·어두운 남색 면은 착빙 등급입니다. 점무늬는 전 등급 동일하며 윤곽선은 최외각에만 표시합니다. 실선 0°C와 파선 −20°C가 온도 구조를 보여줍니다.

등급은 색 면, 점은 착빙 보조 표식

LIGHT / MODERATE / SEVERE는 명도 차이가 큰 색 면으로 구분합니다. 흰 점의 간격·크기는 모든 등급에서 같고, 윤곽선은 착빙 전체의 최외각에만 둡니다. 착빙 면이 덮은 곳의 구름 세부 명암은 가려집니다.

0°C / −20°C는 온도 참고선

−10°C를 추가하면 온도 변화를 더 자세히 볼 수 있습니다. 등온선을 착빙 발생 범위나 안전 경계로 사용하지 않습니다.

표현 비교용 합성 데이터입니다. 실제 KIM 예보·착빙 산출값이 아니며, 지도 고도와 단면 고도는 예시용 MSL입니다.
