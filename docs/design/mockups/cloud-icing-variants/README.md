# 실제 KIM 자료의 A안과 기존 표현 비교

`../cloud-icing-variants.html`을 브라우저로 직접 연다. 파일 하나에 화면 코드·지도 경계·보관 KIM 자료가 들어 있으며 서버나 외부 네트워크가 필요 없다. 실제 서비스의 표시 설정은 변경하지 않는다.

구름의 색·농도와 착빙의 영역·등급은 안 사이에서 동일하다. 착빙 전체의 최외곽만 윤곽선으로 표시하고 내부 구멍·등급 경계에는 선을 그리지 않는다.

| 안 | 착빙 표현 |
| --- | --- |
| A | 선택한 안. 밝은 파랑/중간 파랑/어두운 남색의 불투명 색 면 + 동일한 흰 점 |
| B | 밑색 없는 파랑 점 + 흰 테두리 |
| C | 사선 간격·굵기, SEV는 교차 해칭 |
| D | 투명 파랑 면 + L / M / S 표식 |
| E | 파랑 면 + 흰 점 |
| F | 전체 최외곽 + 대표 등급 표식, 내부 채움 없음 |

처음에는 **보관 KIM 실자료의 500 hPa, 첫 예보시간, A안**을 크게 보여준다. 저장된 205×169 격자의 600/500/450 hPa와 두 예보시간, RKSI→RKPC 단면을 확인한다. 발표·유효 시각과 등급별 격자 수는 선택할 때 화면에 표시한다. 현재 예보라는 의미는 아니다. 단면은 시안 비교를 위한 0–30,000 ft 범위이고, 기존 앱의 연직 축은 수정하지 않는다. 자료 선택을 합성으로 바꾸면 세 등급·빈 영역·내부 구멍을 함께 보는 가상 시험장이며 실제 예보와 구분한다.

지도/단면/둘 다, 배경, 각 레이어를 공통 전환한다. A의 흰 점은 모든 등급에서 9px 간격·0.85px 반지름이며 등급색은 기존 착빙 램프를 사용한다. 구름과 데이터·영역 계산은 유지한다. ‘기존 6안 비교’를 누르면 다른 안과 두 개씩 비교하거나 확대할 수 있고, ‘A안만 보기’로 돌아온다. 각 안의 범례는 해당 질감을 사용한다. F의 표식은 대표 등급만 알려주며 내부의 세부 등급 범위를 나타내지 않는다.

제작 코드와 검증:

```bash
node scripts/preview-cloud-icing-variants.mjs
node scripts/verify-cloud-icing-variants.mjs
```

첫 명령은 backend 저장 자료를 읽고, 기존 착빙 기하·등온선·단면 셀 계산을 재사용해 HTML을 만든다. `preview.js`와 `preview.css`는 비교 시안 전용이다. 기존 구름·착빙 산출식, 수집기, 프로젝트 화면은 변경하지 않는다. 생성된 HTML을 수정하려면 원본 JS/CSS를 수정한 다음 다시 생성한다.

두 번째 명령은 실제 자료와 A안이 기본으로 열리는지, A의 불투명 등급색·공통 점무늬, 같은 구름/착빙 영역 유지, 원자료 불변, 자료·시간·층 전환, 지도/단면과 레이어 전환, 두 안 선택, 확대·Escape, 모바일 넘침을 확인한다. `artifacts/cloud-icing-a-real-kim*`와 `artifacts/cloud-icing-variants-*`에 PNG·결과를 남긴다. HTTP를 모두 차단하며 요청이 없었는지도 확인한다.
