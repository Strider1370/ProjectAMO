# 기관 라운지 HTML 디자인 시안

[시안 열기](2026-09-09-organization-lounge.html) · [설계안](../proposals/2026-09-09-organization-lounge-and-joint-briefing-plan.md)

브라우저에서 HTML 파일을 직접 열면 됩니다. 프로젝트 상대 경로의 디자인 토큰과 로컬 Pretendard 글꼴을 사용하므로 저장소 안에서 열어 주세요. 글꼴 패키지가 없으면 시스템 글꼴로 표시됩니다. 앱 서버나 기상 API는 필요하지 않습니다.

## 확인할 흐름

1. 홈의 오늘 예정비행에서 기상 브리핑을 열고, 기관 자료를 확인합니다.
2. 예정비행 상세에서 주의사항을 수정합니다.
3. 합동 브리핑 준비에서 발표 순서와 주의사항을 바꿉니다.
4. 발표 화면에서 이전·다음 비행으로 이동하고 지도·단면도·첨부자료를 확대합니다.
5. 공유자료에서 검색·종류 필터와 문서 예시의 페이지 이동·확대를 확인합니다.
6. 기관 알림에서 확인·나중에 보기 상태를 바꿉니다.
7. 기관 설정에서 합동 브리핑 메뉴를 켜고 끕니다.
8. 홈의 위험기상 항목에 마우스를 올려 지도 강조를 확인하고, 클릭해서 선택을 고정합니다. iPad에서는 터치로 고정합니다.
9. 발표 화면에서 위험기상 또는 ‘구례 산악 구간 확인’ 카드를 선택해 지도·단면도 연결을 확인합니다. 지도 위 사용자 원이나 단면도 아래 연결 표시에서도 같은 항목을 선택할 수 있습니다.
10. 예정비행 상세의 `지도 주의사항 추가` 또는 합동 브리핑 준비의 `지도에 표시하는 주의사항 → 추가`에서 도형과 글을 작성합니다.
11. 홈 상단 `기관 소식`에서 공지와 최근 자료 서랍을 엽니다. PDF·이미지를 열었다 닫으면 서랍으로 돌아오고, 서랍을 닫으면 홈으로 돌아옵니다. 자료함·브리핑 준비로 이동하는 링크도 제공합니다.

## 지도 주의사항과 연동 강조

- 호버·키보드 초점은 임시 강조이고, 클릭·터치는 선택 고정입니다. 다른 항목을 가리켰다가 벗어나면 기존 고정 선택으로 돌아옵니다. 같은 항목 재선택·`선택 해제`·Esc로 해제할 수 있습니다.
- 지도 위치는 호버로 움직이지 않습니다. 클릭한 대상이 화면 밖에 있을 때만 표시 범위를 조정합니다. A·B 배치 전환은 선택을 유지하고 비행 전환은 선택을 해제합니다.
- 지점은 한 번, 원은 중심과 가장자리를 두 번 찍습니다. 선·구역은 꼭짓점을 찍고 `도형 완료`를 누릅니다. `한 점 취소`와 `다시 그리기`를 지원합니다. 지도에 초점을 둔 뒤 방향키·Enter로도 그릴 수 있습니다.
- 제목·설명·선택적 고도 범위(ft AMSL)를 저장하고, 다시 편집하거나 삭제할 수 있습니다. `글만`을 선택하면 도형 없이 저장합니다.
- 고도가 없으면 단면도에 점선으로 위치 구간만 표시합니다. 경로 밖의 도형은 지도만 강조하고, 여러 번 통과한 영역은 여러 거리 구간에 표시합니다.
- B 배치에서 긴 조종사 주의사항은 해당 칸 안에서 스크롤합니다. 위험기상과 참고자료는 같은 오른쪽 영역에 유지합니다.
- 지도 연결 주의사항과 도형도 현재 탭에서만 유지됩니다. 실제 기관 저장·권한·이력 관리는 구현하지 않았습니다.
- **시안의 도형은 SVG 그림 좌표이며 단면도 연결은 샘플링 근사값입니다.** 지점·선의 일치 여부에는 그림상의 작은 허용 오차를 사용합니다. 운영 기능에서는 설계안대로 지리 좌표와 실제 브리핑 거리축의 교차 판정으로 대체해야 합니다.

## 합동 브리핑 배치 비교

발표 화면의 `A 기존 배치` / `B 지도 중심`으로 같은 비행을 전환해 비교합니다. 선택한 비행과 작성 내용은 유지됩니다.

- **A 기존 배치:** 왼쪽 위 지도·아래 단면도, 오른쪽 위험기상·주의사항·참고자료.
- **B 지도 중심:** 왼쪽 약 60%를 지도에 전체 높이로 배정하고, 오른쪽 위에 단면도·아래에 위험기상·주의사항·참고자료를 배치합니다. 좁아진 단면도는 축과 글자를 별도로 배치하며 확대 버튼으로 크게 볼 수 있습니다.
- B의 지도는 비행경로를 중심에 놓고 주변 권역이 함께 보이도록 표시합니다. 긴 주의사항은 오른쪽 자료 영역 안에서 스크롤합니다.
- 현재 비교 대상은 데스크톱과 iPad 가로입니다. 모바일 구성은 후속 검토로 미룹니다.

## 캡처를 기준으로 조정한 공간 배분

- 공통 상단은 기관명·메뉴·사용자 정보를 합쳐 56px 한 줄로 배치합니다. 홈의 ‘오늘의 기관 상황’ 제목 줄은 없애고 ‘합동 브리핑 준비’ 버튼은 기관 소식 오른쪽으로 옮겼습니다. 날짜는 공통 상단에 유지합니다. 패널 제목은 기본 44px 높이이며, 넓은 데스크톱에서는 본문 최대 폭을 1760px까지 사용합니다.
- 홈은 기관 소식 줄 → 공항 기상 가로 요약 → 지도와 알림·예정비행 순서입니다. 지도는 오른쪽 두 패널의 전체 높이를 채우고 하단을 맞춥니다. 넓은 화면에서는 남은 높이도 활용하며, iPad에서는 내용에 따라 페이지를 스크롤합니다.
- 홈의 예정비행은 시간·비행 정보·기상 브리핑 버튼을 같은 행에 둡니다. 최근 자료는 기관 소식 서랍에 표시하고, 공유자료 페이지의 갤러리는 유지합니다. 서랍은 키보드 초점을 유지하며 Esc·닫기·바깥 클릭으로 닫습니다.
- 발표는 상하 여백과 줄 간격을 줄이고, 지도 제목을 지도 안 도구 모음에 배치합니다. 출처·시각은 하단에 유지하고, `새 자료 도착 예시`는 상단 시계 아이콘으로 옮깁니다.
- 지도 선택 요약은 내용 너비만 사용합니다. 긴 제목은 줄바꿈하며, 선택 해제 버튼과 고도 미지정 안내를 유지합니다.
- 준비 화면은 반복되는 자동 연결 설명·제목·테두리를 정리하고, 참고자료를 두 열에 배치합니다. 입력창은 사용자가 늘릴 수 있습니다.
- 주요 터치 조작은 44px 이상을 유지합니다. 긴 내용은 스크롤로 접근하며 공간 확보를 위해 잘라내지 않습니다.

Chromium의 1180×820 iPad 가로 캡처, 초기 예시 데이터 기준입니다. 아래 수치는 운영 화면의 고정 규격이 아닙니다. 홈 수치는 9월 10일 기관 소식 서랍 배치까지 반영했습니다.

최신 홈 캡처는 같은 폴더의 `density-compact-header-{desktop,ipad,ipad-small}-home.png`입니다. 서랍에서 PDF 페이지 이동·이미지 열기·닫기 후 초점 복귀와 페이지 이동도 Chromium·WebKit에서 확인했습니다. 상단 통합으로 지도 시작 위치는 이전 홈 배치보다 108px 위로 이동했습니다.

## 시안의 범위

- 9개 페이지와 기존 브리핑 연결 예시, 공통 등록·편집·뷰어 대화상자를 제공합니다.
- 비행 등록·편집, 주의사항 수정, 발표 순서, 알림 상태는 현재 탭의 메모리에서만 유지됩니다. 새로고침하면 초기화됩니다.
- 업로드·자료 연결·권역 그리기·날짜 선택·지난 회차·새 기상자료 적용은 화면과 진입 동작을 보여주는 예시입니다. 실제 서버 저장이나 기상 분석을 수행하지 않습니다.
- PDF 뷰어는 두 쪽의 HTML 예시 문서입니다. 실제 PDF 렌더러를 연결한 것은 아닙니다.
- 지도 지형 경계는 프로젝트의 `frontend/public/Geo/sido.json`에서 추출·단순화한 SVG입니다. 지도 기상, 비행경로, 현장도, 연직단면도, 공항 기상, 인물과 기관은 디자인 검토용 예시이며 운항용 자료가 아닙니다.
- 데스크톱·iPad 가로에서 A·B 통합 배치를 비교합니다. 이전 시안의 모바일 스타일 일부는 남아 있지만 현재 설계·검증 대상에 포함하지 않습니다.
- 외부 네트워크·새 패키지 설치 없이 열 수 있습니다. 실제 앱 코드는 변경하지 않습니다.
