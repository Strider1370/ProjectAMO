공통 규칙

  • 화면은 스스로 움직이지 않는다: 시간·고도·공항 카드 과거 보기는 모두 사용자가 조작할 때만 바뀐다. 막대 선택은 팝오버만 열고, 이동은 버튼으로.
  • "없음"과 "확인 불가"를 구분: 계산했는데 없으면 "없음/MOD 이상 없음", 자료가 없으면 회색 빗금 "확인 불가".
  • 색과 글자를 함께: SEV 빨강·MOD 노랑에 항상 글자 칩. 다른 고도는 빗금 점선으로 모양까지 다르게.
  • 위치는 지점 이름 먼저, NM은 보조.
  • 시각은 KST 기본, 팝오버·카드의 자료 시각은 UTC 병기 가능(설정의 표시 시간대 따름). 표기 형식: 10/20 09:45 KST.
  • 통과 시각 계산 = ETD + 경로 거리(SID·STAR 포함) ÷ TAS. 바람 미반영임을 팝오버에 작게 표시. 선행: 총 거리 수정(F3).
  • 최소 지원 폭 1280: 1280~1919에서는 패널 폭 264, 공항 카드 240, 막대 라벨 열 112로 줄임. 1279 이하(휴대폰·세로 태블릿)는 문서형 보기.
