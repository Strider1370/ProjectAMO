# 내 지도 HTML 시안 사용법

작성: 2026-09-19  
[HTML 열기](2026-09-19-flight-map.html) · [UI/UX 명세](../proposals/2026-09-19-flight-map-ux-design.md) · [구현 계획](../proposals/2026-09-19-flight-map-implementation-plan.md)

이 시안은 **개인 지도 작성 → 저장 → 기관 공유**의 화면과 조작을 검토하는 독립 HTML이다. 실제 앱의 Mapbox·계정·기관 서버와 연결되어 있지 않다. 구현 요구사항은 UI/UX 명세, 작업 순서와 코드 재사용은 구현 계획을 기준으로 한다.

## 열기

HTML 파일을 브라우저에서 직접 연다. 개발 서버·Mapbox 토큰이 필요 없다. 기본 화면은 ‘서해안 비행 참고도’의 **보기 패널**이다.

- 지도 목록부터: 파일 주소 끝에 #library를 붙여 다시 연다.
- 보기부터: #view 또는 fragment 없이 연다.
- 편집부터: #edit를 붙여 다시 연다.

fragment는 최초 진입 화면 지정용이다. 화면을 바꿀 때 주소를 갱신하는 제품 라우터가 아니다. 시안의 ‘사용법’에서 예시 자료를 초기화할 수 있다.

**사용법 → 속성 표시 예시**에서 가변 메타데이터 상세를 확인한다. 확인된 공역 형식(CHEONGJU 실제 속성), 알 수 없는 속성 50개, 글 설명만 있는 경우, 일부 해석 실패를 선택할 수 있다. 실제 제품에서는 항목 선택 시 하단 상세에 나오는 내용이며, 시안의 예시 창은 형식 비교를 위한 검토 도구다. 공역 예시 외 자료는 합성 예시다.

CSS·스크립트·예시 지도는 HTML에 포함되어 있다. 프로젝트 내부에서는 설치된 Pretendard GOV 글꼴을 상대 경로로 읽고, 파일을 따로 옮기면 시스템 글꼴로 대체한다. 외부 지도 API를 호출하지 않는다. 브라우저의 로컬 파일 저장 정책에 따라 저장 유지 여부가 달라질 수 있다.

## 권장 확인 순서

| 순서 | 조작 | 확인할 설계 |
|---|---|---|
| 1 | 기본 화면의 목록 또는 지도 지점 클릭 | V2/V3: 기본은 읽기, 선택한 항목의 상세는 아래에 표시 |
| 2 | ‘이 항목 수정’ 또는 ‘수정’ | E1/E2: 같은 왼쪽 자리가 편집 패널로 전환 |
| 3 | 항목 목록으로 돌아가 점 도구 선택, 여러 위치 클릭 | 연속 추가 중 목록 유지, 반복 속성창 없이 여러 점 작성 |
| 4 | 선·면·원 도구를 차례로 선택하고 안내대로 완료 | 네 도구의 작성·완료·속성 진입 흐름 |
| 5 | 항목 이름·색·채움 변경, 위치·형태 수정 | 속성 즉시 반영과 형태 수정의 완료/취소 구분 |
| 6 | 그룹 생성, 항목 여러 개 선택해 다른 그룹으로 드래그 | 혼합 그룹, 이동·정렬·한 번 되돌리기 |
| 7 | 도형을 미완성으로 두고 편집에서 나가기 | ‘계속 그리기 / 그냥 나가기’ 두 선택지 |
| 8 | 편집을 마치고 공유 | D1: 기관을 골라 현재 지도의 독립 사본 생성 |
| 9 | 원본 수정 후 공유본 확인·업데이트 | 개인 저장과 공유본 업데이트가 별도 동작 |
| 10 | 지도 목록에서 새 지도·복제, 메뉴에서 내보내기 | 지도 단위 관리와 예시 KML 다운로드 |
| 11 | 브라우저 폭 축소 | 패널과 지도 전환, 작은 화면의 정보 우선순위 |

## 동작 범위와 제품 차이

| 기능 | 시안 상태 | 실제 구현 참고 |
|---|---|---|
| 보기/편집/속성 전환, 선택 | 작동 | 실제 내 지도 진입점과 MapView 연결 |
| 점·선·면·원, 연속 지점 | 작동 | 실제 좌표·거리 계산과 유효성 검사 필요 |
| 형태 이동·꼭짓점 이동·반경 수정 | 작동 | 꼭짓점 추가/삭제와 좌표 입력은 보완 필요 |
| 그룹·다중 선택·드래그·undo | 작동 | 긴 목록·접근성 대체·실제 지도 이벤트 통합 필요 |
| 색·굵기·채움·이름 표시 | 일부 작동 | 점 크기·점선·이름 크기/항상 표시·상속 보완 필요 |
| 저장·재열기 | 시안 전용 localStorage | 계정 저장·동시 수정·복구·실패 처리는 미구현 |
| 기관 공유·업데이트 | 같은 브라우저의 사본 | 멤버십·권한·서버 불변 버전·다른 사용자 수신은 미구현 |
| KML 내보내기 | 예시 다운로드 | 전체/그룹/항목 범위, 스타일·고도·원 정의 왕복은 미구현 |
| KML/KMZ 가져오기 | 안내만 표시 | 실제 파서 연결·원본 보존·변환 미리보기 필요 |
| 가변 메타데이터 상세 | 사용법에서 네 가지 표시 예시 작동 | 실제 파일 추출·형식 판별·원본 보존과 연결 필요. 임의 KML 파싱 구현을 의미하지 않음 |
| 여러 줄 좌표 입력 | 미구현 | 설계의 보조 입력 흐름으로 구현 필요 |
| 미완성 초안 복구 | 미구현 | 완료 항목과 분리된 복구 저장 필요 |
| 좁은 화면 | 목록/지도 전환 작동 | 실제 iPad Safari 및 제품 지원 범위 검증 필요 |

SVG 배경은 프로젝트 시도 경계 자료를 단순화해 사용했고, 도로·공역·지점은 화면 검토용 합성 예시다. 시안의 거리 환산·KML 좌표를 실제 항공 자료나 기하 계산의 기준으로 사용하지 않는다. 상세 누락과 완료 기준은 UI/UX 명세의 11~12절을 따른다.

시안 자료 키는 projectamo.flight-map-design.20260919.v1이다. 기존 /draw의 projectamo.draw-spike.v1과 다르다. 초기화는 시안 자료를 대상으로 한다. 시안 저장소나 가상의 기관 사본을 실제 사용자 자료 저장 방식으로 이식하지 않는다.

## 확인 기록

2026-09-19, 로컬 Chromium/Playwright로 다음을 확인했다.

- 기본 확인 20항목: 패널 분리·선택·이름 변경·연속 점·선/면/원·단일/다중 드래그·두 선택지 이탈·로컬 공유 사본·KML 다운로드·새로고침 저장·화면 폭별 넘침·스크립트 오류.
- 후속 확인 9항목: 꼭짓점 수정·취소 복구·한 번 undo·그룹/항목 순서·새 지도·복제 시 그룹 없음 중복 방지·HTML 직접 열기·스크립트 오류.
- 두 기록 모두 오류 0건. 기본 확인 후 수정 사항은 후속 확인으로 보완했으며, 모든 제품 환경을 검증한 결과는 아니다.
- 가변 상세 추가 확인 12항목 통과, 오류 0건: 알려진 요약/전체 속성, 미지 필드 50개, 0/false/빈 값, 중복 이름, 글 설명, 부분 실패, HTML 비실행, 속성 없음, 모바일 넘침, 스크립트 오류. 기록은 verification-metadata.json, 캡처는 metadata-desktop.png와 metadata-phone.png다.
- 캡처 크기: 데스크톱 1440×1000, 노트북 1280×800, 태블릿 1024×768, 휴대전화 390×844. iPad Safari 실기기 검증은 하지 않았다.

로컬 검증 결과와 캡처는 ignored 디렉터리 artifacts/flight-map-design/에 있다. verification.json, verification-extra.json과 view-desktop.png, edit-desktop.png 등을 참고할 수 있다. 이 디렉터리는 커밋 대상이 아니므로 다른 체크아웃에 자동 포함되지 않는다. 전달 가능한 기준 자료는 이 README·HTML·두 설계 문서다.
