점수 기준과 가중치

기본 기준과 동일 가중치는 시제품을 위한 설정입니다. 관측에 맞춰 보정된 값이 아닙니다.

선택 지점

변수입력값0~1 점수가중 기여

계산식과 자료 정보

점수 변환
CAPE: (CAPE − 하한) / (상한 − 하한)
강수: (mm/h − 하한) / (상한 − 하한)
OLR: (상한 − OLR) / (상한 − 하한)
각 점수는 0~1 범위로 제한합니다.

결합
지수 = (wC·MC + wR·MR + wO·MO) / (wC + wR + wO). 하나라도 결측이면 계산하지 않습니다.

CAPE는 MetPy의 지표 기반 계산을 사용합니다. 지상기압·2m 기온·비습과 등압면 기온·비습을 사용하고, 지면 아래 등압면은 제외합니다. 연직 자료는 150hPa까지이므로 평형고도가 더 높으면 값이 달라질 수 있습니다.

강수강도는 KIM pr × 3600으로 환산한 mm/h 값입니다. 3시간 누적강수량이 아닙니다. 세 입력 모두 같은 실행·예보시각입니다.

이 점수는 발생 확률이나 운정고도가 아닙니다. 보고서의 기존 고도 변환표를 적용하지 않았습니다. 기존 프로젝트의 ACIM·착빙 계산에는 연결하지 않은 별도 예시입니다.
