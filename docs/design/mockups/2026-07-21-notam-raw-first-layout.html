위계 규칙 · 기본 화면

공항 패널은 선택 공항의 직접 영향만 대상으로 하며, 발효 중이고 운항 영향을 확실히 확인한 항목만 붉은 선으로 강조합니다. 참고 공지와 해석 보류는 기본 화면에서 숨기고, “기타 직접 해당 N건 보기”를 눌렀을 때 각각의 묶음으로 펼칩니다. 사이드 패널은 선택 공항 직접 영향을 먼저 보여 주고, 그 밖의 공항·공역 항목은 전체 목록에서 위치와 발효 시각으로 찾습니다. 모든 단계에서 E) 원문이 기준이며, 파싱 불확실성은 "검토 필요/시간 확인"으로 남깁니다.
