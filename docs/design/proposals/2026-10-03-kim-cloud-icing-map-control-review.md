# 구름·착빙 지도 조작 — 실제 ProjectAMO UI 기준

작성: 2026-10-03. 상태: **사용자 방향 승인 완료**, 제품 적용 전. 구현 정본은 [A안 프로젝트 적용 계획](2026-10-03-kim-cloud-icing-a-production-plan.md).

사용자가 기상 패널 아래 체크박스 설정 상자와 실제 앱 구조를 반영하지 않은 일반 지도 시안을 거부했다. 기존 세 안은 최종 배치 후보에서 제외한다. 착빙 A 표현은 유지하고, 실제 프로젝트 UI 안에서 조작만 단순화한다.

## 확인한 화면과 코드

현재 `App`·`MapView`를 저장 자료로 직접 렌더링했다. 기존 실제 지도·기관 지도 캡처도 확인했다. 좌측 사이드바와 지도 상단 `항공정보 / 기상정보 / 연직단면도`, 기상 패널의 여섯 수치모델 타일, 우측 기압층 레일, 하단 시간 슬라이더·범례, 모바일 sheet·작업 바가 기준이다.

스타일은 기존 `MapView.css`의 `map-legend-toggle`, `App.css`의 활성 버튼 회청색, 공통 간격·44px 터치 크기와 현재 앱의 Wanted Sans를 사용한다. 지도 중앙에 별도의 조작 카드나 설명 상자를 추가하지 않는다.

## 승인된 배치

기상 패널은 현재의 `구름·착빙` 타일 하나로 진입하고, 자식 체크박스 상자를 없앤다. 지도 좌측 하단의 기존 `범례` 옆에 다음 한 줄을 붙인다.

```text
[범례 ▴]  [구름]  [착빙]
```

| 조작 | 동작 |
| --- | --- |
| 구름 | 한 번 눌러 회색 구름 표시 켬/끔 |
| 착빙 | 한 번 눌러 등급 색 면·흰 점·최외곽을 함께 켬/끔 |
| 등온선 | 조작 버튼 없이 0°C 실선·−20°C 파선과 라벨을 동일한 빨간색 `#c0291f`로 표시. −10°C는 제외 |
| 범례 | 기존 범례 열기/닫기와 동일. 새 설정창으로 바꾸지 않음 |

켜진 현상은 기존 상단 지도 버튼과 같은 회청색 활성 상태로 표시한다. 범례와는 8px 간격을 두며 큰 둘러싸기 상자는 없다. 등온선 버튼·메뉴는 제거한다. 구름·착빙 보기에서 0°C와 −20°C만 항상 표시하며, 실제 자료에 해당 온도 경계가 있을 때 그린다.

데스크톱·iPad에서는 기존 범례 높이에 맞춘다. 모바일에서는 시간 슬라이더 재생 버튼의 실제 44px 터치 영역과 충돌해 이 한 줄을 그 위로 올렸다. 재생 버튼, 시간 테이프, 하단 작업 바는 기존 위치를 유지한다. 지도 중앙 시각 카드 아래 배치는 폐기한다. 실제 제품의 모바일 자료 시각은 펼친 범례 안에 있으므로 가상의 상단 시각 카드를 새로 만들지 않는다.

부모 보기 OFF이면 조작과 현상을 숨기고 다시 ON이면 선택을 복원한다. 구름·착빙 모두 OFF여도 등온선과 두 조작을 유지해 다시 켤 수 있게 한다. 바람·난류·운정으로 바꾸면 해당 조작은 숨긴다. 고도·발표/유효시각 선택은 기존 레일과 시간 슬라이더가 계속 소유한다.

저장 KIM `tmfc=2026091006`, F+6/F+9 자료이며 최신 예보가 아니다. 첫 화면은 0°C 등온선을 확인할 수 있는 600 hPa이며 450 hPa에는 −20°C 경계가 나타난다. 온라인 배경 호출을 피하려고 로컬 경계 지도를 사용했다. **현재/제안은 조작 배치 비교**이고 두 화면 모두 같은 A 착빙 표현이다. 제품 파일은 변경하지 않고 독립 번들에서만 배치와 표현을 바꿨다.

실제 하단 범례의 A 표식/라벨 갱신, 기관 지도·단면·브리핑 및 모든 자료 상태 연결은 [제품 적용 계획](2026-10-03-kim-cloud-icing-a-production-plan.md)에 남아 있다. 일반 지도 시안을 만들었다고 해당 기능 구현을 완료로 처리하지 않는다.

## 이전 레퍼런스와 시안의 처리

[Mapbox 레이어 전환 예제](https://docs.mapbox.com/mapbox-gl-js/example/toggle-layers/)와 [Google 지도 사용자 조작 예제](https://developers.google.com/maps/documentation/javascript/examples/control-custom)에서 짧은 버튼으로 레이어를 직접 조작하는 원리는 참고했다. 위치와 스타일은 실제 ProjectAMO UI를 우선한다.

[이전 세 안 HTML](../mockups/cloud-icing-map-controls.html)은 검토 기록으로만 보존한다. 그 안의 시각 카드·고도 레일은 제품 컴포넌트가 아니며, 제품 UI와 연결했다고 볼 수 없으므로 적용 기준으로 사용하지 않는다.
