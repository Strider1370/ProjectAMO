# AI 대화 배치 검토용 실제 앱 캡처

## 현재 시안: 오른쪽 아래 플로팅 대화창

[수정 시안](../../2026-09-22-ai-copilot-actual-preview.html)은 현재 `airport-original.png`, `briefing-original.png` 및 해당 tablet 원본만 사용한다. 지도·자료의 위치와 크기는 바꾸지 않고, 그 위에 기본 400×560px 대화창과 오른쪽 아래 실행 버튼을 표시한다. 헤더 드래그/방향키 이동, 확대/축소, 위치 복원, 접기/재열기를 지원한다. 대화 내용·초안·스크롤은 페이지가 열린 동안 보존하며, 실제 LLM 호출이나 앱 소스 변경은 없다.

하단/측면 분할용 캡처는 이전 배치 검토의 기록으로 보존하지만 현재 시안에서는 사용하지 않는다. 아래 CSS 리사이즈 설명은 이 이전 분할형 산출물에만 해당한다.

## 원본 및 이전 분할형 캡처 기록

- 캡처일: 2026-09-22, Linux Chromium, device scale factor 1.
- 대상: 실행 중인 로컬 ProjectAMO `http://127.0.0.1:5173`, backend `3001`.
- 서버 상태: `/api/health`의 `testMode: true`. METAR·TAF 등 자료가 비어 있는 상태를 그대로 캡처했다. 운영 관측자료나 운항 판단 자료가 아니다.
- 원본 화면: 김포 공항 상세, 실제 앱에서 자동 생성한 김포–제주 경로의 브리핑 준비 및 최종 브리핑. 기상 응답을 별도 fixture로 대체하지 않았다.
- `*-original.png`: 채팅 배치를 위해 CSS를 바꾸기 전의 화면. 지도/자료 내용이나 원본 UI를 편집하지 않았다.
- `*-desktop-bottom.png`, `*-desktop-side.png`, `*-tablet-bottom.png`: 캡처용 브라우저 안에서만 지도 컨테이너 크기와 브리핑 고정 위치를 CSS로 조정하고, 실제 Mapbox resize 이후 다시 찍은 화면. 빈 영역에 HTML 시안의 대화 UI가 놓인다. 앱 소스는 변경하지 않았다.
- 1600×1000: 공항 패널 x=800, width=800; 최종 브리핑 x=797.125, width=802.875. 왼쪽 메뉴는 56px.
- 1024×768: 공항 패널 x=464, width=560; 브리핑 x=520.64, width=503.36.
- 하단 대화 공간은 desktop 390px / tablet 330px, 측면 대화 공간은 desktop 340px. 태블릿 측면형은 지도 가용 폭 부족으로 제외했다.
- 지도 리사이즈만 적용했으며 경로 전체를 새 공간에 다시 맞추는 카메라 보정은 하지 않았다. 따라서 경로 일부가 시야에서 벗어나는 문제도 캡처에 드러난다. 실제 구현 시 화면 배치와 지도 카메라 정책을 함께 검증해야 한다.

[수정 시안](../../2026-09-22-ai-copilot-actual-preview.html)의 지도·자료는 정적 캡처이고 대화만 HTML 인터랙션이다. 캡처 속 기존 버튼은 작동하지 않는다. HTML과 이 폴더를 함께 유지해야 한다.

현재 로컬 재현 스크립트: `artifacts/ai-copilot-ui/capture-actual.mjs` (ignored 검증 산출물). 기존 서버를 재사용하고 수집 설정·자료 저장소를 바꾸지 않으며, 종료 시 자체 생성한 브라우저만 닫는다.
