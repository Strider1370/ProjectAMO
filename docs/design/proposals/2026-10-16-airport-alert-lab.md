# 공항 알림 실험실: 수신 화면

## 범위

`/concepts/alerts`에서 공항 조건을 설정하고 모의 알림을 확인한다. 실제 수집·Web Push 발송·백그라운드 감시는 연결하지 않는다. 설정과 이력은 메모리에만 존재한다.

`?preview=phone`과 `?preview=desktop`은 기기 테두리·축소 없이 같은 `AlertDeviceApp`을 렌더링한다. 휴대폰 단독 화면은 실제 브라우저 너비를 사용하고, 기기 프레임에서는 고정 CSS viewport를 통째로 축소한다. CSS px는 물리 화면 픽셀이나 인치가 아니다.

## 참고한 공식 레퍼런스

- [Apple HIG Notifications](https://developer.apple.com/design/human-interface-guidelines/notifications): 짧고 정보성 있는 제목, 빠르게 이해되는 본문. 모바일 배너의 앱 식별 → 제목 → 본문 순서에 적용.
- [Android Notifications](https://developer.android.com/design/ui/mobile/guides/home-screen/notifications): 출처·시각·핵심 내용의 위계와 관련 알림 묶기. 공항별 묶음과 보조 시각에 적용.
- [Fluent 2 Toast](https://fluent2.microsoft.design/components/web/react/core/toast/usage): 일관된 위치, 관련 내용으로 이동, 닫아도 알림센터에 남는 기록. PC 하단 팝업과 상세 연결에 적용.

이는 앱 내 알림 화면이다. OS 푸시와 잠금화면의 정확한 외형을 재현하거나 제어한다는 뜻은 아니다.

## 화면과 동작

- 비행경로 알람 버튼은 김포국제공항 → 제주국제공항 경로의 예시를 만든다. 도착 공항 시정 1,200m(기준 1,500m 미만)과 경로상 모의 SIGMET 구역의 심한 난류를 표시한다. PC 팝업·휴대폰 모의 푸시·벨 목록에서 경로 패널로 이동한다. 실제 경로 계산/SIGMET 영향 판정 및 경로 설정 관리는 포함하지 않는다.
- 공항경보 알람 버튼은 김포국제공항의 모의 강풍경보와 유효 시간 2시간을 표시한다. 낙뢰 알람 버튼은 김포국제공항 반경 10km에서 최근 30분 낙뢰 3건, 최근접 5.2km를 표시한다. 각각 PC 팝업·휴대폰 모의 푸시·벨 목록에서 별도 예시 상세로 이동한다. 실제 경보/낙뢰 자료나 위치 판정은 사용하지 않는다.

- 휴대폰은 잠금화면의 OS 푸시를 모사한다. 앱 아이콘·이름, 발생 시각, 공항명과 항목별 텍스트를 표시하고 클릭 시 웹앱 공항 패널로 이동한다. 웹앱 안에서는 휴대폰 팝업을 띄우지 않는다. 실제 푸시 발송은 아니며 OS별 외형은 다를 수 있음을 명시한다.

- 팝업 상단 한 줄에는 공항 알림과 알림 발생 시각(KST)을 표시한다. 아래는 공항명과 관측값·기준이며, 발생 시각은 METAR 관측 시각과 구분한다.

- 헤더의 벨 버튼은 진행 중인 알림이 있는 공항 수를 표시한다. 누르면 작은 알림창을 연다.
- 알림창에는 공항명과 해당 항목의 발생 당시 관측값·설정 기준을 표시한다. 예: 시정 1,200m · 기준 1,500m 미만. 표현은 흰 배경의 목록형으로 유지하고 관측값과 기준 대비 방향(↑·↓·=)만 색으로 강조한다. 기준은 작은 보조 텍스트로 표시하며 항목별 색상 박스는 두지 않는다. 최초 팝업과 벨 알림창 모두 해당 항목을 빠짐없이 표시하며, 묶음 팝업도 공항별 해당 값을 표시한다. 읽어도 조건이 해소되기 전까지 남으며, 자료 누락은 해소로 취급하지 않는다.
- 항목을 누르면 실험실 공항 METAR 관측 패널로 이동한다. 별도 알림 상세 페이지와 관측값 대시보드는 두지 않는다.
- 알림창 하단의 알림 설정 버튼은 PC에서 중앙 모달, 휴대폰에서 전체 화면 설정창을 연다. 배경 공항 화면은 그대로 유지하고 닫기 또는 Escape로 돌아간다. 설정창 안에서 키보드 초점을 유지하며 배경 조작을 막는다. 등록 공항 목록에서 공항을 선택해 조건·수신 방법을 수정한다. 공항 추가·일시정지·삭제도 여기서 관리한다.
- Escape, 닫기 버튼, 알림창 바깥 클릭으로 닫을 수 있다. 묶음 팝업은 벨 알림창으로 연결한다.
- 공항 패널은 실험실 모의 관측용이며 실제 운영 공항 패널/실제 푸시 연결은 아직 하지 않았다.
- 테스트 버튼은 기존 설정을 유지해 모의 관측을 만든다. 여러 공항 버튼은 김포·인천·제주의 예시 설정을 적용한다.

## 검증

`alert-lab` 브라우저 계약은 고정 기기 viewport, 벨 알림창에서 공항 패널과 설정으로 이동, 자료 누락과 해소, 360/390/430px 반응형 및 접근성을 확인한다. 실제 휴대폰 하드웨어와 OS 푸시 검증은 별도다.
