# 내 지도 — 사용자 합의와 구현용 UI/UX 명세

작성·정리: 2026-09-19  
상태: **사용자 논의 및 HTML 시안에 따른 구현 기준. 제품 기능은 아직 미구현.**

[HTML 시안](../mockups/2026-09-19-flight-map.html) · [시안 사용법·구현 차이](../mockups/2026-09-19-flight-map.README.md) · [구현 계획·검증 목록](2026-09-19-flight-map-implementation-plan.md)

이 문서는 최초 UI/UX 초안을 사용자와의 후속 논의로 **전면 대체**한다. 구현자는 이 문서 → 시안 사용법 → HTML의 보기·편집 화면 → 구현 계획 순서로 읽는다. 9/5 [조사 기록](../../research/2026-09-05-flight-map-drawing-research.md)은 배경 자료이며, 여기서 제외한 기능을 다시 첫 범위에 넣는 근거로 쓰지 않는다.

문서에 적힌 사용자 동작을 구현 계약으로 삼는다. 시안은 화면 배치·정보 위계·동선을 참고하는 자료다. 픽셀 좌표, 가짜 도로·공역, 단순 저장 코드, 시안의 누락 기능을 제품 구현으로 복제하지 않는다. 코드 파일 분할·API 명칭·용량 수치는 별도 표시한 **구현 기본안**이며 사용자가 개별적으로 확정한 사항과 구분한다.

## 1. 목적과 첫 범위

비행계획에 필요한 기본 지도 정보를 제공하고, 그 위에 **사용자만 아는 지점·참고선·구역을 쉽게 작성·정리**하게 한다. 사용 흐름은 **개인 지도 작성 → 저장 → 기관 공유**다. 화면 명칭은 사용자와 논의한 **내 지도**로 유지한다. 코드 폴더를 바꾸더라도 화면 명칭을 임의로 ‘비행 지도’로 바꾸지 않는다.

| 정보 | 기본 제공 | 사용자 작성 |
|---|---|---|
| 공역 | 앱에 확보된 경계·이름·고도 | 자체 훈련구역·활동구역 |
| 비행경로 | 공표된 항로·항행지점 | 개인·기관 참고 경로·선 |
| 지상 주요 포인트 | 배경지도의 지명·지물 | 위치를 직접 찍고 이름·아이콘·메모 지정 |
| 고속도로 | 확보된 도로 형상·노선명 | 필요한 지점·구간의 참고 표시 |
| 행정구역 | 확보된 행정경계·지역명 | 자체 담당구역·활동범위 |

기본 정보의 실제 자료 범위·축척별 표시 수준을 확인한다. 임의의 지상 지물이 모두 들어 있다고 약속하지 않는다. **다리 등을 클릭해서 특정 지물로 자동 식별·복사하는 기능은 제외**한다. 배경지도를 보고 사용자가 위치를 지정한다.

### 포함

- 작성 도구 **점·선·면·원**. 각 항목의 이름은 지도에 표시 가능.
- 지점 하나씩/연속 추가. 좌표 여러 줄 입력은 보조 입력 방법으로 구현 계획에 포함.
- 이름·메모·스타일·위치/형태 수정, 면·원의 바닥/천장 고도.
- 한 단계 그룹, 여러 항목 선택, 그룹 이동·정렬·드래그, 표시 토글.
- 개인 지도 생성·복제·삭제·자동저장·재열기.
- 기관의 독립 공유본, 명시적 업데이트, 수신자의 개인 사본.
- 기존 KML/KMZ 원본 보기 보존, 편집본 가져오기, KML 전체/선택 범위 내보내기.
- 여러 지도 동시 표시, 한 지도만 편집.

### 제외·후속

- 독립 텍스트 도구, 호·부채꼴·회랑·화살표 신규 작성. **도형의 이름 표시는 제외가 아니다.**
- 중첩 그룹, 실시간 공동편집, 공개 링크 공유.
- 기존 지물 자동 식별, 항공 지점 자동 스냅, 도로/공역 자동 추출.
- 사용자 도형을 이용한 기상 분석·저촉 경고·기관 자동 감시, 유효 시간·반복 일정.
- 이미지/PDF 내보내기, 개인 저장 버전 탐색 화면, 3D 공역 체적 작성.
- 참고선을 실제 비행계획으로 자동 변환. 실제 비행경로는 기존 경로 작성 기능의 소관.

기존 시험판의 추가 도구 코드는 첫 통합에서 삭제하지 않는다. 기존 파일을 잘라내거나 후속 기능을 몰래 활성화하지 않는다.

## 2. 화면과 상태

기본 진입은 **보기**다. 보기 패널과 편집 패널은 **왼쪽 같은 자리를 교체**한다. 오른쪽에 별도 상시 속성 패널을 추가하지 않는다. 전환으로 지도 카메라·배경지도·기상 레이어를 초기화하지 않는다.

| 화면 ID | 보이는 내용 | 주요 동작 | 시안 위치 |
|---|---|---|---|
| V1 지도 목록 | 개인 지도 / 기관 지도, 검색, 표시 여부, 항목 수 | 새 지도, 지도 열기, 표시 토글 | 주소 끝에 #library |
| V2 지도 보기 | 제목, 수정·공유·메뉴, 그룹·항목 목록 | 그룹 접기/표시, 항목 선택 | 기본 화면 또는 #view |
| V3 항목 상세 | V2 아래에 이름·그룹·위치·고도·메모 | 닫기, 이 항목 수정 | V2 목록/지도에서 항목 클릭 |
| E1 지도 편집 | 제목·저장 상태·편집 마침, 네 도구, 되돌리기, 대상 그룹, 목록 | 작성, 드래그, 다중 선택 | V2 수정 또는 #edit |
| E2 항목 속성 | E1의 목록 부분이 입력 폼으로 전환 | 속성 즉시 반영, 위치·형태 수정, 목록 복귀 | E1에서 항목 선택 |
| E3 도형 작성 | E1 도구 안내·임시 도형. 연속 지점은 목록 유지 | 점 추가, 도형 완료, 취소 | 도구 선택 |
| E4 형태 수정 | E2 입력과 구별된 지도 손잡이 | 완료/취소, 전체 이동, 꼭짓점/반경 수정 | 지도에서 위치·형태 수정 |
| D1 기관 공유 | 대상 기관·이름·메모·전체 항목 수 | 이 버전 공유, 취소 | V2 공유 |

  V1 -->|새 지도| E1["편집 + 항목 목록"]
  V2 -->|수정| E1

새 지도는 이름을 입력한 뒤 빈 E1으로 진입한다. 기본 그룹과 ‘그룹 없는 항목’을 제공한다. 표시용 기본 이름은 중복될 수 있으나 식별에는 ID를 쓴다. 내용 검색은 이름으로 시작하고, 검색 결과를 선택하면 해당 그룹을 펼친다.

### V1/V2 규칙

- 표시 토글은 지도에 켜고 끄기만 한다. 제목/열기는 패널의 상세 내용을 연다. 두 클릭 영역은 분리한다.
- 여러 개인/기관 지도를 동시에 표시할 수 있다. 한 지도를 열어도 다른 지도의 표시 상태는 유지한다.
- V2/V3에는 도형 작성 도구·그룹 정렬 손잡이를 노출하지 않는다. 지도 드래그는 카메라만 옮긴다.
- 목록 항목 선택 시 지도와 목록을 함께 강조한다. 화면 밖에 있으면 위치로 이동하고, 보이는 항목은 불필요하게 카메라를 움직이지 않는다.
- 지도 항목 선택 시 해당 지도를 열고 소속 그룹을 펼친다. 빈 지도 클릭은 상세·선택을 해제한다.
- V3의 ‘이 항목 수정’은 선택 상태를 유지한 채 E2로 진입한다. 기관 항목이면 ‘내 지도로 복사’를 제공한다.
- 도형 추가는 목록 위 동작 줄의 ‘추가하기’로 들어간다(2026-09-21 사용자 결정). 헤더의 ‘수정’ 단추는 없앴다 — 상단 ‘수정’으로 점·선·면을 추가하는 동선이 어색하다는 판단이다. 개별 항목 수정은 V3 상세의 ‘이 항목 수정’이 맡는다. ‘편집 마침’은 편집 본문 상단에 둔다.
- 편집 중 다른 지도는 보기 전용이다. 그 지도의 항목 클릭으로 편집 대상이 바뀌지 않는다.
- 접힌 그룹·목록 스크롤·카메라는 보기↔편집 전환 때 보존한다. 편집을 마치면 같은 V2로 돌아온다.

### 레이아웃·반응형

기존 사이드바 레일과 내 지도 진입을 재사용한다. 폭·폰트·간격은 [디자인 정책](../../policies/design/design-language.md) 및 layoutTokens.css에서 가져온다. 시안의 340/380/400px 폭은 검토용 예시다.

넓은 화면에서는 패널과 지도, 좁은 화면에서는 **목록·상세 / 지도 보기** 전환을 사용한다. 글자를 줄여 두 영역을 억지로 배치하지 않는다. 본체 페이지 가로 스크롤은 없어야 한다. 제품은 데스크톱 편집과 태블릿·휴대폰 조회를 우선한다는 선행 범위를 유지한다. 시안은 좁은 화면 편집도 노출하지만 **터치 편집의 제품 지원 확정을 뜻하지 않는다**. 이를 확장할지는 조회 구현과 독립적으로 결정하며 데스크톱 구현을 막지 않는다.

## 3. 작성 동작

도구는 점·선·면·원 네 개를 항상 같은 순서로 표시한다. 추가할 그룹을 도구 근처에 보여준다. 그룹을 선택하지 않으면 ‘그룹 없는 항목’에 넣는다. 그룹을 선택하고 연속 추가하면 그 그룹에 계속 쌓인다.

| 도구 | 위치 지정·완료 | 완료 후 |
|---|---|---|
| 점 | 지도 한 번 클릭, 기본 이름 자동 생성 | 단건이면 E2에서 이름 수정. 반복 입력 모달 없음 |
| 점 + 연속 추가 | 클릭할 때마다 기본 이름의 완성 지점 추가 | E1 목록 유지, 같은 도구 유지, ‘추가 마침’으로 종료 |
| 선 | 두 개 이상 서로 다른 점을 순서대로 클릭 → 도형 완료/Enter | E2 |
| 면 | 세 개 이상 서로 다른 경계점 클릭 → 도형 완료/Enter/첫 점 클릭 | 닫힌 면으로 E2 |
| 원 | 중심 클릭 → 반경 미리보기 → 두 번째 클릭 | 중심·반경이 정의된 원으로 E2 |

기본은 단건 완료 후 선택 상태로 돌아간다. 연속 입력은 지점에 명시적으로 제공한다. /draw의 모든 도구 고정 동작을 그대로 물려받지 않는다.

E3 안내는 다음 행동과 입력 상태를 보여준다. 예: ‘면 · 3개 점 입력됨’. 선·면의 ‘한 점 취소’는 마지막 꼭짓점만 제거한다. 연속 지점의 되돌리기는 직전 완성 지점을 제거하고 계속 추가할 수 있게 한다. 완료된 지점과 미완성 꼭짓점을 혼동하지 않는다.

숫자 입력: 지점의 좌표와 원의 반경(NM)을 수정할 수 있다. 좌표 여러 줄 붙여넣기는 그룹을 지정한 뒤 이름/좌표 미리보기와 잘못된 행 표시를 거쳐 일괄 추가한다. 입력 형식 선택·위도/경도 순서를 명시한다. DD/DM/DMS 파서는 기존 coordFormat.js 재사용을 검토한다. 오류 행을 조용히 건너뛰어 ‘전부 성공’으로 표시하지 않는다. 시안에는 이 폼이 아직 없다.

실제 기하는 WGS84 좌표를 사용한다. 원은 중심과 NM 반경으로 보관하고 기존 shapeBuilders.js의 지리 계산으로 만든다. 시안의 픽셀 거리/17 환산은 사용하지 않는다. 유효하지 않은 좌표·자기교차 면·0 반경은 완료 전에 위치와 이유를 알려준다.

## 4. 속성·형태 수정

| 종류 | 속성 |
|---|---|
| 공통 | 이름, 소속 그룹, 메모, 표시/이름표 설정 |
| 점 | 아이콘, 색, 크기, 위치 |
| 선 | 색, 굵기, 실선/점선, 꼭짓점 |
| 면 | 테두리 색·굵기, 채움 농도, 꼭짓점, 바닥·천장 고도 |
| 원 | 테두리 색·굵기, 채움 농도, 중심·반경, 바닥·천장 고도 |

이름·메모·색 등은 유효한 값을 입력하면 바로 반영한다. 속성마다 ‘적용’ 버튼을 만들지 않는다. 한글 조합 중 값이나 불완전 숫자를 서버에 확정하지 않고, 텍스트 편집 한 번을 되돌리기 한 단계로 묶는다. E2의 ‘항목 목록’으로 그룹 목록에 복귀한다.

위치·모양은 **‘지도에서 위치·형태 수정’을 누른 동안만** 직접 드래그한다. 평소 선택과 기하 편집을 분리한다.

- 점: 끌어서 이동.
- 선·면: 꼭짓점 이동, 중간점으로 꼭짓점 추가, 선택한 꼭짓점 삭제. 최소 개수 검증.
- 원: 중심·반경 손잡이, 반경 숫자 입력. 원의 샘플링 꼭짓점을 사용자에게 노출하지 않는다.
- 도형 전체 이동은 모양을 유지한다.
- E4 ‘완료’는 한 번의 변경으로 확정. ‘취소’는 진입 전 기하로 복원. 편집 중 임시 기하는 완료본 저장과 분리한다.

첫 작성 고도는 /draw와 같은 **ft MSL**로 명시한다. 미지정은 null이며 0과 구분한다. 둘 다 입력했으면 바닥 < 천장이어야 한다. 다른 기준(AGL/FL/SFC/UNL)의 가져온 자료는 원문·기준을 보존하고 근거 없이 MSL로 변환하지 않는다. 이 기능의 고도 입력은 공역 허가나 브리핑 저촉 검사를 의미하지 않는다.

## 5. 그룹·다중 선택·드래그

그룹은 **한 단계**다. 점·선·면·원을 섞어 넣을 수 있다. 항목은 정확히 한 그룹에 속하고, 하나의 ‘그룹 없는 항목’ 영역이 있다.

- 그룹 생성, 이름 변경, 접기/펼치기, 전체 표시 토글, 그룹 해제, 그룹과 항목 삭제.
- 그룹 해제는 항목을 ‘그룹 없는 항목’으로 옮긴다. 그룹 전체 삭제는 항목 수도 확인한다.
- 다중 선택은 ‘선택’ 모드의 체크박스로 한다. 표시 토글과 선택 체크박스를 분리한다.
- 다중 작업은 그룹 이동, 공통 색 변경, 삭제. 이동 메뉴에서 기존/새 그룹을 지정할 수 있다.

| 드래그 대상·목적지 | 결과 |
|---|---|
| 항목 → 같은 그룹의 항목 사이 | 순서 변경 |
| 항목 → 다른 그룹 제목/빈 공간 | 그 그룹의 끝으로 이동 |
| 항목 → 다른 그룹의 항목 앞 | 그 위치에 삽입 |
| 선택한 여러 항목 중 하나 → 목적지 | 선택 전체 이동. 기존 상대 순서 유지 |
| 그룹 손잡이 → 그룹 사이 | 그룹 순서 변경. 중첩 생성 안 함 |

드래그 손잡이는 편집 모드에만 보인다. 삽입 선/대상 그룹 강조, 빈 그룹 드롭 영역, 접힌 그룹에 머물 때 펼치기, 긴 목록 가장자리 자동 스크롤을 제공한다. 자기 자신에게 놓기·범위 밖 놓기는 변경 없음. 한 번의 드롭은 되돌리기 한 단계다. 드래그 없이 ‘그룹으로 이동’과 순서 이동 동작을 사용할 수 있어야 한다.

검색 중에는 보이지 않는 항목을 포함한 순서 해석이 모호하므로 **검색을 지운 뒤 정렬**하게 안내한다. 필터된 목록에서 몰래 전체 순서를 바꾸지 않는다. ‘그룹 없는 항목’도 표시용 영역으로 정렬 가능하되 이름 변경/해제/영역 삭제는 하지 않는다. 그 안의 항목 삭제는 가능하다. 이 둘은 구현 기본 규칙이다.

## 6. 지도 표현과 기본 레이어

- 점은 아이콘+옆 이름, 선은 중간 부근 이름, 면·원은 내부 이름.
- 항목 표시와 이름표 표시를 구분한다. 그룹 단위 이름표 켜기/끄기도 가능.
- 기본 스타일로 바로 작성 가능. 같은 종류의 다음 도형은 직전 스타일을 이어받는다.
- 면·원은 옅은 채움. 기상이 가려지면 표시 농도를 낮추거나 0으로 렌더링하되 저장된 스타일은 변경하지 않는다.
- 이름은 배경과 구별되는 halo를 사용한다. 이름 겹침을 정리하고 선택 항목 우선 표시, 중요한 항목의 ‘이름 항상 표시’를 제공한다.
- 선택 강조는 공역의 의미/위험 등급과 다른 중립 강조로 구별한다.
- 사용자 레이어가 기상 경보·시간 막대·확대 컨트롤을 가리지 않는다.

기존 공역·도로·행정경계·기상 설정은 기존 메뉴 소유권을 유지한다. 시안 지도 상단의 도로/행정경계/지명/공역 버튼은 검토용이며, 같은 설정 UI를 제품에 중복 생성하라는 뜻이 아니다. 지도 스타일 교체 후 모든 사용자 지도·이름표·편집 상태를 다시 설치한다. 기존 기본 지도 설정에서 숨긴 도로명·지명은 비행계획 사용성을 실제 데이터로 확인하여 조정한다.

## 7. 취소·되돌리기·이탈

| 행동 | 계약 |
|---|---|
| 도형 완료 | 현재 선·면·원을 완성 항목으로 확정 |
| 취소/Esc | 현재 작성·형태 수정만 취소. 이미 완료된 항목 유지 |
| 되돌리기/다시하기 | 추가·속성 변경·삭제·그룹 이동·정렬을 작업 단위로 복구 |
| 편집 마침 | 같은 지도의 보기 패널로 복귀. 정상 상태에서는 확인창 없음 |

미완성 도형이나 형태 수정 중에 패널 이탈·편집 종료·다른 도구 전환을 요청하면 **‘계속 그리기 / 그냥 나가기’ 두 선택만** 제공한다. **‘완료하고 나가기’는 넣지 않는다.**

- 계속 그리기: 현재 초안 유지.
- 그냥 나가기: 현재 미완성 도형 폐기 또는 형태 수정 전 상태 복원 후 요청한 화면으로 이동.
- 이미 완료한 연속 지점·다른 항목은 지우지 않는다.
- 새로고침/탭 닫기는 브라우저의 이탈 경고와 복구본을 이용하며, 브라우저 기본 확인문구를 임의로 제어한다고 약속하지 않는다.

되돌리기는 점 한 개, 형태 드래그 한 번, 여러 항목의 드롭 한 번, 텍스트 한 번 수정 단위다. Ctrl/Cmd+Z는 입력창 안에서는 브라우저 텍스트 편집을 우선한다. 미완성 꼭짓점 제거와 완성 항목 되돌리기를 구분한다.

## 8. 저장·지도 관리

지도 한 벌에 이름·그룹과 항목 순서·기하·스타일·고도·메모를 저장한다. 복제는 새 개인 지도 ID를 만든다. 지도 삭제는 이름·항목 수를 확인하고, 기관 공유본은 삭제하지 않는다.

완성된 변경은 자동저장한다. 사용자 개인의 표시 지도·접힌 그룹·이름표 임시 토글·카메라·선택은 내용과 분리한다. 특히 **기관 지도 표시를 끄는 행동은 공유 자료 수정이 아니다.** 작성자가 정한 기본 스타일/이름표 정책과 조회자의 현재 표시 override도 구분한다.

| 화면 문구 | 실제 상태 |
|---|---|
| 저장 중… | 최신 완료 변경을 계정 서버에 저장 중 |
| 계정에 저장됨 · 시각 | 해당 revision의 서버 응답 확인 |
| 이 기기에 보관 중 | 비로그인 또는 로컬 전용, 계정 저장 아님 |
| 기기에 보관됨 · 동기화 대기 | 복구본 성공, 서버 미확인 |
| 저장 실패 · 다시 시도 | 실패 원인과 복구/백업 경로 제공 |

시안은 ‘이 브라우저에 저장됨’만 실동작한다. 제품에서 이를 계정 저장 성공으로 바꿔 표시하는 것만으로 구현을 끝내지 않는다.

계정 저장은 revision 충돌을 검출하며 자동 덮어쓰지 않는다. 충돌 시 내 변경을 사본으로 남길 수 있다. 오래된 저장 응답이 최신 상태를 저장됨으로 바꾸지 않는다. 로컬 복구본은 계정별 격리한다. UTC/epoch 저장, 화면은 선택한 시간대 표기를 따른다.

미완성 작성 초안은 완료본과 별도로 기기에 복구 보관한다. 공유·내보내기는 완료본만 사용한다. 사용자에게 저장 성공이 확인되지 않은 작업을 버리는 종료 동작을 숨기지 않는다.

## 9. 기관 공유

D1에서 대상 기관, 지도 이름, 선택적 전달 메모, 전체 그룹·항목 수를 확인한다. **숨긴 항목도 포함**한다고 명시한다. 공유 범위는 지도 전체다. 선택 범위 전달은 파일 내보내기로 한다.

- 서버에 확정 저장된 특정 개인 revision으로 **기관의 독립 스냅샷**을 만든다.
- 받은 사람은 보기·표시 토글·상세 확인만 한다. 수정은 개인 사본 생성 후.
- 원본을 고쳐도 공유본은 그대로. 작성자가 ‘공유본 업데이트’를 누를 때 새 기관 버전 생성.
- 이미 열어둔 수신자에게 ‘새 버전이 있습니다 · 적용’. 읽던 내용을 몰래 교체하지 않는다. 새로 열면 최신 버전.
- 개인 원본 삭제와 기관 공유 중단을 구분한다. 소속 이동으로 자료가 다른 기관으로 따라가지 않는다.
- 기관 지도 목록에는 기관·버전·수정 시각을 보여준다. 선택한 기관의 활성 멤버십을 서버에서 검증한다.
- 미가입/비로그인 사용자의 개인 작업은 유지하고 공유 가능한 조건을 안내한다.

**권한 구현 기본안:** 활성 구성원은 자신의 지도를 공유하고 기관 지도를 열람·개인 복사할 수 있다. 공유 항목의 게시자 또는 기관 관리자가 업데이트·공유 중단할 수 있다. 기관 관리자가 개인 원본을 편집할 수는 없다. 기존 기관 비행/자료의 권한을 일괄 변경하지 않는다.

공유 중단·구성원 비활성 이후 API 재요청은 거부하고 열린 자료도 권한 재검증 결과에 따라 가린다. 이미 내려받은 파일/개인 사본까지 원격 회수하는 기능은 없다. 영속 오프라인 기관 캐시는 첫 범위에서 제외한다. 이 정책 세부는 구현 기본안이며 첫 프론트 작성 단계의 선행 조건은 아니다.

## 10. 가져오기·내보내기·기존 자료

### 가져오기

파일을 처음 열면 시안과 같은 **보기 패널**에서 지도 이름·원본 폴더 계층·개별 항목을 표시한다. 원본 Placemark 하나는 목록 한 행이며, 렌더링을 위해 분해된 도형들은 내부적으로 같은 항목에 연결한다. 선택·강조·표시 토글도 원본 항목 단위다. 가져온 폴더의 중첩 조회는 유지하며 신규 작성 그룹의 한 단계 규칙과 구분한다. 원본 보기에서 ‘수정’을 누르면 변환 미리보기를 거쳐 개인 편집본을 만든다.

‘편집본으로 가져오기’는 지도 목록에서 시작하면 새 개인 지도를 만들고, 편집 중 시작하면 현재 지도에 추가한다. 원본을 보기로 여는 단계와 편집본 변환을 구분한다. 파일 선택과 드롭을 지원한다. 기존 항목을 덮어쓰지 않고 새 ID로 넣는다. 이름·폴더·지원 스타일을 유지하며 추가 항목을 선택해 바로 그룹 이동할 수 있게 한다.

중첩 KML 폴더는 편집본에서 경로명(예: 훈련 / 서편)을 가진 한 단계 그룹으로 평탄화하는 기본안을 쓴다. 같은 폴더 이름 때문에 그룹을 합치지 않는다. 원본은 기존 ‘가져온 파일’ 보기 흐름과 보관소에 그대로 남긴다.

지원하지 않는 이미지·HTML·고도 기준·독립 글자·고급 도형 메타데이터 등이 있으면 변환 전에 포함/변환/제외 개수를 보여준다. 원·호·회랑의 일반 선/면 표현을 유지하는 것과 수치 편집 가능 여부를 구분한다. 파일을 보고 일반 다각형을 원으로 추측하지 않는다. 변환할 수 없는 항목 때문에 기존 원본까지 삭제하지 않는다.

HTML 설명은 원문을 보관하고 읽을 수 있는 텍스트/속성 표로 표시한다. 복합 항목과 내부 구멍이 있는 면은 조각 분리·바깥 링만 저장하는 과정에서 손실되지 않도록 한다. 구체적인 근거와 표본별 완료 기준은 [실제 KMZ 두 파일 검토](2026-09-19-flight-map-real-kmz-review.md)를 따른다.

**공역정보 메타데이터 조회는 첫 범위의 필수 기능이다.** 항목 상세는 이름·유형/등급·상한/하한·식별·비고를 우선 표시하고, 항로에는 해당 방위·길이 필드도 보여준다. ‘전체 원본 속성’에서 인식하지 못한 필드까지 확인할 수 있어야 한다. 고도의 값·단위·기준을 함께 유지하며 FL, Height, MSL 등을 임의로 같은 값으로 변환하지 않는다. 자료 없음은 0과 구분한다. 사용자 편집 값/메모와 원본 메타데이터를 분리하고 개인 저장·기관 공유·재내보내기에도 원본 속성을 보존한다.

위 주요 항목 배치는 검증된 공역자료의 요약 예시이며, 모든 파일에 강제하는 고정 양식이 아니다. **공통 상세의 기본은 파일마다 필드명·개수·값이 달라지는 가변 속성표**다.

- 원본 필드 순서·이름·값을 보존하며 5개/50개 등 개수에 맞춰 행을 만든다. 긴 이름·값은 줄바꿈하고 많은 행은 상세 영역 안에서 스크롤한다. 중복 이름 필드도 객체 키로 덮어쓰지 않는다.
- 의미와 기준을 확인한 형식만 주요 정보로 요약한다. 필드 이름이 비슷하다는 이유만으로 고도·등급·단위를 추정하지 않는다. 요약이 있으면 ‘전체 원본 속성’을 펼칠 수 있고, 요약이 없으면 읽은 속성표를 바로 보여준다.
- 설명이 일반 글이면 글로, 표로 읽을 수 있으면 표로 표시한다. 모든 설명을 고도/등급 칸에 강제로 넣지 않는다. 설명과 속성이 없을 때는 ‘제공된 설명·속성이 없습니다’로 안내한다.
- 알 수 없는 필드도 표시하며, 읽지 못한 내용은 ‘일부 내용을 해석하지 못했습니다’ 등 실제 상태를 알리고 원본을 보존한다. 파싱 실패를 ‘속성 없음’이나 전체 성공으로 표시하지 않는다.
- 숫자 0·false·자료 없음은 구분한다. 안전한 텍스트/표 렌더링을 사용하고 원본 HTML을 실행하지 않는다. 현재 확인된 두 표본 외 모든 KML 형식의 자동 해석을 보장하지 않는다.

### 내보내기

- KML: 지도 전체, 선택한 그룹, 선택한 항목 중 범위를 지정한다.
- 숨김 상태와 내보내기 범위는 별개다. 범위의 총 항목 수를 명시한다.
- 좌표·이름·메모·그룹/순서·지원 스타일과 가져온 원본 속성/설명을 보존한다.
- 원은 표준 KML 다각형으로 내보내고 앱 전용 메타데이터에 중심·반경·도형 종류를 기록하여 우리 앱 재가져오기 때 복원한다.
- 바닥/천장 값과 기준도 메타데이터에 보존한다. 외부 프로그램이 앱 전용 메타데이터까지 해석한다고 보장하지 않는다.
- 첫 범위에서 실제 바닥~천장 체적을 구현하지 않으면 평면 경계와 고도 설명으로 내보내는 쪽을 택한다. 바닥이 2,000ft인데 지면부터 천장까지 기둥으로 내보내면서 정확한 공역이라고 표현하지 않는다.

**현재 /draw의 한계:** kmlWrite.js는 Placemark를 Document에 나열하여 그룹을 쓰지 않는다. 원의 생성 정의를 기록하지 않으며, 바닥 고도는 3D 형상에 반영하지 않는다. importKml.js는 좌표의 가장 높은 고도를 천장으로 읽고 바닥을 0으로 둔다. 기존 입출력의 존재와 위 보존 계약의 구현 완료는 다르다.

### 이전

기존 my-map 원본 파일·폴더 보기를 유지한다. 기존 /draw 브라우저 자료를 발견하면 개인 지도로 가져오는 경로를 제공한다. 새 저장본과 복구 여부를 확인하기 전 기존 키/원본을 삭제하지 않는다. 독립 글자·고급 생성 도형 등 첫 범위 밖 데이터는 읽기 전용 호환 또는 원본 보관+선택 변환으로 보존한다. /draw는 통합·이전 완료 전 제거하지 않는다.

## 11. 시안과 제품의 차이

| 영역 | HTML 시안 | 실제 구현에서 해야 할 것 |
|---|---|---|
| 지도 | 시도 경계 SVG + 합성 지물·공역 | 기존 Mapbox 지도와 실자료 사용 |
| 기하 | 픽셀 좌표, 원의 임시 NM 환산 | WGS84, 지리 거리·면적, 유효성 검사 |
| 보기·편집 | 세 화면과 선택·속성 전환 작동 | App/MapView 생명주기·기존 메뉴와 통합 |
| 그룹 | 생성·이동·다중 드래그·정렬 작동 | 긴 목록 자동 스크롤·접근성 대체·ID 기반 저장 |
| 형태 | 이동·꼭짓점 이동·반경 변경 | 꼭짓점 추가/삭제·좌표 직접 입력·일괄 입력 보완 |
| 스타일 | 팔레트·굵기·채움·이름 토글 | 점 크기·점선·이름 크기/항상 표시·스타일 상속 보완 |
| 저장 | 시안 전용 localStorage | 계정 API·revision·계정 격리·복구본·저장 실패 처리 |
| 공유 | 브라우저 내 사본 | 실제 두 계정, 기관 권한·불변 버전·새 버전 적용 |
| 파일 | 예시 좌표 KML 다운로드, 가져오기는 안내만 | 기존 파서/작성기를 보완해 실제 파일 입출력 |
| 메타데이터 상세 | 사용법 → 속성 표시 예시에서 네 가지 형식 비교 | 실제 가져온 항목 연결, 필드 추출·요약 판별·원본 보존 구현 |
| 미완성 초안 | 이탈 경고, 별도 복구 저장 없음 | 초안 복구 저장 및 복구/폐기 UI |
| 작은 화면 | 목록/지도 전환, 편집도 시연 가능 | 제품 기기 범위 적용, 실제 iPad Safari 조회 확인 |

시안에서 되는 기능도 실제 앱 계약을 통과해야 완료다. 시안에서 없는 필수 기능은 누락으로 추적하고 범위에서 자동 제외하지 않는다.

## 12. 사용자 동작별 완료 기준
