# 내 지도 시작 화면 재설계

2026-09-22. 사용자가 요청한 최신 화면 방향이다. 기존 명세의 **내 지도 안 기관 목록·공유·업데이트 UI**는 이 문서로 대체한다. HTML 시안에 맞춰 내 지도 React 화면을 적용했다. 기관 라운지의 개인 지도 선택 등록은 별도 후속 작업이다.

[클릭 가능한 HTML](../mockups/2026-09-22-flight-map-start.html)

## 화면 역할

내 지도는 개인이 직접 그린 지도와 개인이 불러온 파일만 관리한다. 기관 자료 등록·교체·버전 관리·삭제·공유는 기관 라운지에서만 한다. 내 지도 안에는 기관 지도 목록, 기관 새로고침, 기관에 공유, 소속 기관 안내를 두지 않는다.

## 1. 아무 지도도 없는 첫 화면

제목 `내 지도`, 한 줄 목적 설명, 큰 카드 두 개만 둔다.

| 카드 | 설명 | 누른 뒤 |
|---|---|---|
| 새 지도 그리기 | 점·선·면·원으로 필요한 정보를 지도 위에 직접 표시합니다. | 기존 지도 편집 패널 |
| 파일 불러오기 | 가지고 있는 KML·KMZ 파일을 지도 위에서 확인합니다. | 파일 선택 패널 |

빈 검색창, 비어 있는 개인/가져온/기관 섹션, 저장 상태, 편집본 변환, 그룹 없는 항목, 자료 이전 배너는 이 첫 화면에 나열하지 않는다. 저장소 접근 실패 등 사용자가 시작하지 못하는 실제 오류는 예외로 해당 행동 근처에 표시한다. 이전 자료 가져오기는 이후 목록 관리 메뉴에 배치한다.

## 2. 새 지도 그리기

별도 이름 입력 화면을 거치지 않는다. `이름 없는 지도`로 시작하고 헤더의 이름을 눌러 변경한다. **기존에 만들어 둔 편집 패널과 그리기 동작을 사용한다.** 새로 만든 흉내 UI로 대체하지 않는다.

- 상단: 지도 이름, 편집 마침.
- 그 아래: 점·선·면·원. 최초에는 어떤 도구도 선택하지 않는다.
- 도구를 고르면 그 도구의 입력 안내와 완료/취소만 추가된다. 연속 추가는 점 도구에서만 표시한다.
- 처음에는 빈 항목 안내. 항목이 생기면 기존 목록·속성 패널로 바뀐다.
- 그룹 추가는 기존 그룹 생성으로 연결한다. 그룹이 없으면 대상 그룹 선택은 숨긴다. 그룹이 생기면 그룹 없는 항목과 해당 그룹 중 대상을 선택한다.
- 항목을 선택하면 기존 이름·그룹·메모·지도 표시·형태 수정 화면을 쓴다.
- 편집 마침은 저장된 지도 보기로 이동한다. 미완성 작업은 기존 ‘계속 그리기 / 그냥 나가기’ 계약을 따른다.

기존 그룹 정리·다중 선택·좌표 일괄 입력·undo/redo·형태 편집을 없애는 설계가 아니다. 해당 작업이 필요할 때 펼치는 구조로 배치한다. HTML은 9월 19일 원본 시안의 그리기, 그룹, 속성, undo/redo, 이동, 이탈 함수를 재사용한다. 현재 제품의 좌표 일괄 입력 등 원본 시안에 없는 동작을 새로 구현했다는 의미는 아니다.

## 3. 파일 불러오기

`내 지도`로 돌아가기, 제목, 파일 드롭 영역, `파일 선택`만 표시한다.

선택 후에는 같은 패널에서 파일명·분석한 폴더/항목 수와 `지도에서 보기`를 보여 준다. 잘못된 형식은 선택 영역 아래에서 설명하고, 다시 선택할 수 있게 한다. 읽을 수 없는 파일에는 열기 버튼을 활성화하지 않는다. 부분 해석은 읽힌 개수와 제외/경고를 짧게 표시하고 세부 내용은 펼쳐 본다.

처음부터 ‘원본/편집본’을 고르게 하지 않는다. 파일을 연 뒤 기존 폴더·항목·상세·가변 메타데이터를 보여 주고, 상단 `사본 만들어 편집`에서만 변환 안내를 확인한다. 변환 포함/변환/제외 개수와 원본 보존은 기존 계약을 유지한다.

HTML의 `파일 예시 보기`는 제품 패널 밖의 검토용 버튼이다. 실제 파일 분석은 연결하지 않았으며, 로컬 파일을 선택하면 파일명만 보여 주고 예시 지도라는 한계를 표시한다. 실제 파일에 대해 가짜 분석 개수를 표시하지 않는다.

## 4. 지도가 생긴 뒤

내 지도 목록에는 `새 지도`, `파일 불러오기`와 개인 지도 행을 표시한다. 지도 행에서 열기와 표시 여부를 구분한다. 복제·내보내기·삭제는 지도를 열고 더보기에서 한다. 개인 지도 이름은 지도 편집 헤더에서 바꾼다. 검색은 목록이 길어질 때 제공한다. 마지막 지도를 삭제하면 두 카드 시작 화면으로 돌아간다.

## 기관 라운지로 옮길 범위

기존 `MaterialsScreen`의 `공유자료 → 지도`와 `자료 등록`에 KML/KMZ 업로드, 파일 교체, 버전 선택, 삭제가 이미 있다. 이곳을 기관 지도 진입점으로 통일한다. 개인 지도의 기관 등록도 라운지에서 `내 지도에서 선택`으로 시작하도록 한다.

`MyMapSharingActions`와 내 지도 목록의 기관 구획·새로고침·기관 알림 및 자동 조회는 제거했다. 개인 지도 선택 등록을 라운지에 연결하는 작업은 남아 있다. 기관 자료 API와 기존 불변 버전 지도 API가 현재 별도이므로, 기존 공유 자료의 ID·버전·권한·원본을 보존하는 연결이 필요하다. 버튼을 감추는 것만으로 기관 기능 이전 완료를 판정하지 않는다.

- HTML: 새로운 빈 상태·파일 화면, 기존 편집 동작 재사용, 기관 상호작용 위치를 분리한 시안.
- 제품 적용: 아래 기록 참고. 기존 기관 자료와 서버 API는 변경하지 않았다.
- 시안 검증: 데스크톱/390px 모바일 렌더링, 시작→실제 점 추가→보기→파일 예시→사본 편집→기관 진입을 브라우저에서 확인. 런타임 오류와 가로 넘침 없음.
- 캡처: ignored `artifacts/flight-map-start-review/`.

## 제품 적용 기록 (2026-09-22)

- 빈 상태를 큰 카드 두 개로 변경. 새 지도는 이름 입력 팝업 없이 기존 점·선·면·원 편집기로 들어가며 헤더에서 이름을 수정한다.
- 파일은 실제 KML/KMZ 분석 결과를 먼저 보여 주고 `지도에서 보기`를 누를 때 저장·열기한다. 미리보기에서 돌아가면 목록에 남지 않는다. 가져온 지도는 `사본 만들어 편집`으로 변환 안내를 거쳐 편집기에 들어간다.
- 좌표 일괄 입력·현재 지도 KML/KMZ 추가는 `추가 도구`, 기존 그리기 자료·기기 자료 이전은 해당 자료가 있을 때 헤더의 `이전 자료`에 배치했다. 복제·내보내기·삭제는 보기 헤더의 더보기에 유지했다.
- 그룹·다중 선택·이동·형태 수정·undo/redo·자동 저장·초안 복구·가변 메타데이터를 유지한다. 마지막 지도를 삭제하면 시작 카드가 다시 나온다.
- 기관 지도 목록·공유·갱신·소속 안내와 자동 조회를 내 지도에서 제거했다. 기존 기관 서버 자료는 유지하며, 기관 라운지의 기존 업로드 화면은 변경하지 않았다.
- 남은 별도 기능: 기관 라운지 `내 지도에서 선택` 및 기존 기관 지도 API/자료 API 연결. 이번 내 지도 화면 수정 완료와 기관 기능 이전 완료를 구분한다.
- 검증: 기존 작성·그룹·KMZ 추가 계약 10개 통과. 초기 복제 테스트는 새 목록의 접근성 이름과 파일 내부 제목에 맞춰 선택자를 갱신했다. 최종 진입·파일·모바일 및 실제 두 KMZ 계약 7개 통과(데스크톱 전용의 모바일 실행 3개 제외). `npm run check` 성공: 백엔드 1,232개 통과·1개 건너뜀, 프론트엔드 1,671개 통과, 공용·운영 검사와 빌드 성공.
- 사용자의 마무리 요청에 따라 추가 전체 브라우저 실행은 중단하고 변경 핵심 흐름으로 범위를 좁혔다. iPad Safari 실기기는 미검증이다.
