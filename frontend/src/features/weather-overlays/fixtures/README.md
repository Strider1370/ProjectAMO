# WAFS SIGWX 임시 지도 샘플

개발 서버에서 `/?wafsSample=1`로 연다. 운영 빌드에서는 진입점과 샘플 모듈이 제거된다.
현재 GIS 위에 경계선·제트 풍속/고도 지점·태풍/화산 지점과 라벨을 표시한다.
예보 기준시각 선택, 3시간 간격 이동·재생, 현상별 필터, 전체 표시 토글,
FIR 전체 범위/한·중·일 확대, 클릭 속성 조회를 제공한다.
검사 화면은 Mercator 투영과 넓은 이동 범위를 사용하고 해제 시 기존 지도 설정을 복원한다.

## 출처와 재생성

공식 목록: https://aviationweather.gov/wifs/

```bash
python3 scripts/wafs-sigwx-samples.py --download
python3 scripts/test_wafs_sigwx_preview.py
DISABLE_COLLECTION=1 PROJECTAMO_FRONTEND_HOST=0.0.0.0 npm run dev:serve
```

원본은 IWXXM 2025-2 공개 샘플 32개다. 기준시각 2026-08-02/03 12Z마다
F06–F48의 15개 개별 예보와 이를 묶은 합본 1개가 있다. 지도에는 합본을 중복하지 않은
30개 프레임을 사용한다. 동일 유효시각이라도 예보 기준시각이 다르면 별도로 다룬다.
GeoJSON metadata에 출처 URL, 원본 SHA-256, UTC 시각, 전구/지역 객체 수를 보존한다.
지역은 현재 인천·해외 FIR 26개를 포함하는 75–170°E / 20°S–70°N이다.
다운로더는 2025-2만 선택하며 기존 파일을 재사용한다. `--download` 없이 실행하면
로컬 다운로드 목록만 사용해 데이터와 `artifacts/wifs-sigwx/audit.json`을 다시 만든다.
자세한 결과는 [샘플 분석](../../../../../docs/research/wafs-sigwx-samples.md)을 참조한다.

## 이번 검사의 한계

- GML CubicSpline에 끝점 접선 방향을 반영하는 C2 보간을 적용했다. chord-length 매개변수 가정과 공식 차트 대조 미완료 상태는 분석 문서에 기록했다.
- 날짜변경선 연속화 후 선분을 범위로 자른다. 영역의 외곽과 내부 구멍은 각각 경계선으로 표시한다. 선택한 난류·착빙 한 영역만 원본 링을 이용해 옅게 채운다.
- 영역 라벨은 보이는 경계선의 앵커와 연결선으로 연결하며 충돌 시 옮기거나 생략한다. 제트 wind symbol은 XML에 지정된 좌표를 사용한다.
- 현상 수는 시간마다 달라진다. 원본 경계/지점이 표시 범위와 교차한 객체 수이며 정식 spline 영역 교차 계산 결과가 아니다.
- CB scallop·착빙 지그재그·강도별 SVG·제트 wind barb와 화살촉을 표시한다. 공식 차트와의 형상 비교는 후속 작업이다.
- WAFS 운영 수집은 연결하지 않았다. 재생은 저장한 과거 예보를 1.5초마다 전환한다.
- 방사성 물질과 모래·먼지폭풍 실제 객체가 없어 해당 표현은 이 샘플로 검증할 수 없다.

난류·착빙의 상시 라벨은 숨긴다. 영역 내부나 경계를 누르면 겹친 현상의 강도·고도 목록을 표시하고 한 영역씩 강조한다.
